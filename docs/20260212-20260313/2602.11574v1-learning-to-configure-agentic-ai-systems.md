## 摘要
配置基于大语言模型（LLM）的智能体系统涉及从庞大的组合设计空间中选择工作流、工具、Token 预算和提示词，目前通常由固定的庞大模板或人工调优的启发式方法处理。这导致了行为的脆弱性和不必要的计算开销，因为无论输入查询是简单还是困难，通常都应用相同的繁琐配置。我们将智能体配置建模为一个基于查询的决策问题，并引入了 ARC（智能体资源与配置学习器），它利用强化学习来学习轻量级的层次化策略，从而动态地定制这些配置。在涵盖推理和工具增强问答的多个基准测试中，所学习的策略始终优于强大的手工设计和其他基准模型，在将任务准确率提高多达 25% 的同时，还降低了 Token 和运行时间成本。这些结果表明，学习针对每个查询的智能体配置是替代“一刀切”设计的有力方案。

## Abstract
Configuring LLM-based agent systems involves choosing workflows, tools, token budgets, and prompts from a large combinatorial design space, and is typically handled today by fixed large templates or hand-tuned heuristics. This leads to brittle behavior and unnecessary compute, since the same cumbersome configuration is often applied to both easy and hard input queries. We formulate agent configuration as a query-wise decision problem and introduce ARC (Agentic Resource & Configuration learner), which learns a light-weight hierarchical policy using reinforcement learning to dynamically tailor these configurations. Across multiple benchmarks spanning reasoning and tool-augmented question answering, the learned policy consistently outperforms strong hand-designed and other baselines, achieving up to 25% higher task accuracy while also reducing token and runtime costs. These results demonstrate that learning per-query agent configurations is a powerful alternative to "one size fits all" designs.

### 1. 核心问题与整体含义（研究动机和背景）
当前的 LLM 智能体系统通常采用“一刀切”的设计模式：无论输入查询（Query）是简单（如“1+1”）还是复杂（如多步推理或需要联网搜索），系统都使用固定的工作流、全量的工具集和冗长的提示词模板。
*   **痛点：** 这种静态配置导致了**计算资源浪费**（简单任务消耗过多 Token）和**性能脆弱**（复杂任务可能因上下文过长导致“信息丢失”或逻辑混乱）。
*   **核心目标：** 将智能体配置建模为一个“按需分配”的决策问题，根据每个查询的难度和类型，动态选择最合适的工作流、工具、Token 预算和提示词。

### 2. 方法论：ARC 框架
ARC 的核心思想是利用**分层强化学习（Hierarchical RL）**来导航庞大的组合配置空间（超过 $10^5$ 种可能配置）。

*   **分层策略设计：**
    *   **高层结构策略 ($\pi_{struct}$)：** 决定“部署什么”。包括选择 9 种工作流模式（如直接回答、投票、评估-优化等）、开启哪些工具以及分配 Token 预算等级。
    *   **低层提示策略 ($\pi_{prompt}$)：** 决定“如何指令”。从预定义的原子指令库中选择并组合成针对特定智能体角色的系统提示词。
*   **关键技术细节：**
    *   **状态表示：** 使用 MetaCLIP 提取查询的语义嵌入，并结合查询长度、数值密度等手工特征。
    *   **奖励函数设计：** 采用塑造奖励（Shaped Reward），平衡任务准确性（正奖励）、步骤数和 Token 消耗（负惩罚），并加入“工具使用塑造”项，惩罚分配了工具却不使用或误用的行为。
    *   **动作掩码（Action Masking）：** 自动过滤掉逻辑上无效的配置组合（如单智能体流中分配多智能体预算），将搜索空间缩小了约 32.6%。
    *   **训练流程：** 先通过 PPO 算法进行强化学习探索，随后提取高奖励的“精英轨迹”进行**监督微调（SFT）**，以稳定策略并提供性能保障。

### 6. 主要结论与发现
*   **性能提升：** ARC 在 GSM8k 和 DROP 等任务上比强基准方法准确率提升了最高 **25%-31%**。
*   **成本效益：** ARC 成功位于 Pareto 前沿，证明了动态配置能显著减少不必要的 Token 消耗。
*   **跨规模迁移：** 在 7B 模型上训练的配置策略可以直接应用于 32B 和 72B 模型，且性能随模型规模增加而稳步提升，表现出极强的**结构不变性**。
*   **错误分析：** 发现策略配置错误率低于 10%，主要的失败原因仍在于底层 LLM 的推理能力限制或知识缺失。

### 7. 优点（亮点）
*   **分层决策：** 将复杂的配置问题分解为结构和提示两个层级，极大地提高了学习效率。
*   **轻量化：** 策略网络本身非常轻量，不需要微调庞大的底层 LLM，部署成本低。
*   **理论支撑：** 为 SFT 阶段提供了理论证明，确保了精炼后的策略具有性能下限保证。
*   **通用性：** 框架不依赖于特定模型，在开源（Qwen）和闭源（Gemini）模型上均有效。

### 8. 不足与局限
*   **领域知识限制：** 在 MedQA（医学）等高度依赖专业知识的任务中，ARC 的通用提示词库表现不如带有超长专业启发式提示词的 GEPA。
*   **工具迁移性：** 策略在不同任务间的迁移效果取决于工具集的重合度。如果新任务使用了完全不同的工具，策略需要重新训练。
*   **提示词库依赖：** 系统的上限受限于预定义的原子提示词库和工作流模板的丰富程度。
