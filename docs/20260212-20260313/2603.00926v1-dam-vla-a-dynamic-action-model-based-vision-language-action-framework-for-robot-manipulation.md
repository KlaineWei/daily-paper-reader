## 摘要
在仓库、医院和家庭等动态环境中，机器人必须在粗略运动和精确操作之间无缝切换，以完成复杂任务。然而，当前的视觉-语言-动作（VLA）框架大多改编自预训练的视觉-语言模型（VLM），往往难以在通用任务适应性与复杂操作所需的专门精度之间取得平衡。为了应对这一挑战，我们提出了 DAM-VLA，一种基于动态动作模型的 VLA 框架。DAM-VLA 将 VLM 推理与专门用于机械臂和夹持器控制的基于扩散的动作模型相结合。具体而言，它引入了：(i) 一种动作路由机制，利用特定任务的视觉和语言线索来选择合适的动作模型（例如，机械臂移动或夹持器操作）；(ii) 一种动态动作模型，融合了高层 VLM 认知与底层视觉特征以预测动作；以及 (iii) 一种双尺度动作加权机制，实现了机械臂移动模型与夹持器操作模型之间的动态协调。通过广泛的评估，DAM-VLA 在模拟环境（SIMPLER、FurnitureBench）和真实场景中均取得了优于现有最先进 VLA 方法的成功率，展示了从标准取放任务到具有挑战性的长时程和接触密集型任务的强大泛化能力。

## Abstract
In dynamic environments such as warehouses, hospitals, and homes, robots must seamlessly transition between gross motion and precise manipulations to complete complex tasks. However, current Vision-Language-Action (VLA) frameworks, largely adapted from pre-trained Vision-Language Models (VLMs), often struggle to reconcile general task adaptability with the specialized precision required for intricate manipulation. To address this challenge, we propose DAM-VLA, a dynamic action model-based VLA framework. DAM-VLA integrates VLM reasoning with diffusion-based action models specialized for arm and gripper control. Specifically, it introduces (i) an action routing mechanism, using task-specific visual and linguistic cues to select appropriate action models (e.g., arm movement or gripper manipulation), (ii) a dynamic action model that fuses high-level VLM cognition with low-level visual features to predict actions, and (iii) a dual-scale action weighting mechanism that enables dynamic coordination between the arm-movement and gripper-manipulation models. Across extensive evaluations, DAM-VLA achieves superior success rates compared to state-of-the-art VLA methods in simulated (SIMPLER, FurnitureBench) and real-world settings, showing robust generalization from standard pick-and-place to demanding long-horizon and contact-rich tasks.

在动态环境（如仓库、医院、家庭）中，机器人需要兼顾**大范围粗略运动（Arm Movement）**与**精细局部操作（Gripper Manipulation）**。
*   **现有问题：** 传统的视觉-语言-动作（VLA）模型（如 RT-2, OpenVLA）通常将动作离散化为 Token，难以达到精细操作所需的精度；而一些基于扩散模型的 VLA 虽然提高了精度，但往往将所有动作类型混为一谈，忽略了机械臂移动（依赖全局视觉、路径约束少）与夹持器操作（依赖局部视觉、约束严苛）在视觉关注点和数据分布上的本质差异。
*   **核心目标：** 提出 DAM-VLA 框架，通过动态路由机制，将 VLM 的高层推理能力与专门化的扩散动作模型相结合，实现通用任务适应性与高精度操作的统一。

### 2. 方法论
DAM-VLA 的核心思想是“分而治之”，其架构包含三个关键组件：
*   **动作路由机制（Action Routing）：** 利用 VLM 的推理潜变量（Reasoning Latent）预测一个权重 $w$。该权重决定当前状态属于“机械臂移动”还是“夹持器操作”，从而调用不同的动作分支。
*   **动态动作模型（Dynamic Action Model）：** 采用双头扩散变压器（DiT）结构。
    *   **移动模型：** 输入全局类别特征（Class Token），侧重全局场景理解。
    *   **操作模型：** 输入局部寄存器特征（Register Token），侧重精细局部特征。
    *   两者均结合了 VLM 提取的高层认知特征（Cognition Latent）作为条件。
*   **双尺度动作加权（Dual-Scale Action Weighting）：**
    *   **轨迹级权重（Trajectory-level）：** 在夹持器状态改变（开/关）附近使用非对称高斯分布加权，强化关键操作瞬间的监督。
    *   **动作块级权重（Action-chunk-level）：** 对预测序列应用指数衰减权重，优先保证近期动作的准确性。
*   **训练目标：** 联合优化分类损失（$L_{class}$）、移动损失（$L_{move}$）和操作损失（$L_{mani}$）。

### 3. 实验设计
*   **数据集：** 预训练使用 **Open X-Embodiment**（主要包含 Fractal 和 BridgeDataV2 子集）。
*   **模拟器 Benchmark：**
    *   **SIMPLER：** 评估 Google Robot 和 WidowX 机器人在视觉匹配（VM）和变体聚合（VA）设置下的表现。
    *   **FurnitureBench：** 评估长程、接触密集型的“单腿家具组装”任务。
*   **真实世界场景：** 使用 Franka 机器人在不同光照、背景、干扰物和未知物体下进行取放任务（Pick-and-place）。
*   **对比方法：** 包括 RT-1, RT-2-X, OpenVLA, Octo, CogACT, $\pi_0$, ECoT 等最先进的 VLA 模型。

### 4. 资源与算力
*   **硬件：** 使用了 **8 台 NVIDIA H100 GPU**。
*   **训练时长：** 预训练阶段耗时约 **2 天**。
*   **超参数：** 学习率恒定为 $2 \times 10^{-5}$，Batch Size 为 256。

### 5. 实验数量与充分性
*   **实验规模：** 涵盖了数千次模拟测试（SIMPLER 多个任务）和 80 次真实世界测试（包含 16 种不同工况）。
*   **消融实验：** 针对视觉 Token 类型、动作块加权、轨迹加权、动态动作模型分支以及双潜变量设计进行了详细的消融分析（共 7 组对比）。
*   **客观性：** 实验对比了多种 SOTA 模型，并在 VM（标准）和 VA（复杂变体）两种环境下测试，证明了模型在动态干扰下的鲁棒性，实验设计较为全面且公平。

### 6. 主要结论与发现
*   **性能领先：** DAM-VLA 在 SIMPLER 模拟器中取得了 81%-83% 的平均成功率，显著优于 CogACT (62%-72%) 和 OpenVLA (28%-37%)。
*   **长程任务优势：** 在复杂的家具组装任务中，DAM-VLA 在“拧螺丝”等接触密集型步骤上的表现远超基准模型。
*   **泛化能力：** 真实世界实验显示，DAM-VLA 在面对未见过的背景和物体（OOD 场景）时，成功率保持在 82.2%，表现出极强的泛化性能。
*   **路由有效性：** 区分移动和操作模型，并分别给予全局和局部视觉特征，是提升精细操作成功率的关键。

### 7. 优点
*   **架构创新：** 首次在 VLA 中引入基于 VLM 推理的动态动作路由，解决了单一模型难以兼顾全局移动与局部精细操作的矛盾。
*   **视觉特征精细化：** 巧妙利用 DINOv2 的 Class Token 和 Register Token 分别对应不同的动作需求。
*   **加权机制科学：** 双尺度加权机制符合机器人操作的物理直觉（即状态切换瞬间最关键，近期预测比远期预测更可靠）。

### 8. 不足与局限
*   **任务覆盖面：** 虽然涉及了家具组装，但实验仍主要集中在取放类任务，对于更复杂的双臂协作或非刚体操作（如布料、绳索）尚未验证。
*   **路由粒度：** 目前仅在“移动”和“操作”两个模型间路由，未来若面对更多样化的动作类型（如擦拭、切割、倾倒），可能需要更复杂的多分支路由信号。
*   **微小提升点：** 在某些特定任务（如“绿块叠黄块”）中，相比竞品的提升幅度相对较小，说明在极高精度的空间对齐上仍有优化空间。
