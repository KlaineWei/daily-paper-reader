## 摘要
大语言模型（LLMs）相比小语言模型（SLMs）展现出更优越的推理能力，但其成本也显著更高。我们提出了协作推理器（COllaborative REAsoner, COREA），这是一个将 SLM 与 LLM 级联的系统，旨在复杂推理任务中实现准确性与成本之间的平衡。COREA 首先尝试使用 SLM 回答问题，SLM 会同时输出答案和口头表达的置信度分数。置信度低于预定义阈值的问题将被转交给 LLM，以获得更准确的解答。我们引入了一种基于强化学习的训练算法，通过额外的置信度校准奖励来对齐 SLM 的置信度。广泛的实验表明，我们的方法在不同的数据集和模型骨干上共同提升了 SLM 的推理能力和置信度校准。与仅使用 LLM 相比，COREA 在域外数学和非数学数据集上分别降低了 21.5% 和 16.8% 的成本，而 pass@1 的绝对下降幅度在 2% 以内。

## Abstract
Large language models (LLMs) demonstrate superior reasoning capabilities compared to small language models (SLMs), but incur substantially higher costs. We propose COllaborative REAsoner (COREA), a system that cascades an SLM with an LLM to achieve a balance between accuracy and cost in complex reasoning tasks. COREA first attempts to answer questions using the SLM, which outputs both an answer and a verbalized confidence score. Questions with confidence below a predefined threshold are deferred to the LLM for more accurate resolution. We introduce a reinforcement learning-based training algorithm that aligns the SLM's confidence through an additional confidence calibration reward. Extensive experiments demonstrate that our method jointly improves the SLM's reasoning ability and confidence calibration across diverse datasets and model backbones. Compared to using the LLM alone, COREA reduces cost by 21.5% and 16.8% on out-of-domain math and non-math datasets, respectively, with only an absolute pass@1 drop within 2%.

### 1. 核心问题与整体含义（研究动机和背景）
论文针对大语言模型（LLM）在复杂推理任务中**性能卓越但推理成本极高**的问题展开研究。虽然小语言模型（SLM）成本低，但推理能力较弱且往往表现出“过度自信”（不知道自己不知道）。
*   **核心问题**：如何构建一个高效的协作系统，让 SLM 处理简单问题，并能准确识别自身局限，将难题动态委派给 LLM？
*   **研究背景**：现有的路由（Routing）方法多依赖外部分类器或简单的启发式规则，难以准确捕捉模型内部的推理置信度。

### 2. 方法论：COREA 框架
论文提出了 **COREA (COllaborative REAsoner)** 系统，其核心思想是通过强化学习（RL）训练一个具备“自我意识”的 SLM。

*   **核心思想**：采用级联架构。SLM 首先尝试回答并输出推理步骤、答案及一个**口头表达的置信度分数**（Verbalized Confidence Score）。若置信度 $\ge$ 阈值 $T$，则采用 SLM 结果；否则，将问题转交给 LLM。
*   **关键技术：带置信度校准的强化学习 (RLCC)**：
    *   使用 **GRPO**（Group Relative Policy Optimization）算法进行训练。
    *   **复合奖励函数**：$R = R_{correct} + R_{format} + R_{confidence}$。
        *   $R_{correct}$：答案正确性奖励（验证码/精确匹配）。
        *   $R_{format}$：格式奖励（确保输出符合指定的推理和置信度标签格式）。
        *   $R_{confidence}$：置信度校准奖励。其定义为置信度分数 $y_c$ 与实际正确概率 $p$ 之间的负距离。
    *   **概率估计**：由于单次采样的正确概率不可见，论文通过 GRPO 组内的平均准确率 $\hat{p}$ 来估计当前问题的正确概率。
    *   **距离度量**：对比了 L1、L2（Brier Score）和 KL 散度等多种度量方式，最终推荐 **L1 奖励**。

### 6. 主要结论与发现
*   **性能与成本平衡**：COREA 在域外数学和非数学任务上分别降低了 **21.5% 和 16.8%** 的成本，而 Pass@1 准确率的绝对下降控制在 **2%** 以内。
*   **双重提升**：RLCC 训练不仅显著提升了 SLM 的推理能力（如在 DeepMath500 上从 42.7% 提升至 56.6%），还大幅降低了预期校准误差（ECE）。
*   **自知之明**：经过校准的 SLM 能够有效识别难题。在相同准确率下，COREA 的成本效益显著优于使用外部路由模型或 Token 概率的方法。

### 7. 优点与亮点
*   **端到端校准**：无需额外的外部分类器或复杂的探测模型，直接利用模型自身的口头表达能力进行路由决策。
*   **奖励函数创新**：提出在 GRPO 组级别利用组准确率来估计概率 $p$，解决了强化学习中置信度难以量化的难题。
*   **高泛化性**：虽然只在数学数据上训练，但在科学（GPQA）和常识（CSQA）等非数学任务上依然表现出极强的校准能力。

### 8. 不足与局限
*   **置信度离散化**：尽管要求输出 0.0-1.0 的连续值，但模型输出往往集中在某些特定数值上，导致成本-准确率曲线不够平滑。
*   **训练稳定性**：在某些情况下，模型会在不同奖励项（推理 vs 校准）之间震荡，难以实现所有组件的同时最优收敛。
*   **成本增益依赖规模**：成本节省的幅度高度依赖于 SLM 和 LLM 之间的参数差距。如果 LLM 规模不够大，协作带来的边际收益会递减。
*   **小模型瓶颈**：实验发现 1.5B 级别的极小模型在“自我意识”校准上明显弱于 7B/8B 模型，存在能力下限。
