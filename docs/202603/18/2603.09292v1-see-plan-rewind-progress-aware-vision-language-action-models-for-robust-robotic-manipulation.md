## 摘要
通过明确且可操作的里程碑来衡量任务进度，对于鲁棒的机器人操控至关重要。这种进度感知能力使模型能够确定当前的任状态，预测可验证的中间状态，并在进度停滞时检测并从故障中恢复。为了实现这一能力，我们引入了“观察、规划、回溯”（See, Plan, Rewind，简称 SPR），这是一种进度感知的视觉-语言-动作框架，可将语言指令动态地映射为一系列空间子目标。SPR 通过一个持续的核心循环运行：观察（Seeing）当前状态和即将到来的里程碑，规划（Planning）通往下一个 2D 路径点的轨迹，并通过对照预期序列监控进度，在发生故障时回溯（Rewinding）到可恢复状态。这种闭环方法实现了鲁棒的错误修正，且无需额外的训练数据或辅助模型。大量实验证明了该框架的有效性、泛化性和鲁棒性：在 LIBERO 基准测试中，SPR 的表现优于 MolmoAct 基准模型 5%。在包含未见指令和初始状态的具有挑战性的 LIBERO-Plus 基准测试中，SPR 以最小的性能下降实现了最先进的鲁棒性，超越了 OpenVLA-OFT 和 UniVLA，展示了卓越的分布外鲁棒性。

## Abstract
Measurement of task progress through explicit, actionable milestones is critical for robust robotic manipulation. This progress awareness enables a model to ground its current task status, anticipate verifiable intermediate states, and detect and recover from failures when progress stalls. To embody this capability, we introduce See, Plan, Rewind (SPR), a progress-aware vision-language-action framework that dynamically grounds language instructions into a sequence of spatial subgoals. SPR operates through a continuous core cycle, Seeing the current state and upcoming milestone, Planning a trajectory towards the next 2D waypoint, and Rewinding to a recoverable state upon failure by monitoring progress against the expected sequence. This closed-loop approach enables robust error correction without requiring additional training data or auxiliary models. Extensive experiments demonstrate the framework's effectiveness, generalization and robustness: SPR outperforms the MolmoAct baseline by 5\% on the LIBERO benchmark. On the challenging LIBERO-Plus benchmark with unseen instructions and initial states, SPR achieves state-of-the-art robustness with the smallest performance drop, surpassing OpenVLA-OFT and UniVLA, demonstrating superior out-of-distribution robustness.

### 论文总结：See, Plan, Rewind (SPR) 框架

#### 1. 核心问题与整体含义（研究动机和背景）
在机器人操控领域，现有的视觉-语言-动作（VLA）模型虽然能执行基本任务，但在面对复杂、长程任务时缺乏**进度感知（Progress Awareness）**。这意味着机器人往往不知道自己完成了多少，也无法在发生碰撞、抓取失败或环境变化时自主恢复。现有的恢复机制通常依赖昂贵的额外故障数据收集或复杂的辅助模型。
**SPR 的核心动机**是赋予机器人类似人类的里程碑意识：通过将抽象指令分解为具体的、空间锚定的子目标，使机器人能够“看到”进度、“规划”路径，并在进度停滞时通过“回溯”机制自主纠正错误。

#### 2. 方法论：核心思想与关键技术
SPR 框架通过一个闭环的“观察-规划-回溯”循环运行：
*   **观察（See）：** 模型接收图像和指令，预测剩余子任务的数量，并为每个子任务生成语义描述和 2D 空间坐标（子目标）。
*   **规划（Plan）：** 模型不直接规划到最终目标，而是规划一条通往**下一个子任务路径点**的 2D 轨迹（包含 1-5 个坐标点），这为长程任务提供了更精确的引导。
*   **回溯（Rewind）：** 
    *   **异常检测：** 维护一个状态记录器。如果预测的子任务计数增加（表示倒退）或规划的轨迹在多个时间步内保持不变（表示陷入死循环或碰撞），则触发异常。
    *   **恢复策略：** 一旦检测到异常，模型会切换到“返回初始位置”指令（执行 $N=3$ 步），将机械臂撤回到分布内（in-distribution）的安全状态，然后重新尝试。
*   **自动化数据流水线：** 利用现有演示数据，通过机械爪状态（开/合）或多模态大模型（如 Gemini-3）自动标注子任务边界，并结合 DINOv3 和 SAM 提取机械爪的 2D 空间轨迹，无需人工干预。

#### 7. 优点与亮点
*   **无需额外故障数据：** 仅通过对成功演示数据的时序反转即可训练回溯能力，极大地降低了数据成本。
*   **显式空间接地：** 将进度监控从抽象的语言描述转变为可验证的 2D 坐标，提高了规划的确定性。
*   **闭环自纠错：** 引入状态记录器实现自主异常检测，使 VLA 模型具备了初步的“反思”和“重试”能力。

#### 8. 不足与局限
*   **离散动作限制：** 使用离散 Token 表示动作限制了毫米级的精细操控精度（如精准放置物体中心）。
*   **物理卡死无法处理：** 如果机器人发生物理上的严重卡死（如物体卡在缝隙中），单纯的逻辑回溯指令可能无法产生实际位移，导致恢复失败。
*   **动作与规划不一致：** 在某些极端情况下，模型预测的 2D 路径点是正确的，但生成的底层动作 Token 却未能准确遵循该路径（幻觉问题）。
