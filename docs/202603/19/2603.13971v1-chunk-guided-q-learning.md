## 摘要
在离线强化学习（RL）中，单步时序差分（TD）学习在长时程任务中可能会遭受自举误差累积的影响。动作分块 TD 方法通过跨多步进行回溯来缓解这一问题，但由于将策略类限制在开环动作序列中，可能会引入次优性。为了解决这一权衡，我们提出了块引导的 Q 学习（CGQ），这是一种单步 TD 算法，它通过将细粒度的单步评论家（critic）向使用时间扩展回溯训练的基于块的评论家进行正则化，从而引导前者。这在减少复合误差的同时，保留了细粒度的价值传播。我们在理论上证明，CGQ 比单独的单步或动作分块 TD 学习都能获得更紧致的评论家最优性界限。在实验上，CGQ 在具有挑战性的长时程 OGBench 任务中取得了强劲的性能，通常优于单步和动作分块方法。

## Abstract
In offline reinforcement learning (RL), single-step temporal-difference (TD) learning can suffer from bootstrapping error accumulation over long horizons. Action-chunked TD methods mitigate this by backing up over multiple steps, but can introduce suboptimality by restricting the policy class to open-loop action sequences. To resolve this trade-off, we present Chunk-Guided Q-Learning (CGQ), a single-step TD algorithm that guides a fine-grained single-step critic by regularizing it toward a chunk-based critic trained using temporally extended backups. This reduces compounding error while preserving fine-grained value propagation. We theoretically show that CGQ attains tighter critic optimality bounds than either single-step or action-chunked TD learning alone. Empirically, CGQ achieves strong performance on challenging long-horizon OGBench tasks, often outperforming both single-step and action-chunked methods.

### 论文总结：Chunk-Guided Q-Learning (CGQ)

#### 1. 核心问题与整体含义（研究动机和背景）
在离线强化学习（Offline RL）中，处理长时程（Long-horizon）任务一直是一个巨大挑战。
*   **单步 TD 学习的缺陷**：传统的单步时序差分（TD）学习依赖于自举（Bootstrapping），微小的估计误差会随着时间步的增加而迅速累积，导致在长路径任务中价值函数失效。
*   **动作分块（Action Chunking）的局限**：虽然通过动作分块（一次预测并执行序列动作）可以减少回溯深度，从而缓解误差累积，但它假设了“开环执行”，即在执行块内动作时无法根据环境变化做出反应。这限制了策略的精细化和轨迹拼接（Stitching）能力，往往导致次优解。
*   **研究动机**：能否在保留单步 TD 学习的精细化和最优性的同时，利用动作分块带来的长程稳定性？

#### 2. 方法论
论文提出了 **Chunk-Guided Q-Learning (CGQ)**，其核心思想是**利用一个辅助的“动作块评论家”来引导“单步评论家”的训练**。
*   **核心架构**：同时训练两个评论家网络。
    *   **动作块评论家 ($Q_{\phi_c}$)**：使用时间扩展的 TD 目标（$h$ 步回溯）进行训练，提供稳定的长程价值信号。
    *   **单步评论家 ($Q_\phi$)**：执行标准的单步 TD 更新，负责捕捉精细的、反应式的价值变化。
*   **关键技术：正则化引导**：
    *   通过一个正则化项 $L_{reg}$，将单步评论家向动作块评论家对齐。
    *   **公式细节**：使用**上分位数蒸馏损失（Upper-expectile distillation loss）**。这种非对称损失（参数 $\tau \ge 0.5$）使单步评论家倾向于向动作块评论家提供的较高价值估计靠拢，从而在减少复合误差的同时，避免被动作块评论家的次优性过度拖累。
*   **理论支撑**：论文证明了 CGQ 的误差界限比单纯的单步 TD 或动作块 TD 更紧致，揭示了偏差（来自块的次优性）与方差（来自单步的累积误差）之间的最优权衡。

#### 7. 优点
*   **平衡性强**：巧妙地结合了单步 TD 的精细化和动作块 TD 的稳定性，解决了离线 RL 中的核心权衡问题。
*   **理论扎实**：不仅有直观的动机，还提供了严谨的收敛误差界限证明。
*   **实现简单**：作为一种正则化手段，CGQ 易于集成到现有的离线 RL 框架（如 FQL）中。
*   **鲁棒性**：消融实验显示，CGQ 对分位数参数 $\tau$ 的选择具有较好的鲁棒性。

*   **超参数敏感性**：正则化权重 $\beta$ 对性能影响较大，且在不同任务间可能需要调整，缺乏自适应调整机制。
