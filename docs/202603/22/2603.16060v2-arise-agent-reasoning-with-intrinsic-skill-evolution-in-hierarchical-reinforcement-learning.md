## 摘要
提升语言模型数学推理能力的主流范式依赖于具有可验证奖励的强化学习。然而，现有方法孤立地处理每个问题实例，未能利用训练过程中出现并积累的可复用策略。为此，我们提出了 ARISE（通过内在技能演化的智能体推理），这是一个分层强化学习框架，其中共享策略既在顶层管理技能，又在底层生成响应（分别称为技能管理器和执行器）。管理器通过专门的技能生成展开（rollout）来维护分层技能库，该过程对成功的解题轨迹进行结构化总结（执行后），同时采用策略驱动的选择机制来检索相关技能，以约束未来的展开（执行前）。分层奖励设计引导了推理能力与技能库质量的协同演化。在两个基础模型和涵盖竞赛数学及 Omni-MATH 的七个基准测试上的实验表明，ARISE 一致优于 GRPO 系列算法和记忆增强基线，在分布外任务上的提升尤为显著。消融研究证实，每个组件都对观察到的改进有所贡献，且技能库质量和推理性能在整个训练过程中同步提升。代码可在 https://github.com/Skylanding/ARISE 获取。

## Abstract
The dominant paradigm for improving mathematical reasoning in language models relies on Reinforcement Learning with verifiable rewards. Yet existing methods treat each problem instance in isolation without leveraging the reusable strategies that emerge and accumulate during training. To this end, we introduce ARISE (Agent Reasoning via Intrinsic Skill Evolution), a hierarchical reinforcement learning framework, in which a shared policy operates both to manage skills at high-level and to generate responses at low-level (denoted as a Skills Manager and a Worker, respectively). The Manager maintains a tiered skill library through a dedicated skill generation rollout that performs structured summarization of successful solution traces (after execution), while employing a policy-driven selection mechanism to retrieve relevant skills to condition future rollouts (before execution). A hierarchical reward design guides the co-evolution of reasoning ability and library quality. Experiments on two base models and seven benchmarks spanning both competition mathematics and Omni-MATH show that ARISE consistently outperforms GRPO-family algorithms and memory-augmented baselines, with particularly notable gains on out-of-distribution tasks. Ablation studies confirm that each component contributes to the observed improvements and that library quality and reasoning performance improve in tandem throughout training. ### 1. 核心问题与研究动机
*   **核心问题**：当前的语言模型（LLM）数学推理强化学习（RL）范式（如 GRPO）通常孤立地处理每个问题。模型在训练过程中产生的成功解题策略（Skills）在单次迭代后即被丢弃，无法积累并复用于后续类似或更难的问题。
*   **研究动机**：现有的“记忆增强”或“技能库”方法通常依赖外部检索器或独立于 RL 目标的更新机制，导致技能选择无法直接通过策略梯度进行优化，且技能库的演化与策略改进之间存在脱节。

### 2. 方法论
ARISE 提出了一个**分层强化学习框架**，将技能库视为智能体状态的内在组成部分，实现“策略-技能库”的协同演化。
*   **核心思想**：使用单个共享策略 $\pi_\theta$ 同时扮演**技能管理器（Manager）**和**执行者（Worker）**。
*   **关键技术细节**：
    *   **演化技能 MDP (ES-MDP)**：将技能库 $M$ 纳入 MDP 状态空间，定义了技能管理动作（添加、更新、淘汰等）。
    *   **策略驱动的技能选择（Download）**：管理器不使用外部检索器，而是根据策略自身的条件对数概率（Log-probability）对候选技能进行评分，通过 $\epsilon$-greedy 机制选择技能。
    *   **结构化技能生成（Upload）**：在标准的 $G$ 个解题展开之外，增加一个专门的展开步骤 $O_{G+1}$，将该轮成功的解题轨迹总结为符合 JSON 模式的结构化技能文档。
    *   **分层奖励设计**：引入三级奖励 $R \in \{0, 1, 2\}$。其中 $R=2$ 奖励“使用技能且解题正确”，$R=1$ 奖励“未使用技能但解题正确”，$R=0$ 为错误。这种设计通过组相对优势（Group Relative Advantage）迫使策略偏好使用有效的技能。
    *   **两层库架构**：维护一个紧凑的**缓存（Cache）**用于实时选择，以及一个较大的**水库（Reservoir）**用于存储备选技能，通过五种管理操作（Add, Update, Evict, Load, Delete）维持质量。
*   **算法流程**：分为两个阶段。**阶段 I（预热）**：构建基础策略并初步填充技能库；**阶段 II（技能增强）**：激活全流程分层强化学习，联合优化策略与技能库。

*   **性能领先**：ARISE 在所有基准测试中均优于 GRPO 系列和现有的记忆增强方法。在 Qwen3-4B 上，Omni-MATH 的平均准确率提升了 **2.9%**。

### 7. 优点
*   **内生性设计**：将技能管理完全整合进策略参数中，使技能选择可直接受梯度引导，解决了外部检索器不可导的问题。
*   **分层奖励创新**：通过简单的奖励分级成功引导模型产生“主动使用工具/策略”的自觉性。
*   **结构化约束**：通过严格的 JSON Schema 和长度限制，确保了技能库的整洁和评分的公平性。

### 8. 不足与局限
*   **计算开销**：虽然在可接受范围内，但额外的 $O_{G+1}$ 展开和每步的技能评分确实增加了训练和推理的时间成本。
*   **任务局限**：目前仅在数学推理任务上进行了验证。在代码生成或多步骤工具调用等其他智能体任务上的有效性尚待证明。
