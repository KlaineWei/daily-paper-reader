## 摘要
大语言模型（LLMs）近期在推荐系统领域获得了越来越多的关注。现有的基于 LLM 的方法通常将物品表示为 Token 序列，并在这些 Token 上应用注意力层以生成推荐。然而，由于继承了标准的注意力机制，这些方法侧重于建模 Token 级别的关系。这种以 Token 为中心的关注点忽略了物品作为推荐基本单元的角色，导致现有方法无法有效捕捉物品级别的协同关系。在本研究中，我们重新审视了 Token 在 LLM 驱动的推荐中的作用，并将其关系分为两类：（1）物品内 Token 关系，用于呈现物品的内容语义（如名称、颜色和尺寸）；（2）物品间 Token 关系，用于编码物品间的协同关系。基于这些见解，我们提出了一种具有物品感知注意力机制（IAM）的新型框架，以增强 LLM 在推荐中的表现。具体而言，IAM 设计了两个互补的注意力层：（1）物品内注意力层，将注意力限制在同一物品内的 Token，建模物品内容语义；（2）物品间注意力层，专门关注跨物品的 Token 关系，捕捉物品协同关系。通过这种堆叠设计，IAM 明确强调了物品作为推荐基本单元的地位，使 LLM 能够有效利用物品级的协同关系。在多个公开数据集上的广泛实验证明了 IAM 在增强 LLM 进行个性化推荐方面的有效性。

## Abstract
Large Language Models (LLMs) have recently gained increasing attention in the field of recommendation. Existing LLM-based methods typically represent items as token sequences, and apply attention layers on these tokens to generate recommendations. However, by inheriting the standard attention mechanism, these methods focus on modeling token-level relations. This token-centric focus overlooks the item as the fundamental unit of recommendation, preventing existing methods from effectively capturing collaborative relations at the item level. In this work, we revisit the role of tokens in LLM-driven recommendation and categorize their relations into two types: (1) intra-item token relations, which present the content semantics of an item, e.g., name, color, and size; and (2) inter-item token relations, which encode collaborative relations across items. Building on these insights, we propose a novel framework with an item-aware attention mechanism (IAM) to enhance LLMs for recommendation. Specifically, IAM devises two complementary attention layers: (1) an intra-item attention layer, which restricts attention to tokens within the same item, modeling item content semantics; and (2) an inter-item attention layer, which attends exclusively to token relations across items, capturing item collaborative relations. Through this stacked design, IAM explicitly emphasizes items as the fundamental units in recommendation, enabling LLMs to effectively exploit item-level collaborative relations. Extensive experiments on several public datasets demonstrate the effectiveness of IAM in enhancing LLMs for personalized recommendation.

### 1. 核心问题与研究动机
*   **核心问题**：现有的基于大语言模型（LLM）的推荐系统直接继承了自然语言处理中的**标准注意力机制**，这种机制是“以 Token 为中心”的。
*   **研究动机**：在推荐场景中，**物品（Item）**才是基本建模单元。标准注意力机制模糊了物品的边界，仅建模 Token 间的关系，导致模型难以有效捕捉物品层面的**协同过滤信息（Collaborative Information）**。
*   **核心思路**：将 Token 间的关系重新定义为“物品内（Intra-item）”和“物品间（Inter-item）”两类，通过改进注意力掩码（Mask），迫使 LLM 从 Token 级建模转向物品级建模。

### 2. 方法论：物品感知注意力机制 (IAM)
IAM 框架通过修改 LLM 内部的因果注意力掩码，设计了两个交替堆叠的层：
*   **物品内注意力层 (Intra-item Attention Layer)**：
    *   **逻辑**：限制 Token 只能关注属于同一个物品的其他 Token。
    *   **作用**：建模物品的内容语义（如标题中的名称、属性），并将物品视为独立的语义单元。
    *   **细节**：放宽了因果约束，允许物品内部 Token 双向交互以增强语义表示。
*   **物品间注意力层 (Inter-item Attention Layer)**：
    *   **逻辑**：限制 Token 只能关注属于**不同**物品的 Token，屏蔽同一物品内部的交互。
    *   **作用**：显式捕捉物品与物品之间的协同关系（如共现模式）。
    *   **细节**：同样采用双向交互，从多个视角（每个 Token 作为一个视角）建模物品间的依赖。
*   **预测层**：采用**基于评分（Score-based）**的范式，在 LLM 顶部添加一个线性适配器（Recommendation Adapter），将输出映射到全量物品集上进行排名，避免了生成式方法可能产生的幻觉问题。

### 6. 主要结论与发现
*   **性能提升**：IAM 在所有指标上均显著优于基准模型，平均提升幅度达 **34.54%**。
*   **物品级建模的重要性**：消融实验证明，单独使用物品内或物品间注意力层效果均不如 IAM，且先建模物品内语义、再建模物品间协同关系的顺序最为有效。
*   **LLM 潜力**：即使不使用复杂的协同嵌入（如 LLaRA 所需的预训练模型），仅通过结构化的注意力调整，LLM 也能展现出极强的推荐能力。
*   **稳定性**：IAM 在不同规模的 Llama 模型上表现稳定，且随着模型深度增加，性能有进一步提升的趋势。

### 7. 优点与亮点
*   **视角新颖**：首次指出 LLM 推荐中“Token 级建模”与“物品级推荐”之间的结构性失配问题。
*   **设计优雅**：无需引入额外的外部协同模型（如 SASRec 预训练嵌入）或复杂的 ID 索引规则，仅通过修改注意力掩码即可实现性能飞跃。
*   **实用性强**：采用评分制而非生成制，解决了 LLM 在推荐中容易产生非法输出（幻觉）的痛点，且支持全量排名。

### 8. 不足与局限
*   **模态局限**：目前主要依赖物品标题（文本），尚未整合图像、视频等多模态信息。
*   **计算开销**：尽管使用了 LoRA，但 LLM 作为推荐骨干网络的推理延迟和显存占用仍远高于 SASRec 等轻量级神经模型，在大规模工业级实时推荐中可能面临挑战。
*   **场景覆盖**：实验主要集中在序列推荐（Sequential Recommendation），对于冷启动、跨域推荐等复杂场景的验证尚不充分。
