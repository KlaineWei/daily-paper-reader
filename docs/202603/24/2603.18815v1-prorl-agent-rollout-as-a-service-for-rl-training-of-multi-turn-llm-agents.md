## 摘要
多轮大语言模型（LLM）智能体在解决复杂的交互式任务中变得日益重要，而强化学习（RL）是改善其长程行为的关键要素。然而，强化学习训练需要生成大量的沙箱化展开轨迹（rollout trajectories），现有的基础设施往往将展开编排与训练循环耦合，导致系统难以迁移和维护。基于“展开即服务”（rollout-as-a-service）的理念，我们提出了 ProRL Agent，这是一个可扩展的基础设施，通过 API 服务支持完整的智能体展开生命周期。ProRL Agent 还提供了标准化且可扩展的沙箱环境，支持在无 root 权限的高性能计算（HPC）环境下的多种智能体任务。我们通过在软件工程、数学、STEM 和编程任务上的强化学习训练验证了 ProRL Agent。ProRL Agent 已开源，并作为 NVIDIA NeMo Gym 的一部分进行了集成。

## Abstract
Multi-turn LLM agents are increasingly important for solving complex, interactive tasks, and reinforcement learning (RL) is a key ingredient for improving their long-horizon behavior. However, RL training requires generating large numbers of sandboxed rollout trajectories, and existing infrastructures often couple rollout orchestration with the training loop, making systems hard to migrate and maintain. Under the rollout-as-a-service philosophy, we present ProRL Agent , a scalable infrastructure that serves the full agentic rollout lifecycle through an API service. ProRL Agent also provides standardized and extensible sandbox environments that support diverse agentic tasks in rootless HPC settings. We validate ProRL Agent through RL training on software engineering, math, STEM, and coding tasks. ProRL Agent is open-sourced and integrated as part of NVIDIA NeMo Gym.

随着大语言模型（LLM）从单轮对话转向复杂的多轮智能体（Agent）任务（如软件工程、网页浏览、系统操作），强化学习（RL）成为提升其长程规划能力的关键。然而，现有的智能体 RL 训练框架存在一个核心瓶颈：**轨迹生成（Rollout）与策略训练（Training）逻辑紧密耦合**。
*   **资源冲突**：Rollout 是 I/O 密集型（涉及沙箱创建、工具调用、异步协调），而训练是 GPU 密集型。耦合设计导致资源利用率低。
*   **维护困难**：迁移训练后端通常需要重写整个智能体执行流水线。
*   **环境限制**：现有沙箱多依赖 Docker，在缺乏 root 权限的高性能计算（HPC）集群中难以部署。
**核心目标**：提出“Rollout即服务”（Rollout-as-a-Service）理念，将轨迹生成的全生命周期解耦为独立服务。

#### 2. 论文提出的方法论
论文提出了 **ProRL Agent** 架构，其核心思想是通过解耦提高系统的可移植性、可扩展性和效率。
*   **Rollout-as-a-Service (RaaS)**：训练器通过 HTTP API 提交任务，ProRL Agent 服务器负责环境初始化、智能体执行和结果评估，最后返回带有奖励信号的完整轨迹。
*   **三阶段异步流水线**：
    1.  **INIT**：初始化沙箱环境（I/O 密集）。
    2.  **RUN**：驱动智能体与环境交互，调用 LLM 推理（推理密集）。
    3.  **EVAL**：根据执行结果计算奖励（计算密集）。
    每个阶段拥有独立的线程池，实现任务重叠执行。
*   **关键技术细节**：
    *   **HPC 原生沙箱**：基于 Singularity 实现无 root 权限的容器化，支持模拟 root 访问和独立 IP 分配。

    *   **异步 DAPO 调度**：优化动态采样策略优化（DAPO），支持任务的异步补充和过期任务清理。
