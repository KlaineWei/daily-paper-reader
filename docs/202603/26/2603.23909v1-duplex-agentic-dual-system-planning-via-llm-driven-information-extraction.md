## 摘要
虽然大语言模型（LLMs）为机器人任务规划提供了语义灵活性，但它们易受幻觉和逻辑不一致性的影响，限制了其在长程领域中的可靠性。为了弥合非结构化环境与严谨规划合成之间的差距，我们提出了 DUPLEX，这是一种智能体双系统神经符号架构，它严格将 LLM 限制在模式引导的信息提取任务中，而非端到端规划或代码生成。在我们的框架中，前馈快系统（Fast System）利用轻量级 LLM 从自然语言中提取实体、关系等，并将其确定性地映射到经典符号规划器的规划领域定义语言（PDDL）问题文件中。为了解决复杂或描述不足的场景，慢系统（Slow System）仅在规划失败时激活，利用求解器的诊断信息驱动高容量 LLM 进行迭代反思与修复。在 12 个经典和家庭规划领域进行的广泛评估表明，DUPLEX 在成功率和可靠性方面均显著优于现有的端到端和混合 LLM 基准。这些结果证实，关键不在于让 LLM 更好地进行规划，而是将 LLM 限制在它擅长的部分——结构化语义落地（structured semantic grounding）——并将逻辑规划合成留给符号规划器。

## Abstract
While Large Language Models (LLMs) provide semantic flexibility for robotic task planning, their susceptibility to hallucination and logical inconsistency limits their reliability in long-horizon domains. To bridge the gap between unstructured environments and rigorous plan synthesis, we propose DUPLEX, an agentic dual-system neuro-symbolic architecture that strictly confines the LLM to schema-guided information extraction rather than end-to-end planning or code generation. In our framework, a feed-forward Fast System utilizes a lightweight LLM to extract entities, relations etc. from natural language, deterministically mapping them into a Planning Domain Definition Language (PDDL) problem file for a classical symbolic planner. To resolve complex or underspecified scenarios, a Slow System is activated exclusively upon planning failure, leveraging solver diagnostics to drive a high-capacity LLM in iterative reflection and repair. Extensive evaluations across 12 classical and household planning domains demonstrate that DUPLEX significantly outperforms existing end-to-end and hybrid LLM baselines in both success rate and reliability. These results confirm that The key is not to make the LLM plan better, but to restrict the LLM to the part it is good at - structured semantic grounding - and leave logical plan synthesis to a symbolic planner.

*   **核心问题**：具身智能体在长程（Long-horizon）任务规划中面临“语义灵活性”与“逻辑严谨性”的矛盾。
*   **研究动机**：
    *   **经典符号规划器（如 PDDL 求解器）**：逻辑严谨、可验证，但存在“知识获取瓶颈”，难以将非结构化的现实环境直接转化为严苛的符号表示。
    *   **大语言模型（LLM）**：具备极强的常识推理和语义理解能力，但在长程规划中极易产生幻觉、违反物理约束或逻辑不一致。
    *   **现有混合方法（如 LLM+P）**：尝试让 LLM 直接编写 PDDL 代码，但这要求 LLM 必须生成完美的语法和逻辑，极其脆弱且易出错。
*   **整体含义**：论文主张不应让 LLM 直接做规划或写代码，而应将其限制在它最擅长的任务——**模式引导的信息提取（IE）**，而将逻辑合成留给确定性的符号规划器。

### 2. 方法论
DUPLEX 提出了一种受认知科学“双系统理论”启发的神经符号架构：

*   **核心思想**：将规划过程分解为“非结构化输入 → 信息提取 → 确定性 PDDL 映射 → 符号求解”。
*   **快系统（Fast System - 前馈路径）**：
    1.  **引导式信息提取**：使用轻量级 LLM（如 Qwen3-8B）根据预定义的 Schema（来自 Domain PDDL）从环境描述中提取实体、关系和状态，输出结构化的 JSON。
    2.  **确定性映射**：通过预编写的脚本将 JSON 数据填入 PDDL 模板。这保证了 **100% 的语法正确性**，消除了 LLM 生成代码时的语法错误。
    3.  **符号求解**：调用 Fast Downward 等规划器生成动作序列。
*   **慢系统（Slow System - 智能体反思）**：
    *   **触发机制**：仅在快系统规划失败（如求解器返回“无解”或“语法错误”）时激活。
    *   **反思修复**：调用高容量 LLM（如 GPT-4o）作为诊断智能体，分析规划器的错误日志，识别缺失的隐式状态或语义错误，迭代修改 PDDL 问题文件直至成功。
*   **分层验证机制**：
    *   L1：规则验证（检查 JSON 完整性）。
    *   L2：语义验证（纠正幻觉或缺失实体）。
    *   L3：逻辑反思（基于规划器反馈推断隐式物理约束）。

*   **基准模型（Benchmarks）**：

    *   **LLM+P**：GPT-4o 直接将自然语言翻译为 PDDL 代码并求解。
*   **对比指标**：成功率（Success Rate, SR）。

### 5. 实验数量与充分性
*   **实验规模**：涵盖了 12 个不同的规划领域，总计进行了数百次独立任务测试（仅家庭领域就进行了 600 次试验）。
*   **消融实验**：专门对比了“仅快系统”与“完整 DUPLEX 系统”的表现，验证了反思机制的增益。

### 6. 主要结论与发现
*   **性能飞跃**：DUPLEX 在 IPC 领域的平均成功率达到 **97.5%**（远超 LLM+P 的 71.9% 和 LLM-as-Planner 的 11.9%）；在家庭领域达到 **83.5%**。

*   **小模型潜力**：通过将任务简化为信息提取，轻量级模型（8B）在快系统中表现优异，降低了系统常态运行的延迟和成本。

### 7. 优点
*   **架构解耦**：成功分离了“语义理解”与“逻辑合成”，让 LLM 和符号系统各司其职。
*   **鲁棒性极高**：通过确定性映射脚本解决了 LLM 生成 PDDL 语法不规范的顽疾。
*   **高效节能**：双系统设计使得大部分简单任务由小模型快速完成，仅在必要时调用大模型。

### 8. 不足与局限
*   **依赖先验知识**：系统仍假设可以获得人工编写的 Domain PDDL 文件（动作定义、谓词等），尚未实现完全自动化的领域建模。
*   **实时性挑战**：慢系统的迭代反思循环会引入额外延迟，可能不适用于对实时响应要求极高的动态环境。
*   **模态限制**：目前主要依赖文本提取，在视觉信息极其丰富且存在指代歧义的真实场景中，纯文本提取可能存在瓶颈。
