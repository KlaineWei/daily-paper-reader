## 摘要
机器人操作通常需要记忆：遮挡和状态变化可能导致决策时的观测产生感知混淆，使得动作选择在观测层面呈现非马尔可夫特性，因为相同的观测可能源于不同的交互历史。大多数具身智能体通过语义压缩的轨迹和基于相似性的检索来实现记忆，这丢弃了用于消除歧义的细粒度感知线索，并可能返回感知上相似但与决策无关的情节。受人类情景记忆的启发，我们提出了 Chameleon，它通过写入基于几何定位的多模态 Token 来保留消除歧义的上下文，并通过可微记忆栈实现目标导向的回忆。我们还推出了 Camo-Dataset，这是一个涵盖感知混淆下的情景回忆、空间追踪和序列化操作的真实 UR5e 机器人数据集。在各项任务中，Chameleon 在感知易混淆的场景下，相较于强基线方法，一致地提高了决策可靠性和长程控制能力。

## Abstract
Robotic manipulation often requires memory: occlusion and state changes can make decision-time observations perceptually aliased, making action selection non-Markovian at the observation level because the same observation may arise from different interaction histories. Most embodied agents implement memory via semantically compressed traces and similarity-based retrieval, which discards disambiguating fine-grained perceptual cues and can return perceptually similar but decision-irrelevant episodes. Inspired by human episodic memory, we propose Chameleon, which writes geometry-grounded multimodal tokens to preserve disambiguating context and produces goal-directed recall through a differentiable memory stack. We also introduce Camo-Dataset, a real-robot UR5e dataset spanning episodic recall, spatial tracking, and sequential manipulation under perceptual aliasing. Across tasks, Chameleon consistently improves decision reliability and long-horizon control over strong baselines in perceptually confusable settings.

#### 1. 核心问题与研究动机
*   **核心问题**：机器人操作中的“感知混淆”（Perceptual Aliasing）问题。在长程任务中，由于遮挡或状态变化，当前的观测可能无法提供足够的信息来决定下一步动作（即非马尔可夫性）。例如，在“三杯球”游戏中，多个杯子外观完全相同，机器人必须依靠历史记忆才能确定球在哪个杯子下。
*   **研究动机**：现有的具身智能体记忆机制多采用语义压缩（如文本摘要）或基于相似性的检索（RAG）。这种方式会丢失细粒度的感知线索（如空间关系、视角细节），且容易检索出感知相似但决策无关的错误片段。
*   **研究目标**：受人类“内嗅皮层-海马体-前额叶皮层”（EC-HC-PFC）情景记忆系统的启发，构建一种能够保留几何细节并实现目标导向检索的记忆架构。

#### 2. 核心方法论
Chameleon 采用“感知 $\rightarrow$ 记忆 $\rightarrow$ 策略”的闭环架构：
*   **几何定位感知（Perception）**：
    *   **双流编码**：腹侧流（Ventral）提取 DINOv2 图像特征；背侧流（Dorsal）提取以末端执行器（EE）为锚点的几何描述符。
    *   **几何偏置注意力**：利用对极几何（Epipolar Geometry）约束和末端执行器位置，引导多视角（前视和手眼相机）之间的特征融合，减少感知歧义。
*   **分层情景记忆栈（Memory）**：
    *   **时空锚点**：将多模态 Token 分解为 A 个空间锚点和 B 个时间槽位，模拟海马体的模式分离（Pattern Separation）。
    *   **可微动力学**：使用选择性状态空间模型（SSM，类似 Mamba）来维护情景状态（慢速更新）和工作状态（快速更新）。
    *   **HoloHead（潜在想象）**：通过预测未来 2D/3D 路径点（Waypoints）来训练记忆状态，强制其具备“模式补全”（Pattern Completion）能力，确保检索与目标相关。
*   **整流流匹配策略（Policy）**：
    *   基于条件流匹配（Conditional Flow Matching, CFM）生成末端执行器的未来姿态轨迹，相比单步预测更具稳定性。

#### 3. 实验设计
*   **数据集/场景**：推出了 **Camo-Dataset**，包含在真实 UR5e 机器人上收集的 120 个演示视频。
*   **任务分类**：
    1.  **情景回忆**：清理指定盘子（识别曾被污染但外观相同的盘子）。
    2.  **空间追踪**：三杯球游戏（追踪移动后的目标杯子）。
    3.  **顺序操作**：按序添加三种调料（需记忆已完成的步骤）。
*   **对比基准（Benchmarks）**：
    *   **Diffusion Policy**（扩散策略）
    *   **Flow Matching**（流匹配）
    *   **ACT**（动作分块 Transformer）
*   **消融实验**：对比了无记忆、基于记忆库检索、纯 Mamba 架构、无背侧流、无 HoloHead 等 5 种变体。

#### 4. 资源与算力
*   **硬件**：单张 **NVIDIA RTX 4090 GPU**。
*   **训练时长**：每个任务训练 20,000 步。
*   **推理性能**：端到端推理延迟平均为 **82ms**，支持实时操作。
*   **参数量**：可训练参数约为 **49.89M**（不含冻结的 DINOv2 权重）。

#### 5. 实验数量与充分性
*   **实验规模**：每个任务类别进行了 36 次独立的真实机器人测试，总计超过 100 次实机评估。
*   **充分性**：实验涵盖了决策成功率（DSR）、操作成功率（MSR）和整体成功率（SR）等多个维度，并引入了 Cohen’s kappa 系数来排除随机猜测的影响。
*   **客观性**：通过消融实验逐一验证了背侧流、分层记忆结构和 HoloHead 的必要性，实验设计较为严谨、公平。

#### 6. 主要结论与发现
*   **性能领先**：Chameleon 在所有记忆密集型任务中显著优于强基线模型，尤其是在感知混淆严重的决策点上，决策成功率（DSR）提升巨大。
*   **记忆表征**：通过 UMAP 可视化发现，Chameleon 的记忆状态 $h_t$ 能够有效分离感知相似但历史不同的状态（模式分离），并在缺乏即时线索时通过内部动力学补全目标信息（模式补全）。
*   **几何重要性**：背侧流提供的几何约束对于空间追踪任务至关重要，移除后成功率大幅下降。

#### 7. 论文亮点
*   **生物启发**：将神经科学中的情景记忆机制（EC-HC-PFC）成功转化为可计算的工程架构。
*   **解决感知混淆**：针对机器人领域长期存在的非马尔可夫决策难题，提供了有效的几何定位记忆方案。
*   **实机验证**：所有实验均在真实物理机器人上完成，而非仅限于仿真环境，具有较强的实用价值。
