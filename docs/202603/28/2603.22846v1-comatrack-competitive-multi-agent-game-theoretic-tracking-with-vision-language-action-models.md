## 摘要
具身视觉追踪（EVT）是具身智能中的核心动态任务，要求智能体精确跟随语言指定的目标。然而，大多数现有方法依赖于单智能体模仿学习，面临专家数据成本高昂以及由于静态训练环境导致的泛化能力有限的问题。受竞争驱动的能力演化启发，我们提出了 CoMaTrack，这是一个竞争性博弈论多智能体强化学习框架，在具有竞争性子任务的动态对抗设置中训练智能体，从而产生更强的自适应规划和抗干扰策略。我们进一步推出了 CoMaTrack-Bench，这是首个竞争性 EVT 基准测试，其特点是追踪器与自适应对手在不同环境和指令下的博弈场景，实现了主动对抗交互下的标准化鲁棒性评估。实验表明，CoMaTrack 在标准基准测试和 CoMaTrack-Bench 上均达到了最先进的结果。值得注意的是，使用我们框架训练的 3B VLM 在具有挑战性的 EVT-Bench 上超过了之前基于 7B 模型的单智能体模仿学习方法，在 STT、DT 和 AT 指标上分别达到了 92.1%、74.2% 和 57.5%。基准测试代码将在 https://github.com/wlqcode/CoMaTrack-Bench 提供。

## Abstract
Embodied Visual Tracking (EVT), a core dynamic task in embodied intelligence, requires an agent to precisely follow a language-specified target. Yet most existing methods rely on single-agent imitation learning, suffering from costly expert data and limited generalization due to static training environments. Inspired by competition-driven capability evolution, we propose CoMaTrack, a competitive game-theoretic multi-agent reinforcement learning framework that trains agents in a dynamic adversarial setting with competitive subtasks, yielding stronger adaptive planning and interference-resilient strategies. We further introduce CoMaTrack-Bench, the first benchmark for competitive EVT, featuring game scenarios between a tracker and adaptive opponents across diverse environments and instructions, enabling standardized robustness evaluation under active adversarial interactions. Experiments show that CoMaTrack achieves state-of-the-art results on both standard benchmarks and CoMaTrack-Bench. Notably, a 3B VLM trained with our framework surpasses previous single-agent imitation learning methods based on 7B models on the challenging EVT-Bench, achieving 92.1% in STT, 74.2% in DT, and 57.5% in AT. The benchmark code will be available at https://github.com/wlqcode/CoMaTrack-Bench

### CoMaTrack：基于视觉-语言-动作模型的竞争性多智能体博弈论追踪总结

#### 1. 核心问题与研究动机
*   **核心问题**：具身视觉追踪（EVT）要求智能体根据语言指令在复杂动态环境中持续跟随目标。现有方法主要依赖**单智能体模仿学习（IL）**，存在专家数据获取成本高、在静态训练环境下泛化性差、难以应对主动干扰或目标逃逸等问题。
*   **研究动机**：受生物竞争进化启发，作者认为能力的快速演化往往源于持续的竞争。通过引入对抗性对手，可以动态增加任务难度，迫使追踪智能体学习更具鲁棒性的预测、规划和重定位策略，从而打破静态数据分布的限制。

#### 2. 方法论
*   **核心思想**：将 EVT 任务建模为追踪者（Tracker）与对手（Opponent）之间的**竞争性博弈**，利用多智能体强化学习（MARL）构建一个自我进化的训练循环。
*   **关键技术细节**：
    *   **模型架构**：采用端到端的 VLA 架构，以 **Qwen2.5VL-3B** 为骨干网络，结合**流匹配（Flow-matching）**动作模块预测未来 5 步的连续航路点（Waypoints）。
    *   **两阶段训练**：
        1.  **监督微调（SFT）**：在多任务导航、追踪和 VQA 数据集上进行预训练，建立基础的感知与行动能力。
        2.  **多智能体强化学习（RL）**：使用 **GRPO（组相对策略优化）** 算法。追踪者和对手共享模型权重（初始由 SFT 提供），但在环境中扮演不同角色。
    *   **非对称奖励设计**：
        *   **追踪者奖励**：鼓励保持安全跟随距离（1-3m）、面向目标并避免碰撞。
        *   **对手奖励**：鼓励更近距离地接近目标（如 1.25m），从而产生遮挡、路径交叉和物理阻挡，形成对抗。
    *   **KL 散度约束**：在 RL 阶段引入 KL 惩罚，防止模型偏离 SFT 阶段习得的基础知识。

#### 3. 实验设计
*   **数据集与场景**：
    *   **训练数据**：包含来自 HM3D 和 MP3D 场景的约 2 万个追踪回合，以及大规模 VQA 和多任务导航数据。
    *   **标准基准（EVT-Bench）**：评估单目标追踪（STT）、干扰追踪（DT）和歧义追踪（AT）。
    *   **新基准（CoMaTrack-Bench）**：本文提出的首个竞争性 EVT 基准，包含三种对手行为：静态障碍、随机干扰和竞争性追踪。
*   **对比方法**：对比了 IBVS、Uni-NaVid、TrackVLA、TrackVLA++ 等多种 SOTA 模型，涵盖了从 3B 到 7B 不同参数规模的方法。

#### 4. 资源与算力
*   **SFT 阶段**：使用 **48 张 NVIDIA H20 GPU** 集群进行 1 个 epoch 的全参数/投影层微调。
*   **RL 阶段**：使用 **4 张 NVIDIA L20 GPU** 进行 1 个 epoch 的训练，仅对 LLM 部分应用 LoRA 适配器。
*   **推理与部署**：在真机部署（Unitree Go2 X 机器人）中，使用远程 **NVIDIA RTX 4090 GPU** 进行模型推理。

#### 5. 实验数量与充分性
*   **实验规模**：论文在 EVT-Bench 的三个子任务上进行了全面测试，并在新提出的 CoMaTrack-Bench 上进行了零样本（Zero-shot）性能评估。
*   **消融实验**：对比了“仅 SFT”、“单智能体 RL”与“多智能体 RL”的效果，验证了竞争机制的必要性。
*   **充分性与公平性**：实验涵盖了仿真环境与真实世界部署，对比基准包含了目前最强的 7B 模型。通过多次实验和不同对手强度的对比，证明了性能提升并非偶然，评估过程较为客观。

#### 6. 主要结论与发现
*   **竞争驱动泛化**：竞争性多智能体训练产生的自动课程效应（Difficulty Escalation）比静态奖励或单智能体探索更有效。
*   **规模非唯一因素**：经过 CoMaTrack 框架训练的 **3B 模型**在各项指标上全面超越了此前基于 **7B 模型**的模仿学习方法（如在 STT 任务中 SR 达到 92.1%）。
*   **鲁棒性提升**：多智能体训练显著降低了碰撞率（CR），并提高了在复杂干扰下的追踪成功率（SR）。

#### 7. 优点
*   **范式创新**：首次将博弈论与多智能体竞争引入具身视觉追踪的 VLA 模型训练中。
*   **高效性**：证明了通过策略演化可以在较小参数规模下实现超越大模型的性能。
*   **贡献基准**：填补了 EVT 领域缺乏主动对抗评估基准的空白（CoMaTrack-Bench）。
*   **实战性强**：展示了在四足机器人上的零样本迁移能力，具备实际应用潜力。

#### 8. 不足与局限
*   **任务覆盖有限**：目前主要集中在 EVT 任务，尚未在更广泛的视觉语言导航（VLN）任务（如长程指令遵循）上进行大规模验证。
*   **训练稳定性**：多智能体强化学习存在非平稳性（Non-stationarity）问题，训练过程可能比单智能体更复杂且耗时。
*   **对手策略局限**：对手的行为仍受限于模拟器的先验设定，可能无法完全覆盖现实世界中人类或环境的所有极端对抗行为。
