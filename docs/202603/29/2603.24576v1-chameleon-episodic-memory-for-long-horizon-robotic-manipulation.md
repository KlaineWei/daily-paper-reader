## 摘要
机器人操作通常需要记忆：遮挡和状态变化可能导致决策时的观测产生感知混淆，使得动作选择在观测层面呈现非马尔可夫性，因为相同的观测可能源于不同的交互历史。大多数具身智能体通过语义压缩的轨迹和基于相似性的检索来实现记忆，这会丢弃用于消除歧义的细粒度感知线索，并可能返回感知上相似但与决策无关的情节。受人类情景记忆的启发，我们提出了 Chameleon，它通过写入基于几何的多模态 token 来保留消除歧义的上下文，并通过可微记忆栈产生目标导向的回忆。我们还引入了 Camo-Dataset，这是一个使用 UR5e 真实机器人的数据集，涵盖了感知混淆下的情景回忆、空间追踪和序列化操作。在各项任务中，Chameleon 在感知易混淆的设置下，相较于强基准模型，一致地提高了决策可靠性和长程控制能力。

## Abstract
Robotic manipulation often requires memory: occlusion and state changes can make decision-time observations perceptually aliased, making action selection non-Markovian at the observation level because the same observation may arise from different interaction histories. Most embodied agents implement memory via semantically compressed traces and similarity-based retrieval, which discards disambiguating fine-grained perceptual cues and can return perceptually similar but decision-irrelevant episodes. Inspired by human episodic memory, we propose Chameleon, which writes geometry-grounded multimodal tokens to preserve disambiguating context and produces goal-directed recall through a differentiable memory stack. We also introduce Camo-Dataset, a real-robot UR5e dataset spanning episodic recall, spatial tracking, and sequential manipulation under perceptual aliasing. Across tasks, Chameleon consistently improves decision reliability and long-horizon control over strong baselines in perceptually confusable settings.

### 1. 核心问题与研究动机
*   **核心问题**：机器人长程操作中的“感知混淆”（Perceptual Aliasing）问题。在复杂任务中，由于遮挡或状态变化，决策时刻的观测往往具有非马尔可夫性（即当前的视觉画面不足以决定动作，必须依赖历史信息，如“三杯球”游戏中球在哪个杯子里）。
*   **研究背景**：现有的具身智能体记忆机制通常采用语义压缩（如文字描述）或基于相似性的检索（RAG）。这种方式会丢失关键的细粒度几何线索，且容易检索到视觉相似但决策无关的错误片段。
*   **研究动机**：受人类“情景记忆”系统（内嗅皮层-海马体-前额叶皮层）启发，旨在构建一种能够保留细粒度几何上下文并实现目标导向检索的记忆架构。

### 2. 方法论：Chameleon 架构
Chameleon 采用“感知 $\rightarrow$ 记忆 $\rightarrow$ 策略”的闭环流水线：
*   **感知层（Perception）**：
    *   **双流编码**：腹侧流（Ventral）提取 DINOv2 视觉特征；背侧流（Dorsal）提取以末端执行器（EE）为中心的几何描述符。
    *   **几何偏置注意力**：利用对极几何（Epipolar Geometry）约束和末端位姿锚点，实现多视角（前视与手眼相机）间的特征对齐，减少写入记忆时的歧义。
*   **记忆层（Memory）**：
    *   **分层可微栈**：将情景状态（Episodic State）与工作状态（Working State）耦合。
    *   **时空锚点**：利用 Mamba 风格的选择性状态空间模型（SSM），在不同时间尺度（半衰期）和空间分量上存储信息。
    *   **HoloHead（潜在想象）**：通过预测未来 2D/3D 路径点（Waypoints）来训练记忆状态 $h_t$，强制记忆保留对未来决策有用的关键信息（模式补全）。
*   **策略层（Policy）**：
    *   **条件流匹配（CFM）**：仅根据记忆读出的单一状态 $h_t$，通过整流流（Rectified Flow）一次性生成未来一段时界的末端位姿轨迹。

### 3. 实验设计
*   **数据集**：发布了 **Camo-Dataset**，包含 3 类真实机器人（UR5e）任务：
    1.  **情景回忆（清理指定盘子）**：识别并记住用户放置的特定目标。
    2.  **空间追踪（三杯球游戏）**：在杯子交换位置后追踪隐藏物体。
    3.  **序列操作（添加多种调料）**：按顺序执行多步任务，需记住已完成的步骤。
*   **基准模型（Benchmarks）**：对比了具身智能体领域的主流方法：
    *   **Diffusion Policy**（扩散策略）
    *   **Flow Matching**（流匹配）
    *   **ACT**（动作分块转换器）
*   **消融实验**：包括无记忆版本、基于检索的记忆库（Memory Bank）、原生 Mamba、无背侧流几何、无 HoloHead 想象等 5 种变体。

### 4. 资源与算力
*   **硬件**：单张 **NVIDIA RTX 4090 GPU**。
*   **训练设置**：每个任务训练 20,000 步（20K steps），采用 AdamW 优化器，批大小为 4。
*   **推理效率**：端到端推理延迟约为 **82ms**，支持实时操作。

### 5. 实验数量与充分性
*   **数据规模**：每个任务收集 120 条演示数据。
*   **测试规模**：在真实机器人上针对每个类别进行了 36 次独立试验（共 108 次真实测试）。
*   **充分性评价**：实验设计非常充分。除了标准的成功率（SR），还引入了决策成功率（DSR）和操作成功率（MSR）来拆解记忆失效与物理控制失效。消融实验覆盖了架构的每一个核心组件，证明了各模块的必要性。

### 6. 主要结论与发现
*   **性能领先**：Chameleon 在所有任务中显著优于基准模型。在最难的序列任务中，基准模型几乎完全失效（SR 为 0），而 Chameleon 保持了较高的决策准确性。
*   **记忆质量**：通过 UMAP 可视化发现，Chameleon 的记忆状态 $h_t$ 在感知混淆的情况下能清晰地聚类出不同的决策目标（模式分离）。
*   **想象力的作用**：HoloHead 显著提升了决策状态的稳定性，使模型在视觉线索消失后仍能维持正确的目标表征。

### 7. 优点与亮点
*   **生物启发性强**：将神经科学中的海马体功能（模式分离与补全）成功转化为可工程化的 SSM 架构。
*   **解决感知歧义**：通过背侧流几何锚点和多尺度记忆，有效解决了机器人领域长期存在的非马尔可夫决策难题。
*   **真实机器人验证**：所有实验均在物理实体机器人上完成，而非仅限于仿真，具有极高的实用价值。

### 8. 不足与局限
*   **泛化性限制**：目前仅在单一机器人平台（UR5e）上验证，尚未展示跨机器人形态的迁移能力。
*   **缺乏语义集成**：虽然在几何和感知层面表现优异，但未与大语言模型（LLM）或视觉语言模型（VLM）深度集成，可能限制其在需要复杂逻辑推理任务中的表现。
*   **操作误差**：实验分析显示，主要的失败模式仍集中在物理抓取阶段（MSR），模仿学习带来的轨迹随机性在精细操作中仍是瓶颈。
