## 摘要
机器人操作通常需要记忆：遮挡和状态变化可能导致决策时的观测产生感知混淆（perceptually aliased），使得动作选择在观测层面呈现非马尔可夫性，因为相同的观测可能源于不同的交互历史。大多数具身智能体通过语义压缩的轨迹和基于相似性的检索来实现记忆，这会丢弃用于消除歧义的细粒度感知线索，并可能返回感知上相似但与决策无关的情节。受人类情景记忆的启发，我们提出了 Chameleon，它通过写入基于几何的多模态 token 来保留消除歧义的上下文，并通过可微记忆栈产生目标导向的回忆。我们还引入了 Camo-Dataset，这是一个使用 UR5e 真实机器人的数据集，涵盖了感知混淆下的情景回忆、空间追踪和序列操作。在各项任务中，Chameleon 在感知易混淆的设置下，相较于强基准模型，一致地提高了决策可靠性和长程控制能力。

## Abstract
Robotic manipulation often requires memory: occlusion and state changes can make decision-time observations perceptually aliased, making action selection non-Markovian at the observation level because the same observation may arise from different interaction histories. Most embodied agents implement memory via semantically compressed traces and similarity-based retrieval, which discards disambiguating fine-grained perceptual cues and can return perceptually similar but decision-irrelevant episodes. Inspired by human episodic memory, we propose Chameleon, which writes geometry-grounded multimodal tokens to preserve disambiguating context and produces goal-directed recall through a differentiable memory stack. We also introduce Camo-Dataset, a real-robot UR5e dataset spanning episodic recall, spatial tracking, and sequential manipulation under perceptual aliasing. Across tasks, Chameleon consistently improves decision reliability and long-horizon control over strong baselines in perceptually confusable settings.

### 1. 核心问题与研究动机
*   **核心问题**：长程机器人操作中的**感知歧义（Perceptual Aliasing）**。在复杂任务中，由于遮挡或状态变化，机器人当前的观测可能无法提供足够的信息来决定下一步动作（即非马尔可夫性）。例如，在“三杯球”游戏中，决策时的杯子外观完全相同，必须依赖历史记忆才能选出藏球的杯子。
*   **研究背景**：现有的具身智能体记忆机制多采用语义压缩（如文字描述）或基于相似性的检索（RAG模式）。这种方式会丢失细粒度的几何线索，且容易检索到视觉相似但决策无关的错误片段。
*   **研究目标**：受人类“内嗅皮层-海马体-前额叶（EC-HC-PFC）”记忆系统启发，构建一种能够保留细粒度上下文并实现目标导向检索的机器人记忆架构。

### 2. 提出的方法论：Chameleon 架构
Chameleon 采用“感知 $\rightarrow$ 记忆 $\rightarrow$ 策略”的闭环流水线：
*   **几何关联感知（Perception）**：
    *   **双流处理**：腹侧流（Ventral）提取 DINOv2 图像特征；背侧流（Dorsal）利用末端执行器（EE）作为几何锚点，计算 2D-3D 投影关系。
    *   **几何偏置注意力**：利用对极几何（Epipolar Geometry）约束和末端执行器位置来引导多视角（前视和手眼相机）特征融合，确保写入记忆的 Token 具有空间一致性。
*   **分层可微记忆栈（Memory）**：
    *   **情景与工作记忆耦合**：模仿海马体功能，使用选择性状态空间模型（SSM，类似 Mamba）维护“慢速”情景状态（存储长程轨迹）和“快速”工作状态（用于当前控制）。
    *   **时空锚点**：将证据分解为多个空间和时间槽位，减少不同事件间的干扰（模式分离）。
*   **HoloHead 潜意识想象**：
    *   通过一个辅助任务训练记忆状态 $h_t$，使其能够预测未来的 2D/3D 路径点。这种“想象”机制强迫记忆状态保留任务相关的关键信息，实现目标导向的回忆（模式补全）。
*   **整流流匹配策略（Policy）**：
    *   基于条件整流流匹配（Conditional Flow Matching）生成末端执行器的未来轨迹，比传统的扩散策略更稳定且推理更快。

### 3. 实验设计
*   **数据集与场景**：引入了 **Camo-Dataset**，包含三个真实 UR5e 机器人任务：
    1.  **清理指定盘子**：在三个视觉相同的盘子中识别并清理之前被标记的一个（考察情景绑定）。
    2.  **三杯球游戏**：追踪随机交换位置后藏有物体的杯子（考察空间追踪）。
    3.  **添加调味料**：按顺序使用三种勺子并复位，需记忆已完成的步骤（考察序列操作）。
*   **基准模型（Benchmarks）**：对比了 **Diffusion Policy**、**Flow Matching** 和 **ACT**。
*   **评估指标**：除了成功率（SR），还引入了决策成功率（DSR）、操作成功率（MSR）和 Cohen’s kappa 系数（用于衡量排除随机猜测后的决策准确度）。

### 4. 资源与算力
*   **硬件**：单张 **NVIDIA RTX 4090 GPU**。
*   **训练**：每个任务训练 **20,000 步**，Batch Size 为 4。
*   **推理效率**：端到端推理延迟平均为 **82ms**，支持实时操作。
*   **数据量**：每个任务收集 120 条演示数据。

### 5. 实验数量与充分性
*   **实验规模**：在三个不同类别的记忆密集型任务上进行了测试，每个类别进行 36 次独立的真实机器人测试。
*   **消融实验**：设计了 5 种变体，分别验证了记忆模块、背侧流几何感知、HoloHead 想象机制以及 SSM 结构（对比 Vanilla Mamba）的必要性。
*   **客观性**：实验在感知歧义极其严重的真实物理环境下进行，对比方法均在相同条件下训练和部署，评估指标区分了“决策错误”和“物理操作错误”，分析较为深入客观。

### 6. 主要结论与发现
*   **决策可靠性显著提升**：在感知歧义场景下，Chameleon 的决策成功率（DSR）远超基准模型（基准模型在这些任务中表现接近随机猜测）。
*   **记忆状态的有效性**：通过 UMAP 可视化发现，Chameleon 的记忆状态 $h_t$ 能够清晰地分离视觉相似但历史背景不同的状态。
*   **想象机制的作用**：HoloHead 显著增强了模型在缺乏即时视觉线索时的“模式补全”能力，使机器人能够维持长期的任务目标。

### 7. 优点与亮点
*   **生物启发性**：将神经科学中的记忆模型（EC-HC-PFC）成功转化为可工程化的机器人架构，具有较强的理论支撑。
*   **解决非马尔可夫难题**：专门针对机器人领域长期存在的感知歧义问题提出了系统性方案。
*   **端到端可微**：整个记忆检索过程是连续且可微的，避免了传统 RAG 离散检索带来的不稳定性。
*   **真实机器人验证**：所有实验均在物理机器人上完成，而非仅限于仿真。

### 8. 不足与局限
*   **泛化性限制**：目前主要在单一机器人平台上验证，尚未展示跨机器人形态（Cross-embodiment）的迁移能力。
*   **语义理解缺失**：该模型侧重于感知和几何记忆，未与大语言模型（LLM）深度集成，在处理复杂的自然语言指令或常识推理方面可能存在局限。
*   **任务阶段依赖**：实验中使用了简单的阶段指示信号（Phase Indicator），虽然不泄露任务状态，但在完全无监督的任务分割方面仍有提升空间。
