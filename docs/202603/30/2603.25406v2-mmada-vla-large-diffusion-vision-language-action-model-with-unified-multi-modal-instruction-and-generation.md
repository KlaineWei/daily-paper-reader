## 摘要
视觉-语言-动作（VLA）模型旨在根据视觉观测和自然语言指令控制机器人进行操作。然而，现有的分层和自回归范式通常会引入架构开销，面临时间不一致性和长时程误差累积的问题，且缺乏在不增加额外模块的情况下捕获环境动力学的机制。为此，我们提出了 MMaDA-VLA，这是一个完全原生的预训练扩散 VLA 大模型，在单一框架中统一了多模态理解与生成。我们的核心思想是一种原生的离散扩散公式，将语言、图像和连续机器人控制嵌入到统一的离散 token 空间中，并通过掩码 token 去噪训练单个骨干网络，从而并行地联合生成未来目标观测和动作块（action chunk）。迭代去噪实现了全局、无序的细化，在无需辅助世界模型的情况下，将动作锚定在预测的未来视觉结果中，提升了长时程一致性。在仿真基准和真实世界任务中的实验表明，该模型达到了最先进的性能，在 LIBERO 上实现了 98.0% 的平均成功率，在 CALVIN 上达到了 4.78 的平均长度。

## Abstract
Vision-Language-Action (VLA) models aim to control robots for manipulation from visual observations and natural-language instructions. However, existing hierarchical and autoregressive paradigms often introduce architectural overhead, suffer from temporal inconsistency and long-horizon error accumulation, and lack a mechanism to capture environment dynamics without extra modules. To this end, we present MMaDA-VLA, a fully native pre-trained large diffusion VLA model that unifies multi-modal understanding and generation in a single framework. Our key idea is a native discrete diffusion formulation that embeds language, images, and continuous robot controls into one discrete token space and trains a single backbone with masked token denoising to jointly generate a future goal observation and an action chunk in parallel. Iterative denoising enables global, order-free refinement, improving long-horizon consistency while grounding actions in predicted future visual outcomes without auxiliary world models. Experiments across simulation benchmarks and real-world tasks show state-of-the-art performance, achieving 98.0% average success on LIBERO and 4.78 average length on CALVIN.

### 1. 核心问题与研究动机
*   **核心问题**：现有的视觉-语言-动作（VLA）模型主要采用分层架构（增加策略头）或自回归（AR）离散化生成。这些方法存在以下缺陷：
    *   **架构开销**：分层设计增加了训练成本和信息损失。
    *   **时间不一致性**：自回归生成动作序列时，误差会随步数累积，且强行给无序的动作维度施加顺序。
    *   **缺乏动力学建模**：大多数模型无法在不增加额外“世界模型”模块的情况下预测环境变化。
*   **研究背景**：为了解决长程任务（Long-horizon）中的一致性问题，并让模型具备预测未来视觉结果的能力，作者提出了一种原生的离散扩散 VLA 框架。

### 2. 方法论
*   **核心思想**：将语言指令、图像观测和连续机器人动作全部映射到**统一的离散 Token 空间**，并使用单个大模型骨干（Backbone）通过**掩码 Token 去噪（Masked Token Denoising）**任务进行预训练。
*   **关键技术细节**：
    *   **统一 Token 化**：文本使用 LLaDA 分词器，图像使用 MAGVIT-v2 量化器，动作则将每个维度离散化为 256 个 bin。
    *   **并行生成**：模型在推理时，同时并行生成“未来目标观测图像”和“动作块（Action Chunk）”。这种设计让动作生成能锚定在预测的视觉目标上。
    *   **混合注意力机制（Hybrid Attention）**：模态内部采用双向全注意力（允许全局信息交换），模态之间采用因果注意力（确保信息流向生成目标）。
    *   **迭代去噪推理**：类似于扩散模型，通过多次迭代（如 24 步）逐步细化 Token。为了提高实时性，引入了**训练无关的 KV 缓存（KV-Cache）**刷新策略。
*   **算法流程**：输入当前观测和指令 -> 掩码目标图像和动作 Token -> 迭代去噪预测 -> 反 Token 化得到连续动作执行。

### 6. 主要结论与发现
*   **性能领先**：MMaDA-VLA 在 LIBERO 上达到 98.0% 平均成功率，在 CALVIN 上达到 4.78 的平均完成长度，刷新了记录。
*   **视觉预测的价值**：消融实验证明，加入未来目标图像预测（世界模型属性）能显著提升动作准确度（CALVIN 平均长度提升 0.48）。
*   **并行去噪的优势**：相比于先生成图像再生成动作的顺序模式，并行去噪能让动作预测利用图像生成的中间特征，减少误差累积。
*   **预训练的重要性**：大规模跨具身预训练显著增强了模型的泛化能力和执行精度。

### 7. 优点（亮点）
*   **原生统一性**：不依赖额外的策略头或独立的世界模型，在单一 Transformer 架构内实现了理解与生成的统一。
*   **无序建模**：扩散去噪机制避免了自回归模型对动作维度强加顺序的弊端，更符合机器人控制的本质。
*   **高效推理**：通过 KV-Cache 优化解决了扩散模型推理慢的痛点，使其能满足机器人实时控制的需求。

### 8. 不足与局限
*   **视觉保真度有限**：生成的未来目标图像在细节（如夹爪形状、复杂物体纹理）上存在模糊，虽然足以引导动作，但尚未达到高质量视频生成的水平。
*   **推理延迟挑战**：尽管有缓存优化，但迭代去噪的计算开销仍高于单次前向传播的自回归模型，在极高频控制场景下可能受限。
*   **数据依赖**：模型性能高度依赖于大规模高质量的机器人演示数据，对于数据稀缺的新型任务仍需微调。
