## 摘要
我们提出了一种新的言语强化学习（VRL）框架，用于在存在执行不确定性的移动机器人系统中进行可解释的任务级规划。该框架采用闭环架构，通过与物理环境的交互实现策略的迭代改进。在我们的框架中，可执行的行为树由大语言模型（LLM）执行器（actor）进行反复优化，该执行器利用视觉语言模型（VLM）评论器（critic）生成的结构化自然语言反馈，而该评论器负责观察物理机器人及其执行轨迹。与传统的强化学习不同，VRL 中的策略更新直接发生在符号规划层面，无需基于梯度的优化。这实现了透明的推理、显式的因果反馈以及人类可解释的策略演化。我们在执行不确定性下进行多阶段操作和导航任务的真实移动机器人上验证了所提出的框架。实验结果表明，该框架支持可解释的策略改进、对执行失败的闭环自适应以及在物理机器人系统上的可靠部署。

## Abstract
We propose a new Verbal Reinforcement Learning (VRL) framework for interpretable task-level planning in mobile robotic systems operating under execution uncertainty. The framework follows a closed-loop architecture that enables iterative policy improvement through interaction with the physical environment. In our framework, executable Behavior Trees are repeatedly refined by a Large Language Model actor using structured natural-language feedback produced by a Vision-Language Model critic that observes the physical robot and execution traces. Unlike conventional reinforcement learning, policy updates in VRL occur directly at the symbolic planning level, without gradient-based optimization. This enables transparent reasoning, explicit causal feedback, and human-interpretable policy evolution. We validate the proposed framework on a real mobile robot performing a multi-stage manipulation and navigation task under execution uncertainty. Experimental results show that the framework supports explainable policy improvements, closed-loop adaptation to execution failures, and reliable deployment on physical robotic systems.

*   **核心目标**：提出一种**言语强化学习（Verbal Reinforcement Learning, VRL）**框架，通过“执行器-评论器”架构实现任务级规划的闭环自适应，且无需梯度优化，保持决策过程的高度透明和可解释。

### 2. 方法论
*   **核心思想**：将任务策略表示为可执行的行为树，利用 LLM 作为执行器（Actor）修改树结构，利用视觉语言模型（VLM）作为评论器（Critic）提供自然语言形式的反馈。
*   **关键技术细节**：
    *   **策略表示**：使用行为树（BT），因其模块化且易于被 LLM 以代码或符号形式编辑。
    *   **LLM 执行器**：接收任务定义、环境规范、节点库和评论器的反馈，直接对 BT 的结构和参数进行离散编辑。
    *   **VLM 评论器**：观察执行过程中的视觉快照和 BT 执行轨迹。它输出结构化的自然语言评价，并给出两个标量：**警报分数（Alarm Score）**（衡量问题的严重性）和**置信度（Confidence）**。
    *   **算法流程**：
        1. 初始化一个简单的 BT。
        2. 在物理机器人上执行 BT。
        3. VLM 评论器分析视觉和轨迹数据，生成反馈。
        4. LLM 执行器根据反馈、得分和历史记忆更新 BT。
        5. 重复上述过程直至策略优化。

### 6. 主要结论与发现
*   **反馈质量胜过模型规模**：经过微调的 3B 模型在学习稳定性和得分改进上优于未微调的 7B 模型，说明领域适配（对执行失败的因果诊断）至关重要。
*   **符号化输入的价值**：提供额外的结构化感知信息（如木块颜色）能显著降低感知歧义，提高学习效率和最终性能。
*   **闭环必要性**：无评论器的基准测试几乎无法实现有效的策略改进，证明了结构化言语反馈在处理不确定性时的核心作用。
*   **协同进化**：执行器会隐式地适应评论器的局限性（例如，当评论器无法可靠识别颜色时，执行器会选择更保守的策略）。

### 7. 优点
*   **高度可解释性**：所有的策略更新和失败诊断都以自然语言和行为树形式呈现，便于人类理解和干预。
*   **无需梯度**：避免了传统强化学习中复杂的奖励函数设计和大规模样本需求，适合高层逻辑规划。
*   **硬件友好**：直接在物理机器人上运行，能够捕捉到仿真器难以模拟的细微硬件失效。

### 8. 不足与局限
*   **感知瓶颈**：系统的性能上限受限于 VLM 的视觉感知能力。如果评论器无法识别细微的物理错误，执行器就无法做出正确修正。
*   **时间窗口限制**：目前的评论器基于快照分析，难以处理具有长程依赖关系的潜在故障（即错误在很久之后才显现）。
*   **保守倾向**：在感知不确定时，系统倾向于禁用某些功能（如旋转木块）以换取成功率，这可能导致策略陷入局部最优而非全局最优。
