## 摘要
虽然大语言模型（LLM）为机器人任务规划提供了语义灵活性，但其易受幻觉和逻辑不一致性的影响，限制了其在长程领域中的可靠性。为了弥合非结构化环境与严谨规划合成之间的差距，我们提出了 DUPLEX，这是一种代理式双系统神经符号架构，它将 LLM 严格限制在模式引导的信息抽取上，而非端到端规划或代码生成。在我们的框架中，前馈快系统（Fast System）利用轻量级 LLM 从自然语言中提取实体、关系等，并将其确定性地映射到经典符号规划器的规划领域定义语言（PDDL）问题文件中。为了解决复杂或描述不足的场景，慢系统（Slow System）仅在规划失败时激活，利用求解器的诊断信息驱动高容量 LLM 进行迭代反思与修复。在 12 个经典和家庭规划领域的大量评估表明，DUPLEX 在成功率和可靠性方面均显著优于现有的端到端和混合 LLM 基准。这些结果证实，关键不在于让 LLM 更好地进行规划，而在于将 LLM 限制在其擅长的部分——结构化语义落地（grounding）——并将逻辑规划合成留给符号规划器。

## Abstract
While Large Language Models (LLMs) provide semantic flexibility for robotic task planning, their susceptibility to hallucination and logical inconsistency limits their reliability in long-horizon domains. To bridge the gap between unstructured environments and rigorous plan synthesis, we propose DUPLEX, an agentic dual-system neuro-symbolic architecture that strictly confines the LLM to schema-guided information extraction rather than end-to-end planning or code generation. In our framework, a feed-forward Fast System utilizes a lightweight LLM to extract entities, relations etc. from natural language, deterministically mapping them into a Planning Domain Definition Language (PDDL) problem file for a classical symbolic planner. To resolve complex or underspecified scenarios, a Slow System is activated exclusively upon planning failure, leveraging solver diagnostics to drive a high-capacity LLM in iterative reflection and repair. Extensive evaluations across 12 classical and household planning domains demonstrate that DUPLEX significantly outperforms existing end-to-end and hybrid LLM baselines in both success rate and reliability. These results confirm that The key is not to make the LLM plan better, but to restrict the LLM to the part it is good at - structured semantic grounding - and leave logical plan synthesis to a symbolic planner.

### 1. 核心问题与研究动机
*   **核心问题**：大语言模型（LLM）在处理长程（Long-horizon）机器人任务规划时，虽然具备出色的常识推理能力，但极易产生**幻觉**、**逻辑不一致**以及**违反物理约束**等问题。
*   **研究背景**：
    *   **经典符号规划器**（如基于 PDDL 的规划器）逻辑严谨、可验证，但存在“知识获取瓶颈”，即难以将非结构化的现实环境转化为严谨的符号表示。
    *   **现有混合方法**（如 LLM+P）尝试让 LLM 直接编写 PDDL 代码，但这要求 LLM 生成极其精确的语法和逻辑，容错率极低，在复杂任务中表现脆弱。
*   **核心动机**：不应强求 LLM 成为“规划器”或“代码生成器”，而应将其限制在它最擅长的领域——**结构化信息抽取（IE）**，将逻辑合成交给专业的符号规划器。

### 2. 方法论
DUPLEX 提出了一种**代理式双系统神经符号架构**：
*   **快系统（Fast System）**：
    *   **信息抽取**：使用轻量级 LLM（如 Qwen3-8B）作为信息抽取器，根据预定义的 Schema（由 PDDL 领域文件导出）从自然语言描述中提取实体、关系和状态，输出结构化的 JSON。
    *   **确定性映射**：通过预编写的脚本（Mapper）将 JSON 转换为 PDDL 问题文件。这种方式保证了 100% 的语法正确性，避免了 LLM 直接写代码带来的语法错误。
    *   **符号规划**：调用经典规划器（如 Fast Downward）生成动作序列。
*   **慢系统（Slow System）**：
    *   **触发机制**：仅在快系统规划失败（如规划器报错“无解”）时激活。
    *   **代理式反思**：调用高容量 LLM（如 GPT-4o）作为诊断代理，分析规划器的错误诊断信息，识别缺失的初始状态或逻辑矛盾。
    *   **迭代修复**：LLM 针对性地修改 PDDL 问题文件并重新尝试，形成闭环反馈。

*   **性能飞跃**：DUPLEX 在 IPC 领域的平均成功率达到 **97.5%**（远超 LLM+P 的 71.9% 和 LLM-as-Planner 的 11.9%）；在家庭领域达到 **83.5%**。

*   **小模型大作为**：通过将任务简化为信息抽取，轻量级的 8B 模型在快系统中的表现甚至优于直接进行代码生成的 175B+ 级别模型。

### 7. 优点与亮点
*   **架构优雅**：借鉴认知科学的“双系统理论”，兼顾了处理效率（快系统）和复杂纠错能力（慢系统）。
*   **鲁棒性强**：通过“抽取+模板映射”替代“直接生成代码”，彻底解决了 PDDL 语法报错问题。
*   **低成本高效**：日常任务由轻量级本地模型处理，仅在必要时调用昂贵的大模型，降低了推理成本。

*   **依赖先验知识**：系统仍假设可以获取手动编写的 PDDL 领域文件（Domain File），尚未实现领域知识的自动学习。

*   **模态限制**：目前主要依赖文本信息抽取，在视觉信息极其丰富的环境中，可能存在指代歧义或观察遗漏的风险。
