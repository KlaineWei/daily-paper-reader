## 摘要
机器人操作通常需要记忆：遮挡和状态变化可能导致决策时的观测产生感知混淆（perceptually aliased），使得动作选择在观测层面呈现非马尔可夫性，因为相同的观测可能源于不同的交互历史。大多数具身智能体通过语义压缩的轨迹和基于相似性的检索来实现记忆，这会丢弃用于消除歧义的细粒度感知线索，并可能返回感知上相似但与决策无关的情节。受人类情景记忆的启发，我们提出了 Chameleon，它通过写入基于几何的多模态标记（tokens）来保留消除歧义的上下文，并通过可微记忆栈产生目标导向的回忆。我们还引入了 Camo-Dataset，这是一个基于 UR5e 真实机器人的数据集，涵盖了感知混淆下的情景回忆、空间追踪和序列操作。在各项任务中，Chameleon 在感知易混淆的设置下，相比强基准模型一致地提高了决策可靠性和长程控制能力。

## Abstract
Robotic manipulation often requires memory: occlusion and state changes can make decision-time observations perceptually aliased, making action selection non-Markovian at the observation level because the same observation may arise from different interaction histories. Most embodied agents implement memory via semantically compressed traces and similarity-based retrieval, which discards disambiguating fine-grained perceptual cues and can return perceptually similar but decision-irrelevant episodes. Inspired by human episodic memory, we propose Chameleon, which writes geometry-grounded multimodal tokens to preserve disambiguating context and produces goal-directed recall through a differentiable memory stack. We also introduce Camo-Dataset, a real-robot UR5e dataset spanning episodic recall, spatial tracking, and sequential manipulation under perceptual aliasing. Across tasks, Chameleon consistently improves decision reliability and long-horizon control over strong baselines in perceptually confusable settings.

### 1. 核心问题与研究动机
*   **核心问题**：机器人长程操作中的“感知歧义”（Perceptual Aliasing）问题。在复杂任务中，由于遮挡或状态变化，机器人当前的观测可能对应多个不同的历史状态（非马尔可夫性），导致仅凭当前视觉信息无法做出正确决策（例如：在“三杯球”游戏中，交换位置后杯子外观完全一致，必须依靠记忆追踪）。
*   **研究动机**：
    *   **现有方法不足**：目前的具身智能体多采用类似 RAG 的语义压缩记忆或基于相似性的检索，这会丢失细粒度的几何线索，且容易检索到视觉相似但决策无关的错误片段。
    *   **生物启发**：人类的情景记忆（Episodic Memory）通过内嗅皮层（EC）、海马体（HC）和前额叶皮层（PFC）的协作，能够将经验组织为带有空时背景的事件，并进行目标导向的回忆。

### 2. 方法论：Chameleon 架构
Chameleon 采用“感知 $\rightarrow$ 记忆 $\rightarrow$ 策略”的闭环流水线：
*   **感知层（Perception）**：
    *   **双流编码**：腹侧流（Ventral）提取 DINO 视觉特征；背侧流（Dorsal）利用末端执行器（EE）作为几何锚点，生成 3D 射线和 2D 投影特征。
    *   **几何偏置注意力**：通过对极几何（Epipolar Geometry）约束和末端执行器位置偏置，实现多视角（前视和手眼相机）特征的细粒度对齐，减少写入记忆前的歧义。
*   **记忆层（Memory）**：
    *   **分层可微栈**：耦合了“情景状态”（长期存储）和“工作状态”（即时控制）。
    *   **空时锚点**：利用选择性状态空间模型（SSM/Mamba 变体）在不同时间尺度上存储空间特征。
    *   **HoloHead（核心创新）**：引入一个“潜意识想象”目标，训练记忆状态 $h_t$ 去预测未来 2D/3D 的轨迹点。这强迫记忆不仅是压缩，而且必须具备预测未来和目标导向的回忆能力。
*   **策略层（Policy）**：
    *   基于**条件流匹配（Conditional Flow Matching, CFM）**生成末端执行器的姿态轨迹，相比单步预测，在长程任务中更稳定。

### 3. 实验设计
*   **数据集**：发布了 **Camo-Dataset**，包含 360 段真实 UR5e 机器人演示数据。
*   **实验场景**：
    1.  **情景回忆**：清理指定的盘子（盘子外观一致，需记忆用户之前的指示）。
    2.  **空间追踪**：三杯球游戏（追踪被遮挡的物体）。
    3.  **序列操作**：按顺序添加三种调料（需记忆已完成的步骤）。
*   **对比基线**：Diffusion Policy、Flow Matching、ACT（Action Chunking Transformer）。
*   **评估指标**：成功率（SR）、决策成功率（DSR）、操作成功率（MSR）以及经随机概率修正的 Cohen’s Kappa 系数（$\kappa$）。

### 4. 资源与算力
*   **硬件**：单张 **NVIDIA RTX 4090 GPU**。
*   **训练设置**：训练 20,000 步，Batch Size 为 4。
*   **推理性能**：端到端推理延迟平均为 **82ms**，满足 UR5e 机器人的实时操作需求。

### 5. 实验数量与充分性
*   **实验规模**：每个任务类别进行了 36 次独立真实机器人测试，总计超过 100 次实机评估。
*   **消融实验**：设计了 5 种变体，包括移除记忆模块、使用传统检索式记忆库、使用原生 Mamba、移除背侧流几何信息、移除 HoloHead 想象目标。
*   **充分性评价**：实验设计较为充分，涵盖了从感知到记忆机制的各个维度。通过 UMAP 可视化证明了记忆状态在感知歧义下的“模式分离”能力，客观地展示了方法在非马尔可夫决策点上的优势。

### 6. 主要结论与发现
*   **记忆是长程任务的关键**：在感知歧义场景下，缺乏记忆的基线模型（如原生 Diffusion Policy）表现接近随机猜测，而 Chameleon 实现了极高的决策成功率（DSR 在情景任务中达 100%）。
*   **连续动力学优于离散检索**：实验证明，基于 SSM 的连续记忆更新比基于相似性的离散记忆库（Memory Bank）更能有效处理视觉相似但逻辑不同的历史。
*   **想象力增强记忆**：HoloHead 的预测任务显著提升了记忆表示的稳定性，防止了表示坍缩。

### 7. 优点与亮点
*   **生物学一致性**：架构设计紧密贴合神经科学中 EC-HC-PFC 的功能分区，具有较强的理论支撑。
*   **解决痛点**：针对机器人领域长期存在的“感知歧义”给出了系统性的解决方案。
*   **实机验证**：所有实验均在真实物理机器人上完成，而非仅限于仿真环境，具有较高的实用价值。
*   **开源贡献**：提供了专门针对记忆能力测试的开源数据集 Camo-Dataset。

### 8. 不足与局限
*   **泛化性限制**：目前仅在单一机器人平台（UR5e）上验证，跨机器人形态的迁移能力尚待研究。
*   **缺乏语义先验**：未集成大语言模型（LLM）或视觉语言模型（VLM）的语义常识，在处理需要复杂逻辑推理或开放世界指令的任务时可能受限。
*   **事件分割**：目前任务阶段（Phase）仍需人工信号或简单触发，未来需研究如何自动进行“事件分割”以实现更自主的情景记忆写入。
