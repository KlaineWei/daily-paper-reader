## 摘要
视觉-语言-动作（VLA）模型在机器人操控方面表现出色，但由于处理密集的视觉标记（tokens），面临显著的推理延迟。现有的标记缩减方法主要依赖注意力幅度作为静态选择标准。在这项工作中，我们对这一假设提出了挑战，揭示了高注意力标记是任务相关的，甚至可能降低策略性能。为解决这一问题，我们提出了 TIES（Tau 引导的层间高效选择），这是一个由层间标记排名一致性引导的动态框架。通过自适应地平衡注意力幅度与排名一致性，TIES 在无需额外训练的情况下确保了稳健的标记选择。在 CogACT + SIMPLER 基准测试中，TIES 在减少 78% 标记使用的同时，将平均成功率提高了 6%，并在多种解码器和基准测试中展现出强大的泛化能力。

## Abstract
Vision-Language-Action (VLA) models excel in robotic manipulation but suffer from significant inference latency due to processing dense visual tokens. Existing token reduction methods predominantly rely on attention magnitude as a static selection. In this work, we challenge this assumption, revealing that high-attention tokens are task-dependent and can even degrade policy performance. To address this, we introduce \textbf{TIES} (\textbf{T}au-guided \textbf{I}nter-layer \textbf{E}fficient \textbf{S}election), a dynamic framework guided by inter-layer token ranking consistency. By adaptively balancing attention magnitude with ranking consistency, TIES ensures robust token selection without requiring additional training. On the CogACT + SIMPLER benchmark, TIES improves average success rates by 6\% while reducing token usage by 78\%, and demonstrate strong generalization across diverse decoders and benchmarks.

*   **核心问题**：视觉-语言-动作（VLA）模型在机器人操控中表现优异，但由于需要处理大量视觉 Token，Transformer 的二次方复杂度导致推理延迟极高，难以满足实时控制需求。
*   **研究动机**：现有的 Token 缩减方法大多基于“注意力幅度（Attention Magnitude）越大越重要”的假设。作者通过实验挑战了这一假设，发现：
    *   高注意力 Token 具有任务依赖性，在某些任务（如开抽屉）中，保留高注意力 Token 反而会导致性能下降（性能反转）。
    *   高注意力 Token 有时仅作为“信息汇聚点（Attention Sinks）”或锁定在伪相关特征上，而非真正对决策有用的语义信息。

#### 2. 核心方法论：TIES 框架
作者提出了 **TIES（Tau-guided Inter-layer Efficient Selection）**，这是一种无需训练的动态 Token 剪枝框架。
*   **核心指标：层间排名一致性（Kendall’s $\tau$）**：
    *   利用肯德尔相关系数（Kendall rank correlation coefficient）衡量相邻 Transformer 层之间 Token 注意力排名的稳定性。
    *   **伪锁定假设（Spurious Locking Hypothesis）**：高 $\tau$ 值意味着模型在深层仍死板地关注早期层选定的特征（可能陷入局部最优或伪相关）；低 $\tau$ 值则代表模型在不断根据上下文调整关注点，属于健康的“信息流”。
*   **动态选择策略**：
    *   **Hard-TIES**：设定阈值，若 $\tau$ 过高（不可信），则放弃注意力排名，改用均匀采样（Uniform Sampling）以保证多样性；否则采用 Top-k 采样。
    *   **Soft-TIES**：通过线性插值动态分配 Top-k 采样和均匀采样的比例。
*   **关键技术细节**：

    *   **离线校准**：通过少量样本估计 $\tau$ 的中位数和分布，使模型能快速适配新环境。
