## 摘要
视觉-语言-动作（VLA）模型旨在根据视觉观测和自然语言指令控制机器人进行操作。然而，现有的分层和自回归范式通常会引入架构开销，面临时间不一致性和长时程误差累积的问题，并且在不使用额外模块的情况下缺乏捕捉环境动力学的机制。为此，我们提出了 MMaDA-VLA，这是一种完全原生的预训练扩散 VLA 大模型，在单一框架中统一了多模态理解与生成。我们的核心思想是一种原生的离散扩散公式，它将语言、图像和连续机器人控制嵌入到一个离散的 token 空间中，并使用掩码 token 去噪训练单个骨干网络，以并行地联合生成未来目标观测和动作块（action chunk）。迭代去噪实现了全局、无序的细化，在不依赖辅助世界模型的情况下，将动作锚定在预测的未来视觉结果中，从而提高了长时程一致性。在仿真基准测试和真实世界任务中的实验表明，该模型达到了最先进的性能，在 LIBERO 上实现了 98.0% 的平均成功率，在 CALVIN 上实现了 4.78 的平均长度。

## Abstract
Vision-Language-Action (VLA) models aim to control robots for manipulation from visual observations and natural-language instructions. However, existing hierarchical and autoregressive paradigms often introduce architectural overhead, suffer from temporal inconsistency and long-horizon error accumulation, and lack a mechanism to capture environment dynamics without extra modules. To this end, we present MMaDA-VLA, a fully native pre-trained large diffusion VLA model that unifies multi-modal understanding and generation in a single framework. Our key idea is a native discrete diffusion formulation that embeds language, images, and continuous robot controls into one discrete token space and trains a single backbone with masked token denoising to jointly generate a future goal observation and an action chunk in parallel. Iterative denoising enables global, order-free refinement, improving long-horizon consistency while grounding actions in predicted future visual outcomes without auxiliary world models. Experiments across simulation benchmarks and real-world tasks show state-of-the-art performance, achieving 98.0% average success on LIBERO and 4.78 average length on CALVIN.

*   **核心问题**：现有的视觉-语言-动作（VLA）模型主要采用分层架构（增加额外策略头）或自回归生成（离散化动作序列）。这些方法存在架构冗余、长程任务中误差累积、时间不一致性以及缺乏对环境动力学（Environment Dynamics）建模等问题。
*   **研究动机**：旨在开发一种原生的、统一的扩散模型框架，将多模态理解与生成整合在一起。通过并行预测未来视觉目标（Goal Observation）和动作序列，使模型在无需额外世界模型模块的情况下，具备感知环境变化并保持长程操作一致性的能力。

#### 2. 方法论
*   **核心思想**：提出 **MMaDA-VLA**，一个基于离散扩散（Discrete Diffusion）的统一框架。它将语言指令、图像观测和连续机器人动作全部映射到同一个离散 Token 空间中，通过掩码 Token 去噪（Masked Token Denoising）任务进行训练。
*   **关键技术细节**：
    *   **统一 Token 化**：文本使用 LLaDA 分词器，图像使用 MAGVIT-v2 量化器，动作则将每个维度离散化为 256 个 Bin。
    *   **并行生成架构**：模型输入当前观测和指令，并行生成“未来目标图像”和“动作块（Action Chunk）”。这种设计允许动作生成参考预测的视觉演变。
    *   **混合注意力机制（Hybrid Attention）**：模态内部采用双向全注意力（实现全局信息交换），模态之间采用因果注意力（确保信息流向正确），以平衡理解与生成的稳定性。
    *   **迭代去噪推理**：推理时从全掩码状态开始，通过 $D$ 步迭代去噪恢复 Token。引入了 **KV Cache 优化**，通过缓存稳定的指令表示和选择性刷新生成部分的缓存，提升实时控制频率。

*   **并行生成的优势**：相比先生成图像再生成动作的顺序模式，并行去噪能让动作预测利用图像生成的中间特征，减少误差传播。
*   **预训练至关重要**：大规模跨具身预训练显著增强了模型的泛化能力和执行精度。

#### 7. 优点与亮点
*   **原生统一性**：不依赖额外的策略头或独立的世界模型，在单一 Transformer 骨干中实现了理解、预测与控制。
*   **非自回归优势**：利用扩散模型的全局细化能力，避免了自回归模型在动作维度上的无序性偏见和误差累积。
*   **高效推理**：通过训练无关的缓存机制解决了扩散模型推理慢的痛点，使其适用于实时机器人控制。

#### 8. 不足与局限
*   **视觉保真度有限**：生成的未来目标图像在细节（如夹爪几何形状、微小物体）上存在模糊，虽然足以引导动作，但像素级精度仍有提升空间。
*   **复杂交互失败风险**：在真实世界中，面对极高精度的对准（如窄瓶口放置）或复杂的物理交互（如抽屉未完全拉开导致的卡顿）时，仍存在失败概率。
*   **计算开销**：尽管有优化，但 8B 规模的扩散模型在边缘设备上的部署仍面临显存和算力的挑战。
