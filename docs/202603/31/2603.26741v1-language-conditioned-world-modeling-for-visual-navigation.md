## 摘要
我们研究了语言条件视觉导航（LCVN），其中具身智能体被要求仅根据初始的第一人称视角观察来遵循自然语言指令。在无法获取目标图像的情况下，智能体必须依靠语言来塑造其感知和连续控制，这使得对齐（grounding）问题变得尤为具有挑战性。我们将该问题建模为以语言指令为条件的开环轨迹预测，并推出了 LCVN 数据集。这是一个包含 39,016 条轨迹和 117,048 条经过人工验证指令的基准测试，支持在多种环境和指令风格下进行可复现的研究。利用该数据集，我们开发了 LCVN 框架，通过两个互补的模型系列将语言对齐、未来状态预测和动作生成联系起来。第一个系列结合了基于扩散的世界模型 LCVN-WM 和在世界模型潜空间中训练的 Actor-Critic 智能体 LCVN-AC。第二个系列 LCVN-Uni 采用了一种自回归多模态架构，可同时预测动作和未来观察。实验表明，这些系列具有不同的优势：前者提供了更具时间连贯性的展开（rollouts），而后者在未知环境中的泛化能力更强。综上所述，这些观察结果指出了在统一任务设置中共同研究语言对齐、想象和策略学习的价值，LCVN 为进一步研究语言条件世界模型提供了坚实的基础。代码可在 https://github.com/F1y1113/LCVN 获取。

## Abstract
We study language-conditioned visual navigation (LCVN), in which an embodied agent is asked to follow a natural language instruction based only on an initial egocentric observation. Without access to goal images, the agent must rely on language to shape its perception and continuous control, making the grounding problem particularly challenging. We formulate this problem as open-loop trajectory prediction conditioned on linguistic instructions and introduce the LCVN Dataset, a benchmark of 39,016 trajectories and 117,048 human-verified instructions that supports reproducible research across a range of environments and instruction styles. Using this dataset, we develop LCVN frameworks that link language grounding, future-state prediction, and action generation through two complementary model families. The first family combines LCVN-WM, a diffusion-based world model, with LCVN-AC, an actor-critic agent trained in the latent space of the world model. The second family, LCVN-Uni, adopts an autoregressive multimodal architecture that predicts both actions and future observations. Experiments show that these families offer different advantages: the former provides more temporally coherent rollouts, whereas the latter generalizes better to unseen environments. Taken together, these observations point to the value of jointly studying language grounding, imagination, and policy learning in a unified task setting, and LCVN provides a concrete basis for further investigation of language-conditioned world models. The code is available at https://github.com/F1y1113/LCVN.

*   **核心问题**：如何在**开环（Open-loop）**设定下，实现语言驱动的视觉导航？即智能体只看一眼起点图像并听取指令，就必须在脑中“想象”出通往目标的完整路径并生成动作序列。
*   **研究动机**：
    *   现有的视觉导航多依赖目标图像（Goal-conditioned），而人类更习惯使用语言指令。
    *   传统的语言导航多为闭环系统，依赖持续的环境反馈，而缺乏对环境动态预测（世界建模）的深入探讨。
    *   缺乏大规模、高质量且包含多种指令风格（如简洁、繁复、基于地标）的导航数据集。

### 2. 方法论
论文提出了 **LCVN 数据集** 和两类互补的**语言条件世界模型**架构：

*   **LCVN 数据集**：构建了包含 39,016 条轨迹和 117,048 条人工验证指令的大规模数据集。指令分为三种风格：简洁型（Concise）、复杂型（Intricate）和地标型（Landmark-based）。
*   **架构一：LCVN-WM + LCVN-AC（基于扩散模型）**
    *   **LCVN-WM**：基于扩散 Transformer（DiT）的世界模型，通过“扩散强迫（Diffusion Forcing）”技术预测未来潜空间状态。它将语言指令作为交叉注意力的输入，使预测画面符合指令描述。
    *   **LCVN-AC**：在世界模型的潜空间内训练的 Actor-Critic 智能体。它通过计算预测轨迹与专家轨迹之间的“内在奖励（Intrinsic Reward）”来学习策略。
*   **架构二：LCVN-Uni（基于自回归多模态大模型）**
    *   采用统一的自回归架构（基于 Chameleon/Anole-7B），将图像（VQ Token）、动作（Bin Token）和语言（BPE Token）统一编码。
    *   在单次前向传播中同时预测下一个动作和下一帧观察，实现感知、预测与决策的深度融合。

### 3. 实验设计
*   **数据集与场景**：使用了 Go Stanford, ReCon, SCAND, HuRoN 等 5 个多样化机器人数据集进行训练和域内评估；使用 TartanDrive 作为完全未见（Unseen）的零样本评估场景。
*   **Benchmark 与对比方法**：

*   **实验规模**：论文进行了大规模的定量对比，涵盖了 3 个验证/测试集（Seen, Unseen, Test）。
*   **消融实验**：非常充分，涵盖了：

    2.  上下文窗口大小（Context Size k=1, 2, 4）的影响。
    3.  指令风格（简洁 vs 复杂 vs 地标）对表现的影响。

### 6. 主要结论与发现
*   **互补性**：基于扩散的模型（LCVN-WM）生成的视频序列在时间上更连贯，适合短时精细控制；而自回归模型（LCVN-Uni）在未见过的环境中泛化能力更强。
*   **语言的重要性**：加入语言指令显著提升了导航成功率和想象画面的语义一致性。
*   **地标引导最有效**：在三种指令风格中，基于地标的指令对导航性能的提升最为显著。
*   **想象力即战斗力**：实验证明，世界模型对未来预测的保真度（Imagination Quality）与最终的导航成功率呈正相关。

### 7. 优点
*   **任务创新**：首次系统性地定义了“开环语言条件视觉导航”任务，强调了“想象力”在具身智能中的作用。
*   **数据集质量高**：提供了多风格、人工校验的指令，填补了该领域的空白。
*   **双路径探索**：同时对比了扩散模型和自回归模型两条主流技术路线，给出了清晰的适用场景建议。

### 8. 不足与局限
*   **推理延迟**：目前的推理速度（尤其是自回归模型）较慢，难以直接应用于对实时性要求极高的物理机器人。
*   **开环限制**：虽然开环设定能很好地测试预测能力，但在极长距离导航中，缺乏环境反馈会导致误差累积，成功率仍有提升空间。
*   **Token 窗口限制**：LCVN-Uni 受限于 4096 的 Token 窗口，在增加上下文帧数时不得不降低单帧分辨率，存在性能权衡。
