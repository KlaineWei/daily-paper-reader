## 摘要
推荐排序本质上是一个影响力分配问题：排序公式在竞争因素之间分配排序影响力，而业务结果取决于找到它们之间最优的“交换率”。然而，离线代理指标系统性地误判了影响力重新分配如何转化为在线影响，且不同指标之间存在非对称偏差，单一校准因子无法纠正。我们提出了 Sortify，这是首个部署在大规模生产级推荐系统中的全自主 LLM 驱动排序优化智能体。该智能体将排序优化重新定义为持续的影响力交换，实现了从诊断到参数部署的无需人工干预的全闭环。它通过三种机制解决结构性问题：(1) 基于 Savage 主观期望效用 (SEU) 的双通道框架，将离线-在线迁移校正（信念通道）与约束惩罚调整（偏好通道）解耦；(2) 一个操作框架级参数而非底层搜索变量的 LLM 元控制器；(3) 一个包含 7 张关系表的持久化记忆数据库，用于跨轮次学习。其核心指标“影响力份额” (Influence Share) 提供了一种可分解的度量方式，所有因素的贡献总和恰好为 100%。Sortify 已在两个市场部署。在 A 国，该智能体在 7 轮内将 GMV 从 -3.6% 提升至 +9.2%，峰值订单量增长达 +12.5%。在 B 国，冷启动部署在为期 7 天的 A/B 测试中实现了 +4.15% 的 GMV/UU 和 +3.58% 的广告收入增长，随后进入全量生产环境。

## Abstract
Recommendation ranking is fundamentally an influence allocation problem: a sorting formula distributes ranking influence among competing factors, and the business outcome depends on finding the optimal "exchange rates" among them. However, offline proxy metrics systematically misjudge how influence reallocation translates to online impact, with asymmetric bias across metrics that a single calibration factor cannot correct.   We present Sortify, the first fully autonomous LLM-driven ranking optimization agent deployed in a large-scale production recommendation system. The agent reframes ranking optimization as continuous influence exchange, closing the full loop from diagnosis to parameter deployment without human intervention. It addresses structural problems through three mechanisms: (1) a dual-channel framework grounded in Savage's Subjective Expected Utility (SEU) that decouples offline-online transfer correction (Belief channel) from constraint penalty adjustment (Preference channel); (2) an LLM meta-controller operating on framework-level parameters rather than low-level search variables; (3) a persistent Memory DB with 7 relational tables for cross-round learning. Its core metric, Influence Share, provides a decomposable measure where all factor contributions sum to exactly 100%.   Sortify has been deployed across two markets. In Country A, the agent pushed GMV from -3.6% to +9.2% within 7 rounds with peak orders reaching +12.5%. In Country B, a cold-start deployment achieved +4.15% GMV/UU and +3.58% Ads Revenue in a 7-day A/B test, leading to full production rollout.

*   **研究背景**：
    *   **离线在线不一致**：离线指标的大幅提升往往只能转化为在线收益的一小部分，且不同指标的偏差方向不同（有的乐观，有的悲观）。
    *   **诊断信号纠缠**：当在线效果不佳时，难以区分是“预测模型不准”（信念错误）还是“约束惩罚设置不当”（偏好错误）。

### 2. 核心方法论
Sortify 采用三层架构，核心思想是基于 **Savage 的主观期望效用（SEU）理论**，将决策解耦为“信念”与“偏好”两个独立通道。

*   **影响力份额（Influence Share）指标**：
    *   **核心思想**：将排序视为高维空间中“点”穿过“墙”（比较超平面）的过程。
    *   **技术细节**：通过计算各业务因子（如价格、广告出价、相关性）对项对（Item Pair）分差的贡献，定义一个总和为 100% 的可分解指标。这解决了 Kendall's $\tau$ 等指标无法量化各因子贡献的问题。
*   **双通道自适应框架**：
    *   **信念通道（Belief Channel）**：负责修正离线到在线的映射。使用最小均方（LMS）算法进行连续校准，并由 LLM 元控制器根据历史趋势进行“截距跳跃”修正。
    *   **偏好通道（Preference Channel）**：负责调整约束惩罚。根据约束违反压力，采用非对称乘法更新规则（加强惩罚快于放松惩罚）。
*   **LLM 元控制器**：
    *   **操作逻辑**：LLM 不直接调整底层排序参数，而是调整框架级参数（如迁移函数的截距、惩罚倍数）。
    *   **决策依据**：基于 Memory DB 中存储的最近 20 轮实验历史和 30 次校准记录，通过结构化 Prompt 进行推理。
*   **算法流程**：
    1.  拉取在线 A/B 报告。
    2.  更新 Memory DB。
    3.  LMS 校准信念通道。
    4.  LLM 提出框架级修正建议。
    5.  更新目标范围与惩罚权重。
    6.  执行 5000 次 Optuna 搜索寻找最优参数。
    7.  发布参数至生产环境，进入下一轮循环（YOLO 模式）。

*   **对比方法**：主要对比了 Sortify 在不同轮次间的演进效果，以及与传统人工优化模式的结构性差异。

### 6. 主要结论与发现
*   **业务提升**：在国家 A，7 轮内将 GMV 从 -3.6% 提升至 +9.2%，订单量提升 12.5%。在国家 B，7 天 A/B 测试显示 GMV/UU 提升 4.15%，广告收入提升 3.58%。
*   **校准价值**：证明了即使在热启动状态下，离线在线映射也会随时间漂移，持续校准是必要的。
*   **LLM 作用**：LLM 能有效识别 LMS 无法捕捉的跨轮次模式，加速系统从结构性偏差中恢复。
*   **参数演进**：发现排序参数存在“钟摆效应”（在广告与有机流量间摆动），但随校准深入，摆动幅度会收窄。

### 7. 优点
*   **理论扎实**：将 SEU 决策理论引入排序优化，实现了信念与偏好的架构级解耦。
*   **全自主闭环**：实现了从数据拉取、诊断、搜索到部署的无人值守运行，极大降低了人力成本。
*   **可解释性**：通过“影响力份额”指标，让黑盒的排序权重变得直观且可量化。
*   **开发范式创新**：论文特别提到该系统由单人指挥 AI Agent 舰队完成（9.8 万行代码），展示了未来软件工程的新模式。

### 8. 不足与局限
*   **参数震荡**：系统在处理多目标冲突（如广告 vs 有机）时，参数仍存在残余震荡，未能完全收敛至单一点。
*   **低流量噪声**：在低流量时段（如凌晨），在线指标的统计波动可能导致 Belief 通道产生误校准。
*   **极端情况验证不足**：实验期间未遇到极端的市场环境突变（如大型促销日），LLM 处理极端断裂的能力尚待进一步验证。
*   **单目标局限**：目前的优化目标仍是单目标加惩罚项，未来可能需要转向更复杂的帕累托前沿（Pareto Frontier）搜索。
