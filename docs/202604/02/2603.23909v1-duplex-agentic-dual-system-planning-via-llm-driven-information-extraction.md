## 摘要
虽然大语言模型（LLMs）为机器人任务规划提供了语义灵活性，但它们易受幻觉和逻辑不一致性的影响，限制了其在长程领域中的可靠性。为了弥合非结构化环境与严谨规划合成之间的差距，我们提出了 DUPLEX，这是一种智能体双系统神经符号架构，它将 LLM 严格限制在模式引导的信息提取上，而非端到端规划或代码生成。在我们的框架中，前馈快系统（Fast System）利用轻量级 LLM 从自然语言中提取实体、关系等，并将其确定性地映射到经典符号规划器的规划领域定义语言（PDDL）问题文件中。为了解决复杂或描述不足的场景，慢系统（Slow System）仅在规划失败时激活，利用求解器诊断驱动高容量 LLM 进行迭代反思和修复。在 12 个经典和家庭规划领域的大量评估表明，DUPLEX 在成功率和可靠性方面均显著优于现有的端到端和混合 LLM 基准。这些结果证实，关键不在于让 LLM 更好地进行规划，而在于将 LLM 限制在其擅长的部分——结构化语义落地（semantic grounding）——并将逻辑规划合成留给符号规划器。

## Abstract
While Large Language Models (LLMs) provide semantic flexibility for robotic task planning, their susceptibility to hallucination and logical inconsistency limits their reliability in long-horizon domains. To bridge the gap between unstructured environments and rigorous plan synthesis, we propose DUPLEX, an agentic dual-system neuro-symbolic architecture that strictly confines the LLM to schema-guided information extraction rather than end-to-end planning or code generation. In our framework, a feed-forward Fast System utilizes a lightweight LLM to extract entities, relations etc. from natural language, deterministically mapping them into a Planning Domain Definition Language (PDDL) problem file for a classical symbolic planner. To resolve complex or underspecified scenarios, a Slow System is activated exclusively upon planning failure, leveraging solver diagnostics to drive a high-capacity LLM in iterative reflection and repair. Extensive evaluations across 12 classical and household planning domains demonstrate that DUPLEX significantly outperforms existing end-to-end and hybrid LLM baselines in both success rate and reliability. These results confirm that The key is not to make the LLM plan better, but to restrict the LLM to the part it is good at - structured semantic grounding - and leave logical plan synthesis to a symbolic planner.

### 1. 核心问题与整体含义
*   **研究动机**：大语言模型（LLM）在机器人任务规划中虽具语义灵活性，但在长程（Long-horizon）任务中极易产生“幻觉”、逻辑不一致及违反物理约束等问题。
*   **核心矛盾**：现有的“LLM直接规划”不可靠，而“LLM生成代码（如LLM+P）”又因语法和语义的微小错误导致符号规划器频繁崩溃。
*   **整体含义**：本文主张**不应让LLM直接做逻辑规划**，而应将其角色限制在它最擅长的“非结构化信息提取（IE）”上，将严谨的逻辑合成交给经典的符号规划器（如PDDL求解器），并通过双系统架构实现错误的自动修复。

### 2. 方法论
DUPLEX 采用了一种受认知科学启发的**双系统神经符号架构**：
*   **快系统（Fast System）**：
    *   **引导式信息提取**：使用轻量级 LLM（如 Qwen3-8B）根据预定义的 Schema（模式），从环境描述和指令中提取实体、关系和状态，输出结构化的 JSON。
    *   **确定性映射**：通过预编写的脚本将 JSON 自动填充到 PDDL 问题模板中。这保证了生成的 PDDL 文件在语法上 100% 正确，消除了 LLM 直接写代码带来的编译错误。
    *   **符号规划**：调用 Fast Downward 等经典规划器生成可验证的最优动作序列。
*   **慢系统（Slow System - 智能体反思）**：
    *   **触发机制**：仅在快系统规划失败（如求解器返回“无解”）时激活。
    *   **迭代修复**：利用高容量 LLM（如 GPT-4o）作为诊断智能体，分析规划器的错误诊断信息，识别缺失的初始状态或错误的语义关联，并迭代修改 PDDL 文件直至成功。
*   **分层验证**：包含规则级（语法）、语义级（词汇一致性）和逻辑级（求解器反馈）三层校验。

*   **基准模型（Benchmarks）**：

    *   **LLM+P**：GPT-4o 直接将自然语言翻译为 PDDL 代码。
    *   **DUPLEX (Fast System)**：仅使用轻量级模型进行单次提取。

*   **评估指标**：成功率（Success Rate, SR），要求计划必须通过验证器检查且可执行。

### 7. 优点
*   **架构解耦**：将语义落地（LLM 擅长）与逻辑搜索（符号规划器擅长）完美分离。
*   **高可靠性**：通过确定性映射彻底解决了 PDDL 语法报错问题。
*   **效率平衡**：双系统设计实现了“简单任务低成本快响应，复杂任务高投入保成功”的平衡。

### 8. 不足与局限
*   **依赖先验知识**：目前仍需人工编写 Domain PDDL 文件（动作定义），尚未实现完全自动化的领域建模。
*   **实时性挑战**：慢系统的迭代反思循环会带来额外延迟，可能不适用于对实时响应要求极高的动态环境。
