## 摘要
机器人操作通常需要记忆：遮挡和状态变化可能导致决策时的观测产生感知混淆（perceptually aliased），使得动作选择在观测层面呈现非马尔可夫性，因为相同的观测可能源于不同的交互历史。大多数具身智能体通过语义压缩的轨迹和基于相似性的检索来实现记忆，这会丢弃用于消除歧义的细粒度感知线索，并可能返回感知上相似但与决策无关的情节。受人类情景记忆的启发，我们提出了 Chameleon，它通过写入基于几何的多模态标记（tokens）来保留消除歧义的上下文，并通过可微记忆栈产生目标导向的回忆。我们还引入了 Camo-Dataset，这是一个基于 UR5e 真实机器人的数据集，涵盖了感知混淆下的情景回忆、空间追踪和序列操作。在各项任务中，Chameleon 在感知易混淆的设置下，相比强基准模型一致地提高了决策可靠性和长程控制能力。

## Abstract
Robotic manipulation often requires memory: occlusion and state changes can make decision-time observations perceptually aliased, making action selection non-Markovian at the observation level because the same observation may arise from different interaction histories. Most embodied agents implement memory via semantically compressed traces and similarity-based retrieval, which discards disambiguating fine-grained perceptual cues and can return perceptually similar but decision-irrelevant episodes. Inspired by human episodic memory, we propose Chameleon, which writes geometry-grounded multimodal tokens to preserve disambiguating context and produces goal-directed recall through a differentiable memory stack. We also introduce Camo-Dataset, a real-robot UR5e dataset spanning episodic recall, spatial tracking, and sequential manipulation under perceptual aliasing. Across tasks, Chameleon consistently improves decision reliability and long-horizon control over strong baselines in perceptually confusable settings.

#### 1. 核心问题与研究动机
*   **核心问题**：机器人长程操作中普遍存在“感知歧义”（Perceptual Aliasing）现象。由于遮挡、状态变化或任务的序列性质，机器人仅凭当前的视觉观测无法做出正确决策（非马尔可夫过程）。例如，在“三杯球”游戏中，决策时刻三个杯子外观完全相同，必须依赖历史轨迹才能确定目标。
*   **研究动机**：现有的具身智能体记忆机制多采用语义压缩（如文本摘要）或基于相似性的检索（RAG模式）。这种方式会丢失关键的细粒度几何线索，且容易检索到视觉相似但决策无关的错误片段。本文受人类“内嗅皮层-海马体-前额叶皮层”（EC-HC-PFC）记忆系统启发，旨在构建一种能保留几何细节并实现目标导向检索的记忆架构。

#### 2. 方法论：Chameleon 架构
Chameleon 采用“感知 $\rightarrow$ 记忆 $\rightarrow$ 策略”的闭环流水线：
*   **感知层（Perception）**：
    *   **双流编码**：腹侧流（Ventral）提取 DINOv2 视觉特征；背侧流（Dorsal）提取以末端执行器（EE）为中心的几何描述符。
    *   **几何偏置注意力**：利用对极几何（Epipolar Geometry）约束和 EE 锚点，实现多视角（前视与手眼相机）特征的跨视图增强，确保写入记忆的 Token 具有空间一致性。
*   **记忆层（Memory）**：
    *   **分层可微栈**：耦合了“情景状态”（慢速、长程存储）和“工作状态”（快速、即时控制）。
    *   **时空锚点**：利用选择性状态空间模型（SSM，类似 Mamba）在不同时间尺度和空间区域上组织记忆，减少干扰。
    *   **HoloHead（想象头）**：通过一个潜在想象目标进行训练，强制记忆状态 $h_t$ 能够预测未来的 2D/3D 路径点，从而实现目标导向的记忆检索（模式补全）。
*   **策略层（Policy）**：
    *   **条件流匹配（CFM）**：仅以记忆状态 $h_t$ 为输入，通过整流流（Rectified Flow）一次性生成未来的末端执行器姿态轨迹，提高长程控制的稳定性。

#### 3. 实验设计
*   **数据集与场景（Camo-Dataset）**：
    *   **指定盘子清理**：考察情景回忆（区分外观相同的盘子）。
    *   **三杯球游戏**：考察空间追踪（在物体交换位置后跟踪目标）。
    *   **添加调味料**：考察序列操作（记忆已执行的步骤，避免重复或遗漏）。
*   **基准模型（Benchmarks）**：对比了 **Diffusion Policy**、**Flow Matching** 和 **ACT** 三种主流具身智能算法。
*   **评估指标**：除了成功率（SR），还引入了决策成功率（DSR）、操作成功率（MSR）和 Cohen’s Kappa 系数，以精细化衡量记忆对决策的贡献。

#### 4. 资源与算力
*   **硬件**：使用单张 **NVIDIA RTX 4090 GPU** 进行训练。
*   **训练细节**：每个任务训练约 20,000 步，采用 AdamW 优化器，支持混合精度训练。
*   **推理延迟**：端到端推理平均延迟为 **82ms**，满足 UR5e 机器人的实时操作需求。

#### 5. 实验数量与充分性
*   **实验规模**：每个任务收集了 120 个演示视频。在测试阶段，每个类别进行了 36 次独立的真实机器人实验。
*   **消融实验**：设计了 5 种变体（无记忆、基于记忆库检索、纯 Mamba、无背侧流、无 HoloHead），系统验证了各组件的必要性。
*   **充分性评价**：实验设计较为充分，涵盖了从感知到逻辑推理的不同维度，且在真实物理机器人上进行了验证，结果具有较高的客观性和说服力。

#### 6. 主要结论与发现
*   **性能领先**：Chameleon 在所有感知歧义任务中显著优于基准模型，尤其在需要长程记忆的序列任务中，基准模型几乎失效（SR 接近 0），而 Chameleon 保持了较高的可靠性。
*   **表征分离**：通过 UMAP 可视化发现，Chameleon 的记忆状态 $h_t$ 能够将视觉相似但历史不同的状态在潜在空间中有效分离（模式分离）。
*   **想象增强检索**：HoloHead 的引入显著提升了决策成功率，证明了预测未来有助于提取当前任务相关的历史信息。

#### 7. 优点与亮点
*   **生物启发性**：将神经科学中的记忆模型（EC-HC-PFC）成功转化为可工程化的深度学习模块。
*   **解决感知歧义**：针对性地解决了机器人领域长期存在的非马尔可夫决策难题。
*   **几何关联**：不同于纯语义记忆，通过背侧流保留了操作所需的空间几何精度。
*   **开源贡献**：提供了专门针对记忆挑战的真实机器人数据集 Camo-Dataset。

#### 8. 不足与局限
*   **泛化性限制**：目前主要在单一机器人平台（UR5e）和特定任务上验证，跨机器人、跨场景的零样本泛化能力尚待评估。
*   **缺乏大模型集成**：尚未与视觉语言模型（VLM）深度结合，在处理开放世界指令和高级语义推理方面可能存在局限。
*   **任务复杂度**：虽然解决了感知歧义，但任务环境相对受控，在极度动态或杂乱的非结构化环境下的鲁棒性有待进一步观察。
