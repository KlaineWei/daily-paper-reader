## 摘要
零样本目标导航要求智能体在没有先验地图或特定任务训练的情况下，在陌生环境中定位未见过的目标物体，这仍然是一个重大挑战。尽管视觉语言模型（VLM）的最新进展为该任务提供了极具前景的常识推理能力，但这些模型仍面临空间幻觉、局部探索死锁以及高层语义意图与底层控制之间脱节的问题。对此，我们提出了一种名为 ReMemNav 的新型分层导航框架，该框架将全景语义先验和情节记忆与 VLM 无缝集成。我们引入了 Recognize Anything Model 来锚定 VLM 的空间推理过程。我们还设计了一种基于情节语义缓冲队列的自适应双模态反思机制。该机制利用历史记忆主动验证目标可见性并修正决策，以防止死锁。对于底层动作执行，ReMemNav 使用深度掩码提取一系列可行操作，允许 VLM 选择最优动作并映射为实际的空间移动。在 HM3D 和 MP3D 上的广泛评估表明，ReMemNav 在成功率和探索效率方面均优于现有的无需训练的零样本基准模型。具体而言，我们实现了显著的绝对性能提升，在 HM3D v0.1 上成功率（SR）和成功路径长度加权（SPL）分别提高了 1.7% 和 7.0%，在 HM3D v0.2 上提高了 18.2% 和 11.1%，在 MP3D 上提高了 8.7% 和 7.9%。

## Abstract
Zero-shot object navigation requires agents to locate unseen target objects in unfamiliar environments without prior maps or task-specific training which remains a significant challenge. Although recent advancements in vision-language models(VLMs) provide promising commonsense reasoning capabilities for this task, these models still suffer from spatial hallucinations, local exploration deadlocks, and a disconnect between high-level semantic intent and low-level control. In this regard, we propose a novel hierarchical navigation framework named ReMemNav, which seamlessly integrates panoramic semantic priors and episodic memory with VLMs. We introduce the Recognize Anything Model to anchor the spatial reasoning process of the VLM. We also design an adaptive dual-modal rethinking mechanism based on an episodic semantic buffer queue. The proposed mechanism actively verifies target visibility and corrects decisions using historical memory to prevent deadlocks. For low-level action execution, ReMemNav extracts a sequence of feasible actions using depth masks, allowing the VLM to select the optimal action for mapping into actual spatial movement. Extensive evaluations on HM3D and MP3D demonstrate that ReMemNav outperforms existing training-free zero-shot baselines in both success rate and exploration efficiency. Specifically, we achieve significant absolute performance improvements, with SR and SPL increasing by 1.7% and 7.0% on HM3D v0.1, 18.2% and 11.1% on HM3D v0.2, and 8.7% and 7.9% on MP3D.

### 1. 核心问题与整体含义（研究动机和背景）
论文关注的是**零样本目标导航（Zero-Shot Object Navigation, ZSON）**，即要求机器人在完全陌生的环境中，在没有预先构建地图或针对性训练的情况下，寻找并导航至指定类别的物体。
*   **研究动机**：虽然视觉语言模型（VLM）具备强大的常识推理能力，但在实际导航中存在三大痛点：
    1.  **空间幻觉**：VLM 容易根据局部纹理错误推断不存在的物体。
    2.  **局部死锁**：由于缺乏记忆，智能体容易在死胡同或已探索区域陷入循环。
    3.  **控制脱节**：高层语义指令与底层物理动作执行之间缺乏有效的衔接。

### 2. 论文提出的方法论
ReMemNav 提出了一种分层认知框架，核心思想是结合**轻量级语义锚点**与**情节记忆**来增强 VLM 的决策稳健性。
*   **语义视觉锚定（RAM）**：引入 Recognize Anything Model (RAM) 作为感知前端，为 VLM 提供全景图像的结构化标签（如“Angle 30: TV, chair”），通过物理实体标签锚定推理，减少幻觉。
*   **情节记忆缓冲队列（EMBQ）**：建立一个滑动窗口队列（容量为 $K$），存储历史位置坐标和 VLM 生成的环境语义描述，而非高成本的度量地图。
*   **自适应双模态反思机制（ADRM）**：
    *   **模式 A（决策评估）**：当智能体未发现目标时，通过坐标投影检查当前路径是否与记忆中的已探索区域重叠。若重叠，则强制 VLM 结合历史描述进行“反思”，选择新方向以打破死锁。
    *   **模式 B（目标验证）**：当 VLM 声称发现目标时，系统强制其对特定视角的图像进行二次确认，过滤视觉伪影。
*   **底层动作映射**：利用深度掩码采样候选动作射线，由 VLM 在视觉提示下选择最优路径点，确保避障和物理可行性。

*   **数据集/场景**：在 **HM3D (v0.1 & v0.2)** 和 **MP3D** 两个大规模高保真 3D 室内环境数据集上进行评估。
*   **Benchmark**：使用标准的导航指标：成功率（SR）和成功路径长度加权（SPL）。

### 6. 主要结论与发现
*   **性能领先**：ReMemNav 在所有免训练方法中达到 SOTA。在 HM3D v0.2 上，SR 提升了 **18.2%**，SPL 提升了 **11.1%**。

*   **记忆容量效应**：实验发现记忆容量 $K$ 呈现“倒 U 型”趋势，最优值为 10。过大的记忆会导致信息过载，干扰 VLM 的推理。
*   **模型敏感性**：更强的 VLM（如 Gemini-3-Flash）能显著提升框架上限，尤其是在处理全景上下文和逻辑演绎方面。

### 7. 优点
*   **分层解耦**：将高层语义推理与底层避障控制有效分离，既保留了 VLM 的常识，又保证了物理安全。
*   **轻量化记忆**：相比于维护复杂的 3D 语义地图，基于文本描述的情节记忆缓冲区极大地降低了计算和存储开销。
*   **鲁棒性强**：双模态反思机制通过“慢思考”模式有效解决了 VLM 固有的幻觉和循环死锁问题。

### 8. 不足与局限
*   **推理延迟**：依赖高性能 VLM（尤其是闭源 API）可能带来网络延迟或较高的推理成本，影响实时交互。
*   **长程记忆限制**：滑动窗口记忆虽然高效，但在极大规模或多层建筑中，可能会丢失较早的关键信息。
*   **动态环境**：实验主要在静态 3D 扫描场景中进行，未充分讨论在有移动障碍物（如行人）的动态环境中的表现。
