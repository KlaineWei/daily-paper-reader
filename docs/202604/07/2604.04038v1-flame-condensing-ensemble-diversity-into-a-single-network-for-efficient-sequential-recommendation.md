## 摘要
序列推荐需要捕捉多样的用户行为，而单一网络往往难以胜任。虽然集成方法通过利用多个网络缓解了这一问题，但从头开始训练所有网络会导致高昂的计算成本，并因噪声互监督产生不稳定性。我们提出了带有对齐模块化集成（Aligned Modular Ensemble）的冻结与可学习网络（Frozen and Learnable networks，简称 FLAME），这是一个将集成级多样性压缩到单一网络中以实现高效序列推荐的新颖框架。在训练过程中，FLAME 通过模块化集成仅使用两个网络即可模拟指数级的多样性。通过将每个网络分解为子模块（如层或块）并进行动态组合，FLAME 生成了丰富的多样化表示模式空间。为了稳定这一过程，我们预训练并冻结其中一个网络作为语义锚点，并采用引导式互学习。这将多样的表示对齐到剩余可学习网络的空间中，从而确保鲁棒的优化。因此，在推理时，FLAME 仅使用该可学习网络，在与单一网络相比零额外开销的情况下，达到了集成级的性能。在六个数据集上的实验表明，FLAME 优于最先进的基准模型，实现了高达 7.69 倍的收敛加速，并在 NDCG@20 上提升了 9.70%。我们在 https://github.com/woo-joo/FLAME_SIGIR26 提供了 FLAME 的源代码。

## Abstract
Sequential recommendation requires capturing diverse user behaviors, which a single network often fails to capture. While ensemble methods mitigate this by leveraging multiple networks, training them all from scratch leads to high computational cost and instability from noisy mutual supervision. We propose {\bf F}rozen and {\bf L}earnable networks with {\bf A}ligned {\bf M}odular {\bf E}nsemble ({\bf FLAME}), a novel framework that condenses ensemble-level diversity into a single network for efficient sequential recommendation. During training, FLAME simulates exponential diversity using only two networks via {\it modular ensemble}. By decomposing each network into sub-modules (e.g., layers or blocks) and dynamically combining them, FLAME generates a rich space of diverse representation patterns. To stabilize this process, we pretrain and freeze one network to serve as a semantic anchor and employ {\it guided mutual learning}. This aligns the diverse representations into the space of the remaining learnable network, ensuring robust optimization. Consequently, at inference, FLAME utilizes only the learnable network, achieving ensemble-level performance with zero overhead compared to a single network. Experiments on six datasets show that FLAME outperforms state-of-the-art baselines, achieving up to 7.69$\times$ faster convergence and 9.70\% improvement in NDCG@20. We provide the source code of FLAME at https://github.com/woo-joo/FLAME_SIGIR26.

序列推荐的核心挑战在于捕捉用户行为的多样性和复杂性。传统的**集成学习（Ensemble Learning）**通过结合多个模型来提升性能，但在推荐场景下存在两大痛点：
*   **计算低效**：训练和推理多个网络会成倍增加参数量、内存占用和延迟，难以满足实时服务需求。
*   **训练不稳定**：从头开始训练多个网络并进行相互监督（Mutual Supervision）时，早期阶段由于缺乏可靠先验，网络间的噪声干扰会导致优化波动大、收敛慢。
**FLAME 的核心目标**是：在保持单一网络推理效率（零额外开销）的同时，获得集成学习级别的表征多样性和鲁棒性。

### 2. 方法论：核心思想与关键技术
FLAME 提出了“模块化集成”与“引导式互学习”相结合的框架，主要包含以下技术细节：
*   **模块化集成（Modular Ensemble）**：
    *   将网络分解为 $M$ 个子模块（如嵌入层、编码层）。
    *   仅使用两个网络：一个**预训练并冻结（Frozen）**的网络作为语义锚点，一个**可学习（Learnable）**的网络。
    *   通过在每一层动态选择来自“冻结”或“可学习”网络的模块，组合出 $2^M$ 条不同的计算路径，从而用极小的代价模拟出指数级的集成多样性。
*   **引导式互学习（Guided Mutual Learning）**：
    *   **对比对齐**：利用对比学习（Contrastive Learning）将这 $2^M$ 种路径生成的表征对齐到统一的语义空间。
    *   **相似度加权**：为了防止结构相似的路径主导损失函数，引入动态权重，降低高相似度路径对的权重，鼓励模型捕捉更互补的模式。
    *   **系数退火**：在训练初期加强对比对齐以获取冻结网络的先验引导，后期逐渐减小对比损失权重，让可学习网络专注于特定推荐任务。
*   **推理阶段**：训练完成后，仅保留“可学习网络”进行预测，实现与单一模型完全一致的推理速度。

*   **架构创新**：提出的“模块化集成”概念非常巧妙，通过子模块的排列组合而非增加完整网络数量来获取多样性。
*   **实用性极强**：推理阶段零额外开销（Zero-overhead），这对于对延迟敏感的工业级推荐系统极具吸引力。
*   **训练友好**：相比于其他集成方法，FLAME 表现出极佳的收敛稳定性和速度。

### 8. 不足与局限
*   **预训练依赖**：FLAME 需要一个预训练好的冻结网络。虽然实验证明它对冻结网络的质量有一定鲁棒性，但仍增加了训练流程的复杂性（需两阶段训练）。

*   **长序列挑战**：虽然在 MovieLens 等数据集表现良好，但在处理超长用户行为序列时的显存占用（由于对比学习的负采样机制）可能仍是一个潜在瓶颈。
