## 摘要
从演示中学习机器人控制策略是一种强大的范式，但现实世界的数据通常是次优的、有噪声的或存在其他缺陷，这给模仿学习和强化学习带来了重大挑战。在这项工作中，我们提出了一个形式化框架，利用时序行为树（TBT）——一种结合了行为树语义的信号时序逻辑（STL）扩展——在将次优轨迹用于下游策略学习之前对其进行修复。针对违反 TBT 规范的演示，一种基于模型的修复算法会修正轨迹段以满足形式化约束，从而产生一个既逻辑一致又具有可解释性的数据集。修复后的轨迹随后被用于提取势函数，以塑造强化学习的奖励信号，在不需要了解智能体运动学模型的情况下，引导智能体走向状态空间中与任务一致的区域。我们在离散网格世界导航以及连续单智能体和多智能体到达-规避任务中证明了该框架的有效性，突显了其在无法假设高质量演示的环境中进行高效数据机器人学习的潜力。

## Abstract
Learning robot control policies from demonstrations is a powerful paradigm, yet real-world data is often suboptimal, noisy, or otherwise imperfect, posing significant challenges for imitation and reinforcement learning. In this work, we present a formal framework that leverages Temporal Behavior Trees (TBT), an extension of Signal Temporal Logic (STL) with Behavior Tree semantics, to repair suboptimal trajectories prior to their use in downstream policy learning. Given demonstrations that violate a TBT specification, a model-based repair algorithm corrects trajectory segments to satisfy the formal constraints, yielding a dataset that is both logically consistent and interpretable. The repaired trajectories are then used to extract potential functions that shape the reward signal for reinforcement learning, guiding the agent toward task-consistent regions of the state space without requiring knowledge of the agent's kinematic model. We demonstrate the effectiveness of this framework on discrete grid-world navigation and continuous single and multi-agent reach-avoid tasks, highlighting its potential for data-efficient robot learning in settings where high-quality demonstrations cannot be assumed.

### 2. 方法论：核心思想与关键技术
该框架分为三个主要阶段：

*   **TBT 轨迹修复（Trajectory Repair）：**
    *   **核心思想：** 使用时序行为树（TBT）定义任务规范（如“必须先到达A再到达B”且“全程避开障碍”）。
    *   **技术细节：** 将修复问题建模为混合整数线性规划（MILP）。给定一个违反规范的原始轨迹 $\tau$，寻找一个在满足 TBT 规范和简化运动学模型 $M$ 的前提下，与原始轨迹偏差最小的修复轨迹 $\tau_R$。
    *   **优化：** 为解决 MILP 的计算复杂性，引入了基于“地标（Landmark）”的修复策略，将问题简化为线性规划（LP），显著提升修复速度。
*   **奖励发现（Reward Discovery）：**
    *   从修复后的轨迹集中提取两种势函数：**接近势函数（Proximity Potential）**引导智能体靠近专家路径；**安全势函数（Safety Potential）**惩罚偏离安全区域的行为。
    *   这些势函数被转化为基于势能的奖励塑造（Potential-based Reward Shaping），确保不改变原始任务的最优解。
*   **策略学习：**
    *   使用 TBT 在线监控器提供的鲁棒性值作为环境奖励，结合上述势能奖励，利用标准 RL 算法（如 PPO）训练策略。

### 6. 主要结论与发现
*   **修复效果显著：** 即使演示数据包含严重违规，TBT 修复也能生成逻辑一致的引导信号。

### 7. 优点
*   **逻辑严谨性：** 结合了形式化逻辑（TBT/STL）的严谨性和 RL 的学习能力。
*   **数据效率：** 能够变废为宝，利用原本无法使用的错误数据。
*   **可解释性：** TBT 规范比黑盒奖励函数更容易理解和调试。
*   **解耦设计：** 奖励塑造不依赖于具体的机器人动力学模型，具有很强的迁移潜力。

### 8. 不足与局限
*   **模型依赖：** 轨迹修复阶段仍需要一个近似的线性运动学模型，对于极度复杂的非线性系统可能难以建模。
*   **离线限制：** 修复过程是离线完成的，无法处理训练过程中动态出现的全新逻辑冲突。
*   **配置敏感：** 在高度随机的环境中，如果障碍物分布变化剧烈，基于固定轨迹提取的势函数可能会失效（论文提到未来需将势函数与当前观测值挂钩）。
*   **计算开销：** 虽然使用了 LP 简化，但对于大规模多智能体系统，MILP/LP 的求解规模仍可能成为瓶颈。
