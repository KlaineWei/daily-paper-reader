## 摘要
大型基础模型为自主系统提供了强大的推理能力，但将语义意图映射为可靠的实时控制仍具挑战。现有方法要么 (i) 让大语言模型 (LLM) 直接生成轨迹——这种方式脆弱、难以验证且易产生延迟；要么 (ii) 在线调整模型预测控制 (MPC) 的目标——这混合了慢速深思熟虑与快速控制，模糊了接口界限。我们提出了智能体快慢规划 (Agentic Fast-Slow Planning)，这是一个在自然时间尺度上解耦感知、推理、规划和控制的分层框架。该框架包含两个桥梁：“感知到决策” (Perception2Decision) 利用车载视觉语言模型 (VLM) 检测器将场景压缩为以自我为中心的拓扑结构，随后通过云端 LLM 决策器将其映射为符号化驾驶指令，在保持可解释性的同时减少了带宽和延迟；“决策到轨迹” (Decision2Trajectory) 将指令转换为可执行路径，其中语义引导的 A* 算法将源自语言的软成本嵌入经典搜索中，使解偏向可行轨迹，而智能体细化模块则利用反馈和记忆调整规划器超参数。最后，MPC 实时跟踪轨迹，并针对困难情况提供可选的云端引导参考。在 CARLA 中的实验表明，与纯 MPC 和 A* 引导的 MPC 基准相比，智能体快慢规划提高了扰动下的鲁棒性，横向偏差减少了高达 45%，完成时间缩短了 12% 以上。代码见 https://github.com/cjychenjiayi/icra2026_AFSP。

## Abstract
Large foundation models enable powerful reasoning for autonomous systems, but mapping semantic intent to reliable real-time control remains challenging. Existing approaches either (i) let Large Language Models (LLMs) generate trajectories directly - brittle, hard to verify, and latency-prone - or (ii) adjust Model Predictive Control (MPC) objectives online - mixing slow deliberation with fast control and blurring interfaces. We propose Agentic Fast-Slow Planning, a hierarchical framework that decouples perception, reasoning, planning, and control across natural timescales. The framework contains two bridges. Perception2Decision compresses scenes into ego-centric topologies using an on-vehicle Vision-Language Model (VLM) detector, then maps them to symbolic driving directives in the cloud with an LLM decision maker - reducing bandwidth and delay while preserving interpretability. Decision2Trajectory converts directives into executable paths: Semantic-Guided A* embeds language-derived soft costs into classical search to bias solutions toward feasible trajectories, while an Agentic Refinement Module adapts planner hyperparameters using feedback and memory. Finally, MPC tracks the trajectories in real time, with optional cloud-guided references for difficult cases. Experiments in CARLA show that Agentic Fast-Slow Planning improves robustness under perturbations, reducing lateral deviation by up to 45% and completion time by over 12% compared to pure MPC and an A*-guided MPC baseline. Code is available at https://github.com/cjychenjiayi/icra2026_AFSP.

*   **研究动机**：虽然大模型（LLM/VLM）具备强大的语义推理能力，但将其直接应用于自动驾驶的实时控制面临三大挑战：直接生成轨迹过于脆弱且难以验证；云端推理延迟高；高层语义推理与底层快速控制之间的接口模糊，缺乏有效衔接。
*   **核心问题**：如何在保证实时性、安全性和可解释性的前提下，将大模型的“慢思考”（语义推理）与控制系统的“快反应”（实时执行）有机结合。

### 2. 方法论：Agentic Fast-Slow Planning (AFSP)
该框架通过“尺度感知解耦”设计，将系统分为感知、推理、规划、控制四个层级，并通过两个关键桥梁连接：

*   **Perception2Decision（感知到决策）**：
    *   **端云协同**：车载端使用轻量化 VLM（Topology Detector）将原始图像压缩为以自我为中心的“拓扑图”（包含物体类别、距离、方位等符号信息），极大地降低了上传带宽。
    *   **语义决策**：云端 LLM 接收拓扑图，通过思维链（CoT）输出符号化驾驶指令（如 `LEFT`, `KEEP`）和驾驶风格。
*   **Decision2Trajectory（决策到轨迹）**：
    *   **语义引导 A* 算法**：将 LLM 的指令转化为“软成本”（Soft Costs）嵌入经典 A* 搜索。公式化表示为 $g(s') = g(s) + c_{geom} + c_{sem}$，其中 $c_{sem}$ 根据动作是否符合指令（正确、延迟、错误、过度）给予奖励或惩罚。
    *   **智能体细化模块（Agentic Refinement）**：利用 LLM 作为一个闭环调节器，根据规划反馈和记忆库自动调整 A* 的超参数（如各项成本权重），模拟人类专家的调参过程。
*   **实时控制**：采用云端引导的 MPC（模型预测控制），在常规情况下本地跟踪，在复杂场景下参考云端生成的全局轨迹。

### 3. 实验设计
*   **实验场景**：基于 CARLA 仿真器，涵盖了 Town2-7 和 Town10HD 等多种城镇环境。
*   **数据集**：构建了一个包含 50,000 帧训练集和 1,000 帧测试集的自定义数据集，涵盖 49 类物体。
*   **对比方法（Benchmarks）**：
    1.  **纯 MPC**：仅依赖局部避障。
    2.  **A*-MPC**：经典 A* 规划配合 MPC 控制。
    3.  **AFSP（本文方法）**：带语义引导和智能体调参的完整框架。
*   **评估指标**：完成时间（Finish Time）、轨迹长度、平均/最大横向偏差（Lateral Deviation）、速度波动等。

### 4. 资源与算力
*   **模型训练**：使用了 **4 张 NVIDIA A100 GPU** 进行 VLM（基于 InternVL-2B）的微调。
*   **训练时长**：微调过程持续了 12 个 Epoch。
*   **推理端**：云端 LLM 决策使用了 DeepSeek-V3 API，车载端感知使用轻量化 VLM。

### 5. 实验数量与充分性
*   **实验规模**：
    *   针对感知层，对比了三种不同的微调策略（仅视觉、全参数、两阶段微调）。
    *   针对决策层，测试了 200 帧图像中的 48 个典型决策场景。
    *   针对控制层，在 CARLA 中设置了 3 种不同难度的地图扰动场景（名义地图、平移扰动、大幅平移+半径膨胀），每组实验重复 10 次以减少随机性。
*   **充分性评价**：实验设计较为全面，包含了消融分析（如超参数影响）和鲁棒性测试（地图偏移），能够客观反映系统在面对感知误差和环境扰动时的表现。

### 6. 主要结论与发现
*   **性能提升**：AFSP 在所有场景中均表现最优。相比纯 MPC，其最大横向偏差降低了约 **45%**，任务完成时间缩短了 **12%** 以上。
*   **鲁棒性**：语义引导的 A* 能够纠正因地图偏移导致的几何规划错误，保持驾驶意图的一致性。

### 7. 优点（亮点）
*   **解耦设计**：巧妙地解决了大模型推理慢与实时控制快之间的矛盾，通过符号化接口实现了“快慢结合”。
*   **软约束机制**：将语义指令作为 A* 的软成本而非硬约束，既能引导规划，又保留了在极端情况下违背指令以确保几何安全的能力。
*   **自动化调参**：引入 Agentic Refinement 模块，解决了经典算法依赖人工调参的痛点，增强了系统的自适应能力。

### 8. 不足与局限
*   **实时性瓶颈**：尽管进行了优化，云端 LLM 的推理延迟（数秒级）仍无法支持极高动态的瞬时决策，目前更适用于战略级路径规划。
*   **实验环境单一**：实验主要在 CARLA 仿真环境中进行，尚未在真实道路或更复杂的长尾天气/光照条件下验证。
*   **依赖 API 稳定性**：系统性能高度依赖云端 API 的响应速度和稳定性，在网络波动环境下的降级处理机制（Fail-safe）讨论较少。
