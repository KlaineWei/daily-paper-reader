## 摘要
视觉-语言-动作（VLA）模型作为具身控制的大型基础模型，在操作任务中展现出强大的性能。然而，其高性能伴随着高昂的推理成本。为了提高效率，近期的方法采用了动作分块（action chunking）技术，即预测一系列未来动作以进行开环执行。尽管开环执行能有效减少计算量，但由于缺乏闭环反馈，它对环境变化较为敏感，且容易产生误差累积。为了解决这一局限性，我们提出了 SV-VLA（针对 VLA 控制的投机验证），该框架将高效的开环长程规划与轻量级的闭环在线验证相结合。具体而言，SV-VLA 使用重型 VLA 作为低频宏观规划器来生成动作块及规划上下文，同时利用轻量级验证器根据最新观测持续监控执行情况。在当前观测和规划上下文的共同约束下，验证器将已规划动作与闭环参考动作进行对比，并仅在必要时触发重新规划。实验表明，SV-VLA 结合了分块预测的高效性与闭环控制的鲁棒性，能够在动态环境中实现高效且可靠的基于 VLA 的控制。代码见：https://github.com/edsad122/SV-VLA。

## Abstract
Vision-Language-Action (VLA) models, as large foundation models for embodied control, have shown strong performance in manipulation tasks. However, their performance comes at high inference cost. To improve efficiency, recent methods adopt action chunking, which predicts a sequence of future actions for open-loop execution. Although effective for reducing computation, open-loop execution is sensitive to environmental changes and prone to error accumulation due to the lack of close-loop feedback. To address this limitation, we propose Speculative Verification for VLA Control (SV-VLA), a framework that combines efficient open-loop long-horizon planning with lightweight closed-loop online verification. Specifically, SV-VLA uses a heavy VLA as a low-frequency macro-planner to generate an action chunk together with a planning context, while a lightweight verifier continuously monitors execution based on the latest observations. Conditioned on both the current observation and the planning context, the verifier compares the planned action against a closed-loop reference action and triggers replanning only when necessary. Experiments demonstrate that SV-VLA combines the efficiency of chunked prediction with the robustness of closed-loop control, enabling efficient and reliable VLA-based control in dynamic environments. Code is available: https://github.com/edsad122/SV-VLA.

*   **研究背景**：视觉-语言-动作（VLA）模型（如 RT-2, OpenVLA）在机器人操控任务中表现出色，但其巨大的参数量导致推理延迟极高，难以实现高频闭环控制。
*   **核心痛点**：
    *   **动作分块（Action Chunking）**：虽然通过一次推理预测多个动作（开环执行）提高了效率，但在动态环境中容易因环境变化或误差累积而失败。
    *   **投机解码（Speculative Decoding）**：在 NLP 领域有效，但在机器人领域失效。因为机器人未来的观测取决于当前动作的执行结果，无法像文本那样在固定上下文中并行验证。
*   **研究动机**：开发一种既能享受动作分块的高效率，又能具备闭环控制鲁棒性的新框架。

### 2. 方法论：SV-VLA 框架
核心思想是**“昂贵且低频的规划，廉价且高频的验证”**。
*   **宏观规划器（Macro-Planner）**：使用冻结的重型 VLA 模型。在规划起点，输入当前观测、指令和状态，输出一个动作块 $A_{macro}$ 以及一个内部特征 $F_0$（总结了高层规划上下文）。
*   **轻量级验证器（Lightweight Verifier）**：
    *   **结构**：由轻量级视觉骨干（如 ViT-Tiny）和浅层 MLP 组成。
    *   **输入**：当前最新的视觉观测 $I_t$ 和来自重型模型的规划上下文 $F_0$。
    *   **功能**：在每个控制步预测一个“参考动作” $a'_t$。
*   **基于偏差的重规划机制（Deviation-based Replanning）**：
    *   计算预设动作 $a_t$ 与参考动作 $a'_t$ 之间的 L1 距离。
    *   **判定逻辑**：若距离低于阈值 $\tau$，则继续执行原计划；若超过阈值，则认为环境发生显著变化或执行偏离，立即丢弃剩余动作块，触发重型 VLA 进行重规划。

### 6. 主要结论与发现
*   **性能提升**：在长动作块（K=64）设置下，SV-VLA 将平均成功率从 **79.5% 提升至 90.9%**。
*   **效率优势**：相比于频繁调用重型模型的 K=8 基准，SV-VLA 实现了 **2.17 倍的加速**，同时保持了相近的成功率。
*   **关键发现**：轻量级验证器必须同时结合“全局规划上下文”和“实时视觉反馈”才能有效工作；单纯的加速生成（投机解码）而不引入闭环反馈，无法解决具身控制中的执行偏差问题。

### 7. 优点
*   **架构优雅**：巧妙地解决了 VLA 模型推理慢与闭环控制需求之间的矛盾。
*   **低成本适配**：不需要重新训练庞大的 VLA 模型，只需训练一个极小的验证头，易于部署到现有模型上。
*   **即时纠错**：定性实验显示，系统能检测到如“抓取失败”等意外情况并立即重规划，显著增强了系统的自愈能力。

### 8. 不足与局限
*   **阈值依赖**：重规划阈值 $\tau$ 需要手动设定，且不同任务的最优阈值可能不同，缺乏自适应性。
*   **验证器能力有限**：目前的验证器只能决定“是否重规划”，而不能直接对动作进行微调（Local Correction）。
*   **环境局限**：实验主要在模拟器中进行，尚未在具有更复杂光照、物理噪声的真实世界硬件上进行大规模验证。
