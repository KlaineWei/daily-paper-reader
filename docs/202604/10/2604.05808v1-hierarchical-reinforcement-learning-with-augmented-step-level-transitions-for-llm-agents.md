## 摘要
大语言模型（LLM）智能体在复杂的交互式决策任务中展现出了强大的能力。然而，现有的 LLM 智能体通常依赖于日益增长的交互历史，导致了高昂的计算成本和有限的可扩展性。在本文中，我们提出了 STEP-HRL，这是一个分层强化学习（HRL）框架，它通过仅以单步转移而非完整交互历史为条件，实现了步级（step-level）学习。STEP-HRL 对任务进行分层构建，利用已完成的子任务来表示整个任务的全局进度。通过引入局部进度模块，它还迭代且有选择性地总结每个子任务内的交互历史，从而生成局部进度的紧凑摘要。这些组件共同为高层和底层策略生成了增强的步级转移。在 ScienceWorld 和 ALFWorld 基准测试上的实验结果一致表明，STEP-HRL 在性能和泛化能力方面显著优于基准模型，同时减少了 token 使用量。我们的代码可在 https://github.com/TonyStark042/STEP-HRL 获取。

## Abstract
Large language model (LLM) agents have demonstrated strong capabilities in complex interactive decision-making tasks. However, existing LLM agents typically rely on increasingly long interaction histories, resulting in high computational cost and limited scalability. In this paper, we propose STEP-HRL, a hierarchical reinforcement learning (HRL) framework that enables step-level learning by conditioning only on single-step transitions rather than full interaction histories. STEP-HRL structures tasks hierarchically, using completed subtasks to represent global progress of overall task. By introducing a local progress module, it also iteratively and selectively summarizes interaction history within each subtask to produce a compact summary of local progress. Together, these components yield augmented step-level transitions for both high-level and low-level policies. Experimental results on ScienceWorld and ALFWorld benchmarks consistently demonstrate that STEP-HRL substantially outperforms baselines in terms of performance and generalization while reducing token usage. Our code is available at https://github.com/TonyStark042/STEP-HRL.

*   **核心问题**：现有的 LLM 智能体在处理复杂决策任务时，通常依赖于**全量交互历史**（History-conditioned）。随着任务步数增加，上下文长度剧增，导致：
    1.  **计算成本高昂**：Transformer 的注意力机制随长度呈平方级增长。
    2.  **推理干扰**：冗余或无关的历史信息会掩盖关键决策信号，降低推理质量。
    3.  **信用分配困难**：长序列使得强化学习中的奖励归因变得极其复杂。
*   **研究动机**：探索一种“步级（Step-level）”决策模式，使智能体仅依赖当前观察和紧凑的状态表示即可做出决策，从而摆脱对长上下文的依赖。

### 2. 方法论：STEP-HRL 框架
核心思想是将任务分层，并通过“进度建模”将长历史压缩为紧凑的文本表示。
*   **三位一体的策略结构**：
    *   **高层策略 ($\pi_h$)**：负责将全局目标分解为一系列子任务（Subtasks）。它以已完成的子任务序列作为“全局进度”参考。
    *   **局部进度策略 ($\pi_p$)**：这是核心创新点。它在每个子任务内部，迭代地将上一时刻的进度摘要、当前动作和观察总结成一个新的、长度受控的“局部进度”字符串。
    *   **底层策略 ($\pi_l$)**：仅根据当前子任务、当前观察和局部进度摘要来生成具体动作。
*   **训练流程**：
    1.  **行为克隆 (BC) 初始化**：利用专家演示数据（通过 DeepSeek 标注子任务和进度）对三个策略进行联合微调。
    2.  **步级离线强化学习 (Offline RL)**：
        *   **隐式价值学习**：采用 IQL (Implicit Q-Learning) 范式，通过状态价值函数 $V$ 和动作价值函数 $Q$ 的期望回归来学习，无需显式采样。
        *   **优势加权回归 (AWR)**：利用学习到的价值函数计算优势值，引导策略向高奖励动作偏移。
*   **参数共享设计**：高层、底层和进度策略共享同一个 LLM 主干参数，但配备独立的 Critic 网络，以实现高效的知识迁移。

### 7. 优点（亮点）
*   **步级转移机制**：成功将 History-conditioned 任务转化为类似 Markov 的步级决策，极大地提高了推理效率。
*   **局部进度模块**：通过文本摘要的方式实现了动态的状态压缩，既保留了关键信息又过滤了噪声。
*   **参数高效**：三位一体的共享架构减少了训练开销，同时促进了不同层级间的语义一致性。
