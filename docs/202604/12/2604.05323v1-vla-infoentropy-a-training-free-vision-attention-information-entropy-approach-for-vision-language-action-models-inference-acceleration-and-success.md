## 摘要
视觉-语言-动作（VLA）模型集成了视觉感知、语言理解和动作决策，以实现跨模态语义对齐，展现出广泛的应用潜力。然而，对高维视觉特征、复杂语言输入和连续动作序列的联合处理带来了显著的计算开销和较低的推理效率，从而阻碍了其实时部署和可靠性。为了解决这一问题，我们利用图像熵来量化每个视觉 token 的灰度分布特征，并引入注意力熵来捕捉任务相关文本上的注意力分数分布。视觉熵能够识别纹理丰富或具有结构信息的区域，而注意力熵则能精准定位语义相关的 token。结合时间步信息，这些指标实现了一种动态转换策略，使模型的关注点从全局视觉特征转向注意力引导的局部信息区域。因此，由此产生的 VLA-InfoEntropy 方法整合了空间、语义和时间线索，在减少冗余的同时保留了关键内容。广泛的实验表明，我们的方法减少了推理参数量，加快了推理速度，并优于现有方法。

## Abstract
Vision-Language-Action (VLA) models integrate visual perception, language understanding, and action decision-making for cross-modal semantic alignment, exhibiting broad application potential. However, the joint processing of high-dimensional visual features, complex linguistic inputs, and continuous action sequences incurs significant computational overhead and low inference efficiency, thereby hindering real-time deployment and reliability. To address this issue, we use image entropy to quantify the grayscale distribution characteristics of each visual token and introduce attention entropy to capture the distribution of attention scores over task-related text. Visual entropy identifies texture-rich or structurally informative regions, while attention entropy pinpoints semantically relevant tokens. Combined with timestep information, these metrics enable a dynamic transition strategy that shifts the model's focus from global visual features to attention-guided local informative regions. Thus, the resulting VLA-InfoEntropy method integrates spatial, semantic, and temporal cues to reduce redundancy while preserving critical content. Extensive experiments show that our method reduces inference parameters, accelerates inference speed, and outperforms existing approaches.

视觉-语言-动作（VLA）模型虽然在机器人控制和具身智能领域表现出色，但其推理过程面临巨大的计算瓶颈。由于需要同时处理高维视觉特征、复杂文本指令和连续动作序列，推理延迟较高，难以满足实时部署的要求。
*   **核心问题**：现有的加速方法（如 token 剪枝或缓存复用）往往孤立地处理视觉冗余或语义相关性，且忽略了任务执行过程中的时间动态性，导致在减少计算量的同时可能丢失关键信息，甚至降低任务成功率。
*   **研究目标**：提出一种无需训练（Training-free）的方法，通过信息熵理论动态识别并保留关键 token，实现推理加速与性能提升的平衡。

### 2. 方法论：核心思想与关键技术
该方法的核心在于利用**信息熵**来量化 token 的重要性，并结合**时间步信息**进行动态调整。
*   **视觉熵 (Visual Entropy)**：通过计算图像 patch 的灰度分布熵，识别纹理丰富、结构复杂的区域（高熵区域通常包含更多物理特征）。
*   **注意力熵 (Attention Entropy)**：利用模型内部的交叉注意力矩阵，计算视觉 token 对文本指令的注意力分布熵。熵值越低，说明该 token 与特定指令语义关联越紧密。
*   **动态转换策略 (VLA-InfoEntropy)**：
    *   **核心公式**：设计了随时间步 $t$ 变化的动态选择机制。在任务初期，模型侧重于全局视觉上下文（由视觉熵引导）；随着任务推进，模型逐渐转向关注与任务相关的局部细节（由注意力熵引导）。
    *   **KV Cache 复用**：将识别出的“非重要”token 视为静态，直接复用前一帧的 Key-Value 缓存，仅对“重要”token 进行完整计算。
*   **算法流程**：输入图像 -> 计算视觉/注意力熵 -> 根据当前时间步 $t$ 分配 token 比例 -> 筛选重要 token -> 执行 KV Cache 复用推理 -> 输出动作。

### 6. 主要结论与发现
*   **性能提升**：在 LIBERO-Spatial 任务上成功率达到 86.4%，平均成功率（76.4%）优于基准 OpenVLA（75.0%）和其他加速方法。

### 7. 优点（亮点）
*   **免训练特性**：无需昂贵的微调或重新训练过程，具有极强的即插即用性。

*   **动态适应**：模拟了人类视觉“先全局后局部”的感知过程，使模型在不同任务阶段能自适应地分配计算资源。

### 8. 不足与局限
*   **环境局限**：实验主要在 LIBERO 模拟器中进行，尚未在复杂的真实物理世界机器人上进行大规模验证。

*   **极端场景风险**：在光照极度不均或背景极其复杂的环境下，单纯依靠灰度分布的视觉熵可能会失效。
