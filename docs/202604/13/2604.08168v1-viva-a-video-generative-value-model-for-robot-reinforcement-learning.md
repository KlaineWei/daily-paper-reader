## 摘要
视觉-语言-动作（VLA）模型通过大规模预训练推动了机器人操控的发展，但由于部分可观测性和延迟反馈，其在现实世界中的部署仍面临挑战。强化学习通过价值函数解决了这一问题，价值函数能够评估任务进度并指导策略改进。然而，现有的基于视觉语言模型（VLM）构建的价值模型难以捕捉时间动态，从而损害了长程任务中价值估计的可靠性。在本文中，我们提出了 ViVa，这是一种视频生成价值模型，它将预训练的视频生成器重新用于价值估计。ViVa 以当前的观测和机器人本体感知作为输入，联合预测未来的本体感知和当前状态的标量价值。通过利用预训练视频生成器的时空先验，我们的方法将价值估计建立在预期的具身动态之上，超越了静态快照，将价值与预见性内在耦合。通过集成到 RECAP 中，ViVa 在现实世界的纸箱组装任务上取得了显著改进。对所有三项任务的定性分析证实，ViVa 产生了更可靠的价值信号，能够准确反映任务进度。通过利用视频语料库中的时空先验，ViVa 还能泛化到新物体，凸显了视频生成模型在价值估计方面的潜力。

## Abstract
Vision-language-action (VLA) models have advanced robot manipulation through large-scale pretraining, but real-world deployment remains challenging due to partial observability and delayed feedback. Reinforcement learning addresses this via value functions, which assess task progress and guide policy improvement. However, existing value models built on vision-language models (VLMs) struggle to capture temporal dynamics, undermining reliable value estimation in long-horizon tasks. In this paper, we propose ViVa, a video-generative value model that repurposes a pretrained video generator for value estimation. Taking the current observation and robot proprioception as input, ViVa jointly predicts future proprioception and a scalar value for the current state. By leveraging the spatiotemporal priors of a pretrained video generator, our approach grounds value estimation in anticipated embodiment dynamics, moving beyond static snapshots to intrinsically couple value with foresight. Integrated into RECAP, ViVa delivers substantial improvements on real-world box assembly. Qualitative analysis across all three tasks confirms that ViVa produces more reliable value signals, accurately reflecting task progress. By leveraging spatiotemporal priors from video corpora, ViVa also generalizes to novel objects, highlighting the promise of video-generative models for value estimation.

### 1. 核心问题与整体含义（研究动机和背景）
论文的核心问题在于：**现有的机器人强化学习（RL）价值函数缺乏对时间动态的理解。**
目前的视觉-语言-动作（VLA）模型在处理长程任务时，通常依赖基于视觉语言模型（VLM）的价值函数来评估进度。然而，VLM 主要在静态图像上预训练，擅长语义识别却不擅长建模物理世界的动态演变。这导致价值函数在复杂任务中信号不稳定、对错误动作不敏感。研究团队认为，**价值估计本质上是一个预测未来的问题**，因此提出利用预训练的视频生成模型（具备强大的时空先验）来构建价值函数。

### 2. 方法论：核心思想与技术细节
ViVa 的核心思想是将**价值估计（Value Estimation）**与**未来状态预测（Future Prediction）**耦合，利用视频生成器的生成能力来“想象”未来，从而更准确地评估当前状态。

*   **架构基础：** 基于 **Wan2.2**（一种预训练的视频扩散 Transformer，DiT）。
*   **多模态潜变量注入（Latent Injection）：**
    *   将图像通过 VAE 编码为潜帧。
    *   将低维向量（当前本体感受 $q_t$、标量价值 $v_t$）通过重复填充（Repeat-padding）或广播（Broadcast）操作映射为与图像潜帧形状一致的张量。
*   **联合预测任务：** 模型输入当前的多视角图像和本体感受，作为“干净”的条件帧；目标是预测 $K$ 步后的**未来本体感受** $\hat{q}_{t+K}$ 和**当前状态的标量价值** $\hat{v}_t$。
*   **价值定义：** 采用归一化回报（Normalized Return）。成功轨迹的价值在 $[0, 1)$ 之间随进度增长，失败轨迹则通过惩罚项映射到 $[1, 2)$ 之间，从而在数值上清晰区分成功进度与失败状态。
*   **训练目标：** 使用流匹配（Flow Matching）目标函数，同时优化本体感受预测损失和价值预测损失。

### 3. 实验设计
*   **实验场景：** 包含三个具有挑战性的真实世界双臂协作任务：
    1.  **衬衫折叠（Shirt Folding）：** 处理高度可变形的织物。
    2.  **纸箱组装（Box Packaging）：** 长程、多阶段的精确操控。
    3.  **卫生纸整理（Toilet Paper Organization）：** 涉及撕纸、卷纸和贴标签。
*   **Benchmark 与对比方法：**
    *   **纯模仿学习：** $\pi_{0.5}$ 和 Gigabrain-0。
    *   **强化学习基准：** 集成在 RECAP 框架下的 VLM-based 价值模型（基于 SigLIP 编码器）。
    *   **泛化性测试：** 在未见过的物体（折叠长裤）上测试零样本泛化能力。

### 4. 资源与算力
论文明确提到了计算成本：
*   **硬件：** 使用了 **8 台 NVIDIA A800 GPU**。
*   **训练时长：** ViVa 的训练成本约为 **4 GPU·days**（比 VLM 基准的 6 GPU·days 更快）。
*   **推理效率：** 推理延迟为 **0.18 秒/帧**，能够满足机器人实时反馈的需求。

### 5. 实验数量与充分性
*   **实验规模：** 涵盖了 3 个真实任务的性能对比、1 个跨类别的泛化实验，以及针对视频主干网络、本体感受预测必要性、预测步长 $K$ 的多组消融实验。
*   **充分性与公平性：** 实验设计较为客观。通过在相同的 RECAP 框架下仅更换价值模型，实现了公平的受控对比。定性分析部分展示了大量的价值曲线对比，直观地证明了 ViVa 在捕捉任务里程碑和检测细微错误（如抓取失败、受力不均）方面的优越性。

### 6. 主要结论与发现
*   **性能提升：** 在最复杂的纸箱组装任务中，ViVa 将成功率从 VLM 基准的 58% 提升至 **73%**，吞吐量也显著提高。
*   **信号质量：** 相比 VLM 产生的波动或单调上升的信号，ViVa 提供的价值信号更平滑，且在发生错误时会有明显的数值下降（敏感度高）。
*   **泛化能力：** 即使在训练集中未出现的物体（长裤）上，ViVa 也能准确识别操作里程碑，证明了视频生成器时空先验的强大迁移能力。
*   **关键组件：** 消融实验证明，**预测未来本体感受**对于模型理解具身动态至关重要，不带此项预测的模型对物理错误不敏感。

### 7. 优点
*   **视角创新：** 首次将视频生成模型重新定义为强化学习的价值函数，而非仅仅作为世界模型或策略。
*   **时空感知：** 成功利用了视频大模型的先验知识，解决了静态 VLM 无法理解物理过程演变的痛点。
*   **鲁棒性：** 能够检测到非常细微的物理交互错误（如异步抬升、位置微调不当），这在以往的视觉价值模型中很难实现。
*   **效率优化：** 尽管使用了生成式架构，但通过合理的潜变量设计，其训练和推理效率优于某些基于重型视觉编码器的判别式模型。

### 8. 不足与局限
*   **实验覆盖面：** 受限于真实机器人实验的高昂成本和 RECAP 框架的长周期，大规模定量实验仅集中在纸箱组装任务上，其他任务主要以定性分析为主。
*   **预测步长敏感性：** 实验显示预测步长 $K$ 对结果影响较大，过长或过短都会导致信号不稳定，这需要针对不同任务进行调优。
*   **应用限制：** 目前主要验证了在双臂操控任务上的效果，对于更广阔的移动导航或高速动态交互场景的适用性尚待验证。
