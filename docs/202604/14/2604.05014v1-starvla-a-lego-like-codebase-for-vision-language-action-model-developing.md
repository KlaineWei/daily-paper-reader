## 摘要
构建通用具身智能体需要整合感知、语言理解和动作，这些是基于多模态基础模型（包括视觉-语言模型和世界模型的最新进展）的视觉-语言-动作（VLA）方法所解决的核心能力。尽管取得了快速进展，但 VLA 方法在不兼容的架构、代码库和评估协议中仍然处于碎片化状态，阻碍了有原则的比较和可复现性。我们提出了 StarVLA，一个用于 VLA 研究的开源代码库。StarVLA 从三个方面应对了这些挑战。首先，它提供了一种模块化的“主干网络-动作头”（backbone-action-head）架构，支持 VLM 主干（如 Qwen-VL）和世界模型主干（如 Cosmos）以及代表性的动作解码范式，所有这些都在一个共享的抽象层下，其中主干网络和动作头都可以独立更换。其次，它提供了可重用的训练策略，包括跨具身学习（cross-embodiment learning）和多模态协同训练（multimodal co-training），这些策略在支持的范式中具有一致的适用性。第三，它通过统一的评估接口集成了主要的基准测试，包括 LIBERO、SimplerEnv、RoboTwin 2.0、RoboCasa-GR1 和 BEHAVIOR-1K，支持仿真和真实机器人部署。StarVLA 还提供了简单且完全可复现的单基准训练方案，尽管数据工程极少，但在使用 VLM 和世界模型主干的多个基准测试中，其表现已经达到或超过了之前的方法。据我们所知，StarVLA 是目前最全面的开源 VLA 框架之一，我们期望它能降低复现现有方法和开发新方法原型的门槛。StarVLA 正在积极维护和扩展中；随着项目的进展，我们将更新本报告。代码和文档可在 https://github.com/starVLA/starVLA 获取。

## Abstract
Building generalist embodied agents requires integrating perception, language understanding, and action, which are core capabilities addressed by Vision-Language-Action (VLA) approaches based on multimodal foundation models, including recent advances in vision-language models and world models. Despite rapid progress, VLA methods remain fragmented across incompatible architectures, codebases, and evaluation protocols, hindering principled comparison and reproducibility. We present StarVLA, an open-source codebase for VLA research. StarVLA addresses these challenges in three aspects. First, it provides a modular backbone--action-head architecture that supports both VLM backbones (e.g., Qwen-VL) and world-model backbones (e.g., Cosmos) alongside representative action-decoding paradigms, all under a shared abstraction in which backbone and action head can each be swapped independently. Second, it provides reusable training strategies, including cross-embodiment learning and multimodal co-training, that apply consistently across supported paradigms. Third, it integrates major benchmarks, including LIBERO, SimplerEnv, RoboTwin~2.0, RoboCasa-GR1, and BEHAVIOR-1K, through a unified evaluation interface that supports both simulation and real-robot deployment. StarVLA also ships simple, fully reproducible single-benchmark training recipes that, despite minimal data engineering, already match or surpass prior methods on multiple benchmarks with both VLM and world-model backbones. To our best knowledge, StarVLA is one of the most comprehensive open-source VLA frameworks available, and we expect it to lower the barrier for reproducing existing methods and prototyping new ones. StarVLA is being actively maintained and expanded; we will update this report as the project evolves. The code and documentation are available at https://github.com/starVLA/starVLA.

*   **核心问题**：缺乏一个统一的抽象框架，导致研究者难以公平地比较不同设计选择（例如：基于 VLM 的方法与基于世界模型的方法之间的优劣），也难以复现已有成果或快速开发新原型。

### 2. 方法论：核心思想与关键技术
*   **核心思想**：采用**“骨干网络-动作头”（Backbone-Action-Head）**的解耦架构。将 VLA 系统抽象为一个策略 $\pi$，将多模态观测和指令映射为动作序列及辅助输出。
*   **关键技术细节**：
    *   **统一 I/O 接口**：训练和推理均直接处理原始环境观测（Raw Images/Strings），减少了因过度预处理导致的训练/测试分布偏移。
    *   **四种代表性范式实现**：
        1.  **StarVLA-FAST**：离散动作标记化，利用 LLM 词表进行自回归生成。
        2.  **StarVLA-OFT**：并行回归，通过轻量级 MLP 预测连续动作。
        3.  **StarVLA-π**：基于流匹配（Flow-matching）的去噪动作专家。
        4.  **StarVLA-GR00T**：双系统设计（System 1 快速动作生成，System 2 慢速逻辑推理）。
    *   **灵活的训练策略**：支持标准行为克隆（SFT）、多模态协同训练（保持 VLM 的推理能力）以及跨具身混合数据训练。
    *   **Server-Client 评估架构**：模型作为服务端运行，不同基准测试作为客户端通过 WebSocket 通信，解决了不同仿真器依赖冲突的问题。

*   **充分性与公平性**：实验设计非常充分且客观。作者特意强调在“最小化数据工程”的前提下建立基准线，不依赖复杂的预训练混合数据，确保了对比的纯粹性。此外，针对 SimplerEnv 等高方差基准，采用了多次运行取平均值的严谨做法。

### 6. 主要结论与发现
*   **模块化优势**：证明了通过统一的“骨干-动作头”抽象，可以有效整合 VLM 和世界模型（如 Cosmos）作为底座，且性能互有胜负，证明了框架的普适性。
*   **性能表现**：StarVLA 提供的简单训练方案在多个基准（如 LIBERO, SimplerEnv）上达到或超过了现有的 SOTA 性能。

*   **通用性验证**：单个通用模型在跨基准训练后，在 RoboCasa 等复杂任务上的表现甚至优于专门的专家模型。

### 7. 优点
*   **极高的工程质量**：解决了 VLA 研究中长期存在的环境配置难、代码复用率低的问题。
*   **高度灵活性**：支持骨干网络和动作头的“插拔式”更换，极大方便了消融实验。
*   **透明与可复现**：提供了详尽的训练脚本、YAML 配置及算力开销分析，对社区非常友好。

### 8. 不足与局限
*   **强化学习集成**：目前主要支持监督学习（BC）和协同训练，强化学习（RL）微调功能仍在集成中。
*   **算力门槛**：尽管代码开源，但训练高性能 VLA 模型（如 4B 参数以上）仍需要昂贵的计算资源，普通研究者难以负担。
*   **实机实验深度**：虽然框架支持实机部署，但论文中的量化数据主要来自仿真环境，缺乏大规模真实世界环境下的鲁棒性对比。
