## 摘要
视觉-语言-动作（VLA）模型通过大规模预训练推动了机器人操作的发展，但由于部分可观测性和延迟反馈，其在现实世界中的部署仍面临挑战。强化学习通过价值函数来解决这一问题，价值函数用于评估任务进度并指导策略改进。然而，现有的基于视觉语言模型（VLM）构建的价值模型难以捕捉时间动态，从而损害了长程任务中价值估计的可靠性。在本文中，我们提出了 ViVa，这是一种视频生成价值模型，它将预训练的视频生成器重新用于价值估计。ViVa 以当前的观测和机器人本体感知作为输入，联合预测未来的本体感知以及当前状态的标量价值。通过利用预训练视频生成器的时空先验，我们的方法将价值估计建立在预期的具身动态之上，超越了静态快照，从而将价值与前瞻性内在耦合。通过集成到 RECAP 中，ViVa 在现实世界的纸箱组装任务上取得了显著改进。对所有三项任务的定性分析证实，ViVa 产生了更可靠的价值信号，能够准确反映任务进度。通过利用视频语料库中的时空先验，ViVa 还能泛化到新物体，凸显了视频生成模型在价值估计方面的潜力。

## Abstract
Vision-language-action (VLA) models have advanced robot manipulation through large-scale pretraining, but real-world deployment remains challenging due to partial observability and delayed feedback. Reinforcement learning addresses this via value functions, which assess task progress and guide policy improvement. However, existing value models built on vision-language models (VLMs) struggle to capture temporal dynamics, undermining reliable value estimation in long-horizon tasks. In this paper, we propose ViVa, a video-generative value model that repurposes a pretrained video generator for value estimation. Taking the current observation and robot proprioception as input, ViVa jointly predicts future proprioception and a scalar value for the current state. By leveraging the spatiotemporal priors of a pretrained video generator, our approach grounds value estimation in anticipated embodiment dynamics, moving beyond static snapshots to intrinsically couple value with foresight. Integrated into RECAP, ViVa delivers substantial improvements on real-world box assembly. Qualitative analysis across all three tasks confirms that ViVa produces more reliable value signals, accurately reflecting task progress. By leveraging spatiotemporal priors from video corpora, ViVa also generalizes to novel objects, highlighting the promise of video-generative models for value estimation.

### 2. 方法论
*   **核心思想**：将价值估计重新表述为未来预测任务。利用预训练的视频扩散 Transformer（Wan2.2）作为骨干，同时预测未来的机器人状态（本体感受）和当前的标量价值。
*   **关键技术细节**：
    *   **多模态潜在注入（Latent Injection）**：将图像、机器人本体感受（关节角/末端位姿）和标量价值全部映射到潜在空间（Latent Space）。本体感受通过重复填充（Repeat-padding）转换为潜在帧，标量价值通过广播（Broadcast）转换为潜在帧。
    *   **联合预测架构**：输入当前的观测（多视角图像 + 本体感受），模型作为去噪器，在条件引导下联合生成“未来 $K$ 步的本体感受”和“当前状态的标量价值”。
    *   **价值定义**：采用归一化回报（Normalized Return）。成功轨迹的价值在 $[0, 1)$ 之间随进度增长，失败轨迹则通过惩罚项映射到 $[1, 2)$ 之间，从而在进度和成败之间建立清晰的判别边界。
*   **算法流程**：基于流匹配（Flow Matching）目标进行训练，通过预测从噪声到目标潜在帧的向量场来学习。

### 3. 实验设计
*   **实验场景**：三个具有挑战性的真实世界双臂操作任务：

    2.  **纸箱组装（Box Packaging）**：长程、多阶段操作。
    3.  **纸巾整理（Toilet Paper Organization）**：涉及撕扯、卷回和贴标签等精细动作。
*   **Benchmark 与对比方法**：

*   **泛化性测试**：在未见过的物体（如折叠裤子）上测试模型的零样本泛化能力。

*   **推理效率**：ViVa 的推理延迟为 **0.18s/帧**，能够满足实时或近实时的强化学习闭环需求。

### 5. 实验数量与充分性
*   **实验规模**：涵盖了 3 个真实任务的性能评估、1 个跨类别的泛化性实验，以及针对视频骨干作用、本体感受预测必要性、预测步长 $K$ 的多组消融实验。
*   **充分性评价**：实验设计较为充分。通过定性曲线分析（展示价值随时间的变化）直观证明了 ViVa 相比 VLM 在捕捉任务里程碑和检测错误方面的优越性。真实机器人上的成功率对比（从 58% 提升到 73%）提供了客观的量化支持。

### 6. 主要结论与发现
*   **时空先验至关重要**：视频生成模型由于在海量视频上预训练，比静态 VLM 更能理解物理世界的演变，从而提供更平滑、更具前瞻性的价值信号。
*   **具身耦合的优势**：联合预测未来本体感受能显著增强模型对细微操作错误（如抓取落空、受力不均）的敏感度。
*   **泛化能力强**：ViVa 能够将从视频中学到的通用物理规律迁移到新物体上，而 VLM 往往会过拟合于训练集的视觉特征。

### 7. 优点与亮点
*   **范式创新**：首次系统性地将视频生成模型作为强化学习的价值函数（Critic），而非仅仅作为世界模型（Simulator）或策略（Policy）。
*   **鲁棒的错误检测**：能够灵敏地捕捉到操作过程中的瞬时失败（如盒子对齐偏差），这是传统模型难以做到的。
*   **效率优化**：通过潜在注入技术，在不改变视频生成器核心架构的前提下实现了多模态输入输出，且训练和推理效率优于部分主流 VLM 方案。

### 8. 不足与局限
*   **实验覆盖范围**：受限于真实机器人实验的高昂成本和 RECAP 框架的长周期，大规模量化实验仅集中在“纸箱组装”任务上，其他任务更多是定性分析。
*   **预测步长敏感性**：实验表明预测步长 $K$ 对性能影响较大，过长或过短都会导致信号不稳定，这需要针对不同任务进行调优。
*   **应用限制**：虽然推理速度较快，但对于极高频（如 >50Hz）的底层控制反馈，扩散模型的采样延迟可能仍是一个瓶颈。
