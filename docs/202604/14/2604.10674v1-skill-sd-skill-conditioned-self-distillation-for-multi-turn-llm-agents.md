## 摘要
强化学习（RL）已广泛用于训练多轮交互任务中的大语言模型（LLM）智能体，但其样本效率受到稀疏奖励和长时程的严重限制。同策略自蒸馏（OPSD）通过提供来自能够访问标准答案的特权教师的密集 Token 级监督来缓解这一问题。然而，这种固定的特权信息无法捕捉智能体任务中多样化的有效策略，且将 OPSD 与 RL 简单结合往往会导致训练崩溃。为了解决这些局限性，我们提出了 Skill-SD，这是一个将智能体自身的轨迹转化为动态的、仅限训练的监督信息的框架。已完成的轨迹被总结为简洁的自然语言技能，描述了成功的行为、错误和工作流。这些技能作为动态特权信息仅对教师进行条件化，而学生始终在普通任务提示下行动，并通过蒸馏学习内化这些指导。为了稳定训练，我们推导了一种重要性加权的逆 KL 损失，以提供梯度正确的 Token 级蒸馏，并动态地将教师与不断进步的学生同步。在智能体基准测试上的实验结果表明，Skill-SD 显著优于标准的 RL 基准，在 AppWorld 和 Sokoban 任务上分别提升了原生 GRPO（+14.0%/+10.9%）和原生 OPD（+42.1%/+40.6%）。项目页面：https://k1xe.github.io/skill-sd/

## Abstract
Reinforcement learning (RL) has been widely used to train LLM agents for multi-turn interactive tasks, but its sample efficiency is severely limited by sparse rewards and long horizons. On-policy self-distillation (OPSD) alleviates this by providing dense token-level supervision from a privileged teacher that has access to ground-truth answers. However, such fixed privileged information cannot capture the diverse valid strategies in agent tasks, and naively combining OPSD with RL often leads to training collapse. To address these limitations, we introduce Skill-SD, a framework that turns the agent's own trajectories into dynamic training-only supervision. Completed trajectories are summarized into compact natural language skills that describe successful behaviors, mistakes, and workflows. These skills serve as dynamic privileged information conditioning only the teacher, while the student always acts under the plain task prompt and learns to internalize the guidance through distillation. To stabilize the training, we derive an importance-weighted reverse-KL loss to provide gradient-correct token-level distillation, and dynamically synchronize the teacher with the improving student. Experimental results on agentic benchmarks demonstrate that Skill-SD substantially outperforms the standard RL baseline, improving both vanilla GRPO (+14.0%/+10.9% on AppWorld/Sokoban) and vanilla OPD (+42.1%/+40.6%). ### 2. 方法论：Skill-SD 框架
*   **核心思想**：将智能体过去的成功与失败轨迹总结为自然语言“技能”（Skills），作为仅在训练阶段提供给“教师模型”的特权信息。学生模型在没有技能提示的情况下模仿教师，从而内化这些策略。
*   **关键技术细节**：
    *   **技能生成与检索**：使用辅助 LLM 将轨迹总结为包含“成功分析”、“错误分析”和“黄金工作流”的 JSON 格式技能。通过 UCB（置信区间上界）算法从技能库中检索最有效的技能。
    *   **重要性加权逆 KL 损失（SDL Loss）**：针对教师和学生使用不同 Prompt（跨 Prompt 设定）导致的分布偏移，推导了带有重要性采样权重 $\rho$ 的逆 KL 散度损失函数，确保 Token 级的梯度更新是无偏且正确的。
    *   **动态教师同步**：教师模型不再固定，而是定期从最新的学生模型参数中同步，确保指导信号随模型能力的提升而共同进化。
    *   **联合优化**：总损失函数由 GRPO（组相对策略优化）损失和 SDL（自蒸馏）损失加权组成。

### 6. 主要结论与发现
*   **性能飞跃**：Skill-SD 在 AppWorld 上比原生 GRPO 准确率提升了 **14.0%**，在 Sokoban 上提升了 **10.9%**。
*   **技能的角色**：技能应该引导“教师”而非直接喂给“学生”。直接给学生喂技能会导致严重的过拟合和推理依赖。
*   **稳定性关键**：**同策略（On-policy）采样**对稳定训练至关重要。实验显示，使用教师进行异策略（Off-policy）采样会导致训练在中期崩溃，尤其是在不可逆任务（Sokoban）中。
*   **动态同步必要性**：动态更新教师参数比固定教师能获得更高的性能上限。

### 7. 优点与亮点
*   **动态特权信息**：巧妙地将自然语言总结作为动态特权信息，解决了智能体任务缺乏唯一标准答案的问题。
*   **数学严谨性**：针对跨 Prompt 蒸馏推导了重要性加权的梯度修正公式，解决了自蒸馏中的梯度偏差问题。
*   **推理无依赖**：训练完成后，学生模型不需要任何外部技能库或辅助模型即可独立运行，保持了轻量化。

### 8. 不足与局限
*   **技能总结成本**：虽然采用了异步生成，但依赖外部更强的 LLM 进行轨迹总结会产生额外的 API 开销或计算成本。
*   **检索机制简单**：目前使用 UCB 进行技能检索，对于极大规模的任务池，可能需要更复杂的语义检索（Embedding-based）机制。
*   **任务覆盖**：虽然在两个典型任务上表现优异，但在更广泛的真实世界开放域任务（如 Web 导航）上的泛化性仍有待进一步验证。
