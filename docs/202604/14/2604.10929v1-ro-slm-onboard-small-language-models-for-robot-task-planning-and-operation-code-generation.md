## 摘要
大语言模型（LLMs）的最新进展赋予了机器人理解人类指令的上下文推理能力。然而，目前支持 LLM 的机器人通常依赖于云端模型或高性能计算基础设施，这限制了它们在网络环境不稳定或计算资源受限的机器人（如无人机和小型地面车辆）上的部署。因此，部署支持机载运行的微调小语言模型（SLMs）提供了一个极具前景的替代方案。本文提出了 Ro-SLM，这是一个通过蒸馏 LLMs 的知识与推理来实现可靠的 SLM 驱动机器人操作的框架。Ro-SLM 从数据集合成入手，利用 LLMs 生成多样化的任务指令，在极少人工干预的情况下产出相应的基准代码，并将指令增强至现实应用场景。随后，Ro-SLM 使用该数据集进行微调，并由 LLM 担任奖励函数以指导训练。在无人机操作任务上的广泛实验表明，Ro-SLM 将 SLM 的性能从无法支持机器人任务规划和代码生成，提升到了接近 LLM 的水平。

## Abstract
Recent advances in large language models (LLMs) provide robots with contextual reasoning abilities to comprehend human instructions. Yet, current LLM-enabled robots typically depend on cloud-based models or high-performance computing infrastructure, which limit their deployment on robots under unreliable internet environments or with constrained computational resources, such as UAVs and small ground vehicles. Thus, deploying fine-tuned small language models (SLMs) that support onboard deployment offers a promising alternative. This paper introduces Ro-SLM, a framework that enables reliable SLM-driven robot operation by distilling LLMs' knowledge and reasoning. Ro-SLM starts from dataset synthesis by leveraging LLMs to generate diverse task instructions, produce corresponding ground truth code with minimal human assistance, and augment instructions into real-world application scenarios. Ro-SLM is then fine-tuned with the dataset, in which LLM serves as a reward function to guide the training. Extensive experiments on UAV operation tasks demonstrate that Ro-SLM improves the performance of SLM from being incapable of supporting robotic task planning and code generation to achieving performance that approaches LLM.

*   **研究动机**：
    *   **LLM 的局限性**：大语言模型（如 GPT-4）虽然推理能力强，但参数量巨大，难以在嵌入式设备上本地运行，且依赖持续的互联网连接。
    *   **SLM 的不足**：小语言模型（SLM）虽可机载部署，但由于参数规模限制，其逻辑推理、任务拆解和代码生成的准确性较差，难以直接用于复杂的机器人指令处理。
    *   **目标**：通过知识蒸馏和针对性微调，将 LLM 的推理能力迁移到 SLM 中，使其在本地部署时具备接近 LLM 的表现。

### 2. 方法论：Ro-SLM 框架
Ro-SLM 采用两阶段流程：**数据集合成**与**模型微调优化**。

*   **阶段一：数据集合成（Dataset Synthesis）**
    1.  **指令集生成**：利用 LLM（如 GPT-5.1）根据预设的机器人操作策略和演示，自动生成不同复杂度的任务指令（从简单空间移动到复杂多步规划）。
    2.  **基准代码生成**：使用具备纠错能力的 LLM 框架生成对应的机器人操作代码。对于极高难度的任务，引入少量人工干预以确保代码作为“基准真相（Ground Truth）”的绝对准确。
    3.  **场景增强**：利用 LLM 的世界知识，将简洁的指令（如“向上飞5米”）改写为更符合人类自然语言习惯的现实应用场景描述（如“检查仓库通风口，请上升5米”）。
    4.  **数据预处理**：移除代码中的所有注释，防止 SLM 过度拟合语言模式而非逻辑结构。

*   **阶段二：SLM 微调与优化（Fine-tuning & Optimization）**
    1.  **监督微调（SFT）**：使用合成的数据集对基础 SLM（如 Llama-3.1-8B）进行微调，并采用 **LoRA** 技术提高训练效率。
    2.  **基于 LLM 反馈的强化学习（GRPO）**：引入**组相对策略优化（GRPO）**算法。在此过程中，LLM 充当“奖励函数”，通过比较 SLM 生成的代码与基准代码在机器人行为逻辑上是否等效（而非简单的文本相似度）来提供奖励信号，进一步优化模型。

### 6. 主要结论与发现
*   **性能飞跃**：原始 SLM 几乎无法完成机器人规划任务，而 Ro-SLM 使其在简单任务上达到 **97.7%** 的成功率，在复杂任务上达到 **70%**，表现接近 LLM。

*   **鲁棒性**：通过数据增强，SLM 对人类自然语言的理解能力显著增强，能够处理非结构化的模糊指令。

### 7. 优点（亮点）
*   **闭环蒸馏**：不仅利用 LLM 生成数据，还利用 LLM 作为奖励函数进行强化学习，实现了从知识到逻辑的深度迁移。
*   **机载可行性**：为资源受限的机器人提供了一种无需联网、低延迟的智能决策方案。
*   **数据质量控制**：通过“纠错生成+人工校验”确保了微调数据的极高准确性。

### 8. 不足与局限
*   **显存瓶颈**：虽然是“小”模型，但 8B 参数仍需 16GB 显存，对于极小型的边缘设备（如显存小于 8GB 的微型控制器）依然过大。
*   **人工依赖**：复杂任务的基准数据生成仍需领域专家参与校验，限制了其向全新领域快速迁移的自动化程度。
*   **单次推理限制**：Ro-SLM 采用单次生成模式，缺乏 LLM 方案中常见的“多轮迭代纠错”机制，在处理极其复杂的逻辑错误时容错率较低。
*   **环境泛化**：实验主要在仿真环境中完成，真实物理世界中的传感器噪声和动态障碍物可能对代码执行效果产生额外影响。
