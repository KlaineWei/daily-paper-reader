## 摘要
强化学习（RL）已被广泛用于训练大语言模型（LLM）智能体以执行多轮交互任务，但其样本效率受到稀疏奖励和长时程（long horizons）的严重限制。同策略自蒸馏（OPSD）通过提供来自拥有地面真值（ground-truth）答案的特权教师的密集词元级（token-level）监督来缓解这一问题。然而，这种固定的特权信息无法捕捉智能体任务中多样化的有效策略，且将 OPSD 与 RL 简单结合往往会导致训练崩溃。为了解决这些局限性，我们提出了 Skill-SD，这是一个将智能体自身的轨迹转化为动态的、仅限训练的监督信息的框架。完成的轨迹被总结为简洁的自然语言技能，描述了成功的行为、错误和工作流。这些技能作为动态特权信息仅对教师进行条件化，而学生始终在普通任务提示下行动，并通过蒸馏学习内化这些指导。为了稳定训练，我们推导了一种重要性加权的反向 KL 损失，以提供梯度正确的词元级蒸馏，并动态地将教师与不断进步的学生同步。在智能体基准测试上的实验结果表明，Skill-SD 显著优于标准的 RL 基线，在 AppWorld 和 Sokoban 任务上分别提升了原生 GRPO（+14.0%/+10.9%）和原生 OPD（+42.1%/+40.6%）。项目主页：https://k1xe.github.io/skill-sd/

## Abstract
Reinforcement learning (RL) has been widely used to train LLM agents for multi-turn interactive tasks, but its sample efficiency is severely limited by sparse rewards and long horizons. On-policy self-distillation (OPSD) alleviates this by providing dense token-level supervision from a privileged teacher that has access to ground-truth answers. However, such fixed privileged information cannot capture the diverse valid strategies in agent tasks, and naively combining OPSD with RL often leads to training collapse. To address these limitations, we introduce Skill-SD, a framework that turns the agent's own trajectories into dynamic training-only supervision. Completed trajectories are summarized into compact natural language skills that describe successful behaviors, mistakes, and workflows. These skills serve as dynamic privileged information conditioning only the teacher, while the student always acts under the plain task prompt and learns to internalize the guidance through distillation. To stabilize the training, we derive an importance-weighted reverse-KL loss to provide gradient-correct token-level distillation, and dynamically synchronize the teacher with the improving student. Experimental results on agentic benchmarks demonstrate that Skill-SD substantially outperforms the standard RL baseline, improving both vanilla GRPO (+14.0%/+10.9% on AppWorld/Sokoban) and vanilla OPD (+42.1%/+40.6%). *   **核心问题**：在多轮交互任务中，强化学习（RL）面临**奖励稀疏**和**时程过长**的问题。现有的自蒸馏方法（如 OPSD）通常依赖固定的“地面真值”作为特权信息，这在策略多样化的智能体任务（如 API 调用或推箱子）中表现不佳。此外，将自蒸馏与 RL 结合时，容易因教师与学生分布不匹配而导致**训练崩溃**。
*   **研究背景**：智能体任务不像数学题有唯一答案，它需要灵活的策略。作者试图寻找一种动态的、能捕捉成功与失败经验的信号，来引导模型自我进化。

### 2. 方法论：核心思想与关键技术
*   **核心思想**：将智能体自身的历史轨迹总结为自然语言形式的“技能”（包含成功分析、错误分析和黄金工作流），这些技能仅在训练时作为**特权信息**提供给教师模型，学生模型则在无技能的普通提示下学习，通过蒸馏将教师的知识内化。
*   **关键技术细节**：
    *   **技能生成与检索**：使用辅助 LLM 将轨迹总结为 JSON 格式的技能，并存储在基于 **UCB（置信区间上界）** 算法索引的缓冲区中，以平衡技能的探索与利用。
    *   **重要性加权逆 KL 损失（SDL Loss）**：为了解决教师（有技能提示）和学生（无技能提示）分布不一致导致的梯度偏差，推导了带有重要性采样权重 $\rho$ 的逆 KL 散度公式，确保词元级（token-level）更新的无偏性。
    *   **动态教师同步**：教师模型不再是固定的，而是定期从最新的学生模型中同步参数，使特权信号随模型能力的提升而共同演进。
    *   **异步架构**：技能总结由后台异步完成，不阻塞主训练循环，保证了训练效率。

### 3. 实验设计
*   **数据集/场景**：

*   **客观性**：通过对比“技能增强型 GRPO”证明了技能应引导教师而非直接喂给学生，这一发现具有较强的说服力。

### 6. 主要结论与发现
*   **性能飞跃**：Skill-SD 在 AppWorld 上比原生 GRPO 准确率提升了 **14.0%**，在 Sokoban 上提升了 **10.9%**。
*   **稳定性关键**：**同策略（学生采样）**对稳定训练至关重要。异策略（教师采样）虽然早期起步快，但在中后期会发生严重的训练崩溃。
*   **技能内化**：直接给学生喂技能会导致严重的过拟合（训练集高分，验证集崩溃），而通过蒸馏让学生内化技能则是更稳健的方案。
*   **动态同步必要性**：动态更新教师参数比固定教师能获得更高的性能上限。

### 7. 优点
*   **创新的特权信息设计**：将“技能”作为动态特权信息，解决了智能体任务缺乏固定标准答案的难题。
*   **数学严谨性**：针对跨提示词（Cross-prompt）场景推导了重要性加权的损失函数，解决了梯度偏差问题。
*   **高效性**：异步技能生成机制使得额外开销极小，适合大规模训练。

### 8. 不足与局限
*   **依赖外部模型**：技能的总结依赖于一个性能较强的辅助 LLM，这增加了系统复杂度和对外部 API 的依赖。
*   **检索机制简单**：目前使用 UCB 进行任务内检索，当任务池极大或需要跨任务迁移技能时，可能需要更复杂的语义检索（Embedding-based）。
*   **理论扩展**：目前的梯度分析主要在词元级别，对于长轨迹级别的 KL 边界理论分析仍有待深入。
