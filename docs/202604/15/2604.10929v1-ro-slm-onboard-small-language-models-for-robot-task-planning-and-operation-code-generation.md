## 摘要
大语言模型（LLMs）的最新进展为机器人提供了理解人类指令的上下文推理能力。然而，目前支持 LLM 的机器人通常依赖于云端模型或高性能计算基础设施，这限制了它们在互联网环境不稳定或计算资源受限的机器人（如无人机和小型地面车辆）上的部署。因此，部署支持机载运行的微调小语言模型（SLMs）提供了一个极具前景的替代方案。本文介绍了 Ro-SLM，这是一个通过蒸馏 LLMs 的知识和推理能力来实现可靠的 SLM 驱动机器人操作的框架。Ro-SLM 从数据集合成开始，利用 LLMs 生成多样化的任务指令，在极少人工辅助的情况下生成相应的基准代码，并将指令增强到现实世界的应用场景中。随后，Ro-SLM 使用该数据集进行微调，其中 LLM 作为奖励函数来指导训练。在无人机操作任务上的广泛实验表明，Ro-SLM 将 SLM 的性能从无法支持机器人任务规划和代码生成，提升到了接近 LLM 的水平。

## Abstract
Recent advances in large language models (LLMs) provide robots with contextual reasoning abilities to comprehend human instructions. Yet, current LLM-enabled robots typically depend on cloud-based models or high-performance computing infrastructure, which limit their deployment on robots under unreliable internet environments or with constrained computational resources, such as UAVs and small ground vehicles. Thus, deploying fine-tuned small language models (SLMs) that support onboard deployment offers a promising alternative. This paper introduces Ro-SLM, a framework that enables reliable SLM-driven robot operation by distilling LLMs' knowledge and reasoning. Ro-SLM starts from dataset synthesis by leveraging LLMs to generate diverse task instructions, produce corresponding ground truth code with minimal human assistance, and augment instructions into real-world application scenarios. Ro-SLM is then fine-tuned with the dataset, in which LLM serves as a reward function to guide the training. Extensive experiments on UAV operation tasks demonstrate that Ro-SLM improves the performance of SLM from being incapable of supporting robotic task planning and code generation to achieving performance that approaches LLM.

*   **研究动机**：
    *   **LLM 的局限性**：虽然 GPT-4 等大模型推理能力强，但参数量巨大，本地部署成本高，且依赖云端服务，不适合实时性要求高或偏远地区的机器人任务。
    *   **SLM 的短板**：小语言模型（SLM）虽可机载部署，但由于参数规模限制，其逻辑推理、指令遵循和代码生成能力较弱，难以直接用于复杂的机器人操作。
    *   **目标**：通过知识蒸馏和针对性微调，将 LLM 的推理能力迁移到 SLM 中，使其在本地即可完成可靠的机器人任务规划。

### 2. 方法论
Ro-SLM 框架分为两个主要阶段：**数据集合成**与**模型微调优化**。

*   **阶段一：数据集合成（Dataset Synthesis）**
    1.  **任务指令生成**：利用 LLM 代理根据机器人操作策略和演示，自动生成不同复杂度的任务指令（从简单空间移动到复杂多步规划）。
    2.  **基准代码生成**：采用纠错式代码生成框架，将指令映射为机器人 API 代码。对于极高难度的任务，引入少量人工辅助以确保 Ground Truth 的绝对准确。
    3.  **场景增强（Augmentation）**：利用 LLM 的世界知识，将简洁的指令（如“向上飞5米”）改写为更符合人类自然语言的现实场景描述（如“检查仓库通风口”），提高模型的泛化性。
    4.  **数据预处理**：移除代码中的所有注释，防止 SLM 过度拟合语法模式而非逻辑结构。

*   **阶段二：SLM 微调与优化（Fine-tune & Optimization）**
    1.  **监督微调（SFT）**：使用 LoRA 技术在合成数据集上对 SLM（如 Llama-3.1-8B）进行初步训练。
    2.  **基于 LLM 反馈的强化学习（GRPO）**：引入组相对策略优化（GRPO），并配置一个 LLM 作为**奖励函数**。该奖励函数不比较文本相似度，而是解释代码背后的机器人行为意图，判断其是否与基准行为一致，从而优化 SLM 的步骤级推理能力。

### 6. 主要结论与发现
*   **性能飞跃**：Ro-SLM 使 8B 规模的 SLM 从几乎无法完成任务提升到了接近 LLM（o4-mini）的水平。

*   **鲁棒性增强**：通过数据增强，SLM 能够更好地理解非结构化、拟人化的人类指令。
*   **泛化能力**：模型不仅学会了 API 调用，还掌握了机器人任务规划的逻辑，能够迁移到不同类型的机器人平台。

### 7. 优点
*   **机载友好**：解决了机器人对云端大模型的依赖问题，实现了真正的本地化智能。
*   **行为级奖励机制**：利用 LLM 作为奖励函数来判断代码逻辑而非文本匹配，这在机器人代码生成领域非常有效。
*   **高质量数据管线**：结合了自动生成与少量人工校验，平衡了数据规模与数据质量。

### 8. 不足与局限
*   **内存门槛**：虽然是 SLM，但 8B 模型仍需约 16GB 显存，对于极小型的嵌入式设备（如 1B/3B 级别需求）仍有压力。

*   **安全风险**：论文提到生成的代码直接控制物理实体，若发生推理错误可能导致碰撞或损坏，需额外的安全防护机制。
