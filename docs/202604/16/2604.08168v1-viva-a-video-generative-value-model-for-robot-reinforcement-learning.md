## 摘要
视觉-语言-动作（VLA）模型通过大规模预训练推动了机器人操控的发展，但由于部分可观测性和延迟反馈，其在现实世界中的部署仍面临挑战。强化学习通过价值函数来解决这一问题，价值函数用于评估任务进度并指导策略改进。然而，现有的基于视觉语言模型（VLM）构建的价值模型难以捕捉时间动态，从而削弱了在长程任务中进行可靠价值估计的能力。在本文中，我们提出了 ViVa，这是一种视频生成价值模型，它将预训练的视频生成器重新用于价值估计。ViVa 以当前观测和机器人本体感知作为输入，联合预测未来的本体感知以及当前状态的标量价值。通过利用预训练视频生成器的时空先验，我们的方法将价值估计建立在预期的具身动态之上，超越了静态快照，将价值与前瞻性内在耦合。将 ViVa 集成到 RECAP 中后，在现实世界的纸箱组装任务上取得了显著改进。对所有三项任务的定性分析证实，ViVa 产生了更可靠的价值信号，能够准确反映任务进度。通过利用视频语料库中的时空先验，ViVa 还能泛化到新物体，凸显了视频生成模型在价值估计方面的潜力。

## Abstract
Vision-language-action (VLA) models have advanced robot manipulation through large-scale pretraining, but real-world deployment remains challenging due to partial observability and delayed feedback. Reinforcement learning addresses this via value functions, which assess task progress and guide policy improvement. However, existing value models built on vision-language models (VLMs) struggle to capture temporal dynamics, undermining reliable value estimation in long-horizon tasks. In this paper, we propose ViVa, a video-generative value model that repurposes a pretrained video generator for value estimation. Taking the current observation and robot proprioception as input, ViVa jointly predicts future proprioception and a scalar value for the current state. By leveraging the spatiotemporal priors of a pretrained video generator, our approach grounds value estimation in anticipated embodiment dynamics, moving beyond static snapshots to intrinsically couple value with foresight. Integrated into RECAP, ViVa delivers substantial improvements on real-world box assembly. Qualitative analysis across all three tasks confirms that ViVa produces more reliable value signals, accurately reflecting task progress. By leveraging spatiotemporal priors from video corpora, ViVa also generalizes to novel objects, highlighting the promise of video-generative models for value estimation.

*   **整体含义**：本文提出将价值估计重新定义为“未来预测”问题，利用预训练视频生成器的时空先验知识来增强机器人对任务进度的感知。

### 2. 方法论
*   **核心思想**：将预训练的视频生成器（如 Wan2.2）改造为价值模型。通过联合预测“未来状态”和“当前价值”，使模型在评估当前状态时必须考虑未来的物理演变。
*   **关键技术细节**：
    *   **潜空间注入（Latent Injection）**：将机器人本体感受（关节角度/末端位姿）和标量价值（0-1之间的进度值）通过重复填充或广播的方式，映射为与视频潜空间（VAE Latent）形状一致的帧。
    *   **联合预测架构**：输入包括当前多视角图像和当前本体感受。模型作为扩散 Transformer（DiT），以这些输入为条件，去噪生成两个目标帧：一个是 $K$ 步后的未来本体感受，另一个是代表当前状态价值的标量帧。
    *   **奖励与价值定义**：采用一种区分成功与失败的奖励函数。成功轨迹的累积回报在 $[0, 1)$ 之间，失败轨迹则通过终端惩罚被推移至 $[1, 2)$ 之间，从而在价值空间中为成功和失败建立明确的边界。
    *   **训练目标**：使用流匹配（Flow Matching）目标函数，同时优化未来本体感受预测和价值预测的损失。

    2.  **纸箱组装**：长程任务，包含抓取、放置、折叠盖板和密封。
    3.  **卫生纸整理**：涉及撕纸、倒卷和贴标签等精细动作。

*   **实验规模**：涵盖了三个真实任务的性能评估、针对未见物体（如折叠裤子）的泛化性测试，以及多组消融实验。
*   **消融实验**：分别验证了视频生成骨干网的作用、未来本体感受预测的必要性，以及预测步长 $K$（取值 25, 50, 75）对稳定性的影响。
*   **充分性评价**：实验设计较为全面，不仅有定量的成功率对比，还有深入的定性分析（可视化价值曲线），能够客观证明视频先验在捕捉物理错误（如抓取失败、对齐不准）方面的优越性。

### 6. 主要结论与发现
*   **性能提升**：在最复杂的纸箱组装任务中，ViVa 将成功率从基准 VLA 的 53% 提升至 **73%**，吞吐量也显著增加。
*   **可靠性**：相比 VLM 价值模型容易出现的“单调上升”（过拟合成功轨迹）或“剧烈波动”，ViVa 的价值信号能准确反映任务里程碑，并在发生细微物理错误时产生明显的数值下降。
*   **泛化能力**：由于继承了视频大模型的通用时空常识，ViVa 在面对训练集之外的新物体（如裤子）时，依然能产生平滑且准确的进度评估。

### 7. 优点
*   **范式创新**：将价值函数从简单的图像分类器提升为具备“前瞻性”的生成式模型。
*   **具身耦合**：通过联合预测本体感受，强制模型学习机器人自身的运动学动态，而不仅仅是环境的视觉变化。
*   **高效性**：利用潜空间注入技术，在不改变预训练视频模型核心架构的前提下实现了多模态对齐，且训练/推理效率优于部分 VLM 方案。

### 8. 不足与局限
*   **实验覆盖**：主要集中在真实世界任务，缺乏在更大规模仿真环境（如 Sim-to-Real）中的验证。
*   **框架依赖**：目前主要作为 RECAP 框架的一个组件，其在其他强化学习算法（如 PPO 或离线 RL）中的通用性有待进一步探索。
*   **预测步长敏感性**：实验表明预测步长 $K$ 对结果影响较大，如何自动选择最优的预测视野仍是一个挑战。
