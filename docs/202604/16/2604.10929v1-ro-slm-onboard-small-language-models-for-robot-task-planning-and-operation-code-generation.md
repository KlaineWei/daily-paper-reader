## 摘要
大语言模型（LLMs）的最新进展为机器人提供了理解人类指令的上下文推理能力。然而，目前支持 LLM 的机器人通常依赖于云端模型或高性能计算基础设施，这限制了它们在网络环境不可靠或计算资源受限的机器人（如无人机和小型地面车辆）上的部署。因此，部署支持机载运行的微调小语言模型（SLMs）提供了一种极具前景的替代方案。本文介绍了 Ro-SLM，这是一个通过蒸馏 LLMs 的知识和推理能力来实现可靠的 SLM 驱动机器人操作的框架。Ro-SLM 从数据集合成开始，利用 LLMs 生成多样化的任务指令，在极少人工协助的情况下产生相应的标准答案（ground truth）代码，并将指令增强到真实世界的应用场景中。随后，Ro-SLM 使用该数据集进行微调，其中 LLM 作为奖励函数来指导训练。在无人机操作任务上的广泛实验表明，Ro-SLM 将 SLM 的性能从无法支持机器人任务规划和代码生成，提升到了接近 LLM 的水平。

## Abstract
Recent advances in large language models (LLMs) provide robots with contextual reasoning abilities to comprehend human instructions. Yet, current LLM-enabled robots typically depend on cloud-based models or high-performance computing infrastructure, which limit their deployment on robots under unreliable internet environments or with constrained computational resources, such as UAVs and small ground vehicles. Thus, deploying fine-tuned small language models (SLMs) that support onboard deployment offers a promising alternative. This paper introduces Ro-SLM, a framework that enables reliable SLM-driven robot operation by distilling LLMs' knowledge and reasoning. Ro-SLM starts from dataset synthesis by leveraging LLMs to generate diverse task instructions, produce corresponding ground truth code with minimal human assistance, and augment instructions into real-world application scenarios. Ro-SLM is then fine-tuned with the dataset, in which LLM serves as a reward function to guide the training. Extensive experiments on UAV operation tasks demonstrate that Ro-SLM improves the performance of SLM from being incapable of supporting robotic task planning and code generation to achieving performance that approaches LLM.

*   **核心痛点**：在网络不稳定（如山区、灾区）或计算资源受限（如小型无人机、地面车辆）的环境下，云端 LLM 无法使用，而本地部署大型模型又面临功耗和载荷挑战。
*   **研究目标**：开发一种能够机载运行（Onboard）的小语言模型（SLM），使其在保持较小规模的同时，具备接近 LLM 的逻辑推理和代码生成能力。

### 2. 方法论
Ro-SLM 框架分为两个主要阶段：

*   **阶段一：数据集合成（Dataset Synthesis）**
    *   **指令生成**：利用 LLM 代理根据机器人操作策略自动生成多样化的任务指令（从简单到复杂）。
    *   **标准代码生成**：采用纠错式代码生成方法，将指令映射为机器人操作代码。对于高复杂度任务，引入少量人工干预以确保代码的绝对正确性。
    *   **场景增强**：利用 LLM 的常识知识，将简洁的指令重写为更符合人类表达习惯的真实应用场景描述。
    *   **数据预处理**：移除代码中的所有注释，防止 SLM 过度拟合语言模式而非逻辑结构。
*   **阶段二：SLM 微调与优化**
    *   **监督微调（SFT）**：使用 LoRA 技术在合成数据集上对 SLM（如 Llama-3.1-8B）进行初步对齐。
    *   **基于 LLM 反馈的优化**：引入 **GRPO（组相对策略优化）** 算法。LLM 在此充当奖励函数，它不直接对比文本相似度，而是解释代码隐含的机器人行为，判断其是否与标准答案在逻辑上等效。

### 6. 主要结论与发现
*   **性能飞跃**：原始 SLM 几乎无法完成任务，而 Ro-SLM 使其在简单任务上达到了 **97.7%** 的成功率，在复杂任务上达到了 **70%**，接近 LLM 水平。
*   **超越 LLM 的潜力**：在“极高难度”任务中，Ro-SLM 的成功率甚至超过了 o4-mini，这归功于训练数据中包含的高质量人工校准代码。
*   **关键因素**：移除代码注释和进行真实场景的数据增强对提升 SLM 的鲁棒性至关重要。

### 7. 优点
*   **机载可行性**：解决了机器人对云端 API 的依赖，提升了在极端环境下的自主性。
*   **行为级奖励**：GRPO 结合 LLM 行为解释的奖励机制，比传统的文本重叠度（如 BLEU）更适合代码生成任务。
*   **高效蒸馏**：通过少量高质量数据（约 600 条）即可显著提升小模型的逻辑推理能力。

### 8. 不足与局限
*   **内存需求**：尽管是“小”模型，8B 参数仍需约 16GB 显存，对于极小型的嵌入式设备（如 1B/3B 级别需求）仍有压力。
*   **人工依赖**：复杂任务的标准答案生成仍需领域专家参与校对，限制了数据集的大规模自动化扩展。
*   **单次推理限制**：Ro-SLM 采用单次生成模式，缺乏 LLM 方案中常见的“多次迭代纠错”机制，在处理极长程任务时容错率较低。
*   **环境泛化**：实验主要在模拟器中完成，真实物理世界中的传感器噪声和动态障碍物可能对代码执行效果产生影响。
