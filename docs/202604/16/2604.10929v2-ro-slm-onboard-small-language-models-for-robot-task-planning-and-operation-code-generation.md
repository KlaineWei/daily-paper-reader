## 摘要
大语言模型（LLMs）的最新进展为机器人提供了理解人类指令的上下文推理能力。然而，目前支持 LLM 的机器人通常依赖云端模型或高性能计算基础设施，这限制了它们在网络环境不可靠或计算资源受限的机器人（如无人机和小型地面车辆）上的部署。因此，部署支持机载运行的微调小语言模型（SLMs）提供了一个极具前景的替代方案。本文介绍了 Ro-SLM，这是一个通过蒸馏 LLMs 的知识和推理能力来实现可靠的 SLM 驱动机器人操作的框架。Ro-SLM 从数据集合成开始，利用 LLMs 生成多样化的任务指令，在极少人工辅助的情况下生成相应的基准代码，并将指令增强到真实世界的应用场景中。随后，Ro-SLM 使用该数据集进行微调，其中 LLM 作为奖励函数来指导训练。在无人机操作任务上的广泛实验表明，Ro-SLM 将 SLM 的性能从无法支持机器人任务规划和代码生成，提升到了接近 LLM 的水平。

## Abstract
Recent advances in large language models (LLMs) provide robots with contextual reasoning abilities to comprehend human instructions. Yet, current LLM-enabled robots typically depend on cloud-based models or high-performance computing infrastructure, which limit their deployment on robots under unreliable internet environments or with constrained computational resources, such as UAVs and small ground vehicles. Thus, deploying fine-tuned small language models (SLMs) that support onboard deployment offers a promising alternative. This paper introduces Ro-SLM, a framework that enables reliable SLM-driven robot operation by distilling LLMs' knowledge and reasoning. Ro-SLM starts from dataset synthesis by leveraging LLMs to generate diverse task instructions, produce corresponding ground truth code with minimal human assistance, and augment instructions into real-world application scenarios. Ro-SLM is then fine-tuned with the dataset, in which LLM serves as a reward function to guide the training. Extensive experiments on UAV operation tasks demonstrate that Ro-SLM improves the performance of SLM from being incapable of supporting robotic task planning and code generation to achieving performance that approaches LLM.

*   **核心问题**：如何在计算资源受限（如无人机、小型地面车辆）且网络环境不可靠（无法连接云端）的机器人平台上，实现可靠的任务规划与操作代码生成。
*   **研究背景**：虽然 GPT-4 等大语言模型（LLM）在机器人推理方面表现卓越，但其巨大的参数量和对云端 API 的依赖限制了机载部署。现有的小语言模型（SLM）虽然可以本地运行，但推理能力较弱，难以准确理解复杂指令并生成可执行代码。

### 2. 方法论：Ro-SLM 框架
Ro-SLM 的核心思想是通过**知识蒸馏**将 LLM 的推理能力迁移到 SLM 中，主要分为两个阶段：

*   **阶段一：数据集合成（Dataset Synthesis）**
    1.  **任务指令生成**：利用 LLM 代理根据预设的机器人操作策略和演示，自动生成不同复杂度的任务指令。
    2.  **基准代码生成**：采用“纠错式代码生成”框架，由 LLM 生成对应的机器人操作代码。对于极高复杂度的任务，引入少量人工辅助以确保 Ground Truth 的绝对准确。
    3.  **场景增强**：利用 LLM 的世界知识，将简洁的指令（如“向上飞5米”）改写为更符合人类习惯的真实应用场景描述（如“检查仓库墙壁的垂直状况”），并去除代码注释以防止模型过拟合于语言模式。
*   **阶段二：SLM 微调与优化**
    1.  **监督微调（SFT）**：使用合成的数据集对 SLM（如 Llama-3.1-8B）进行初步训练，并采用 LoRA 技术提高效率。
    2.  **基于 LLM 反馈的优化（GRPO）**：引入组相对策略优化（GRPO），将 LLM 配置为奖励函数。LLM 不仅对比文本相似度，更重要的是解释代码隐含的机器人行为，判断其是否与基准行为一致，从而引导模型进行步骤级的推理优化。

### 3. 实验设计
*   **实验场景**：主要针对无人机（UAV）操作任务，并在地面车辆（ROSMASTER X3）上验证了泛化性。

### 5. 实验数量与充分性
*   **实验规模**：合成了 598 个指令-代码对，其中 492 对用于训练，106 对用于评估。
*   **充分性**：实验涵盖了从简单到极高难度的四个复杂度等级，并进行了详尽的**消融实验**（验证了注释去除、数据增强、任务多样性和 GRPO 优化的必要性）。

### 6. 主要结论与发现
*   **性能跨越**：原始 SLM 在机器人任务上几乎不可用，而 Ro-SLM 使其在基础任务上达到了 **97.7% 的成功率**，在复杂任务上达到了 **70% 的成功率**。
*   **接近 LLM**：在极高难度的任务中，Ro-SLM 甚至在某些指标上超过了 LLM（o4-mini），这归功于高质量的人工辅助微调数据。
*   **泛化能力**：模型在地面机器人平台上也表现良好，证明其学到的是任务规划逻辑而非简单的 API 记忆。
*   **数据质量至上**：去除代码注释和增加真实场景描述对提升 SLM 的鲁棒性至关重要。

### 7. 优点与亮点
*   **端侧友好**：解决了机器人领域对云端 LLM 的过度依赖，为离线、资源受限环境提供了可行方案。
*   **创新的奖励机制**：不依赖文本相似度，而是利用 LLM 理解代码逻辑并作为 GRPO 的奖励函数，这更符合机器人操作的本质。
*   **高质量数据生成流**：结合了 LLM 的自动化能力与必要的人工校验，平衡了数据规模与准确性。

### 8. 不足与局限
*   **内存占用仍有挑战**：8B 模型虽小，但 16GB 显存对于更小型的嵌入式设备（如更低端的单片机或微型无人机）依然过大。
*   **单次推理限制**：Ro-SLM 采用单次生成模式，缺乏像 Corrective GSCE 那样的多轮迭代纠错机制，在处理极端复杂任务时容错率较低。
*   **人工依赖**：虽然号称“极少人工”，但在处理高难度任务的 Ground Truth 时仍需专家介入，限制了向全新领域快速迁移的自动化程度。
*   **实机验证不足**：实验主要在 AirSim 模拟器中完成，真实物理环境中的传感器噪声、动力学不确定性对模型的影响尚待验证。
