## 摘要
视觉-语言-动作（VLA）模型已成为具身智能的主流。最近的 VLA 模型将其输入模态从仅 2D 扩展到 2D+3D 范式，形成了多视觉模态 VLA（MVLA）模型。尽管实现了空间感知的提升，但由于模态扩展导致输入 Token 数量增加，MVLA 面临着更大的加速需求。Token 剪枝是针对 MVLA 模型量身定制的一种有效优化方法。然而，现有的 Token 剪枝方案多是为仅 2D 的 VLA 模型设计的，忽略了 2D/3D 模态显著性的差异。在本文中，我们遵循 MVLA 模型中多模态数据的应用过程，并开发了一种三阶段分析方法，以捕捉 2D/3D 模态显著性的差异和动态变化。基于此，我们为 MVLA 模型提出了一种相应的三阶段 Token 剪枝框架，以实现最优的 2D/3D Token 选择和高效剪枝。实验表明，我们的框架在精度损失极小的情况下，实现了高达 2.55 倍的推理加速，而额外开销仅为 5.8%。我们的代码即将发布。

## Abstract
Vision-Language-Action (VLA) models have emerged as the mainstream of embodied intelligence. Recent VLA models have expanded their input modalities from 2D-only to 2D+3D paradigms, forming multi-visual-modal VLA (MVLA) models. Despite achieving improved spatial perception, MVLA faces a greater acceleration demand due to the increased number of input tokens caused by modal expansion. Token pruning is an effective optimization methods tailored to MVLA models. However, existing token pruning schemes are designed for 2D-only VLA models, ignoring 2D/3D modality salience differences. In this paper, we follow the application process of multi-modal data in MVLA models and develop a tri-stage analysis to capture the discrepancy and dynamics of 2D/3D modality salience. Based on these, we propose a corresponding tri-stage token pruning framework for MVLA models to achieve optimal 2D/3D token selection and efficient pruning. Experiments show that our framework achieves up to a 2.55x inference speedup with minimal accuracy loss, while only costing 5.8% overhead. Our Code is coming soon.

随着具身智能的发展，视觉-语言-动作（VLA）模型已从单一的 2D 图像输入演进为 **2D+3D（如点云）的多视觉模态（MVLA）** 架构。虽然 3D 信息的引入增强了空间感知，但也带来了 **Token 数量剧增** 的问题，导致推理速度极慢（通常仅 3~5 Hz），无法满足机器人实时控制（20~30 Hz）的需求。
现有的 Token 剪枝技术主要针对单一 2D 模态设计，忽略了 **2D 与 3D 模态之间显著性（Salience）的差异及其在动作执行过程中的动态变化**。本论文旨在通过分析 2D/3D 模态在不同推理阶段的贡献度，提出一种高效的剪枝框架以实现推理加速。

#### 2. 方法论：核心思想与关键技术
论文提出了一个**三阶段 Token 剪枝框架**，对应 MVLA 模型推理的三个关键环节：

*   **第一阶段：数据预处理分析（Data Preprocessing Stage）**
    *   **核心思想**：利用模型最后一层特征的 $L_1$ 范数来量化 2D 和 3D 模态的原始显著性。

*   **第二阶段：语义综合分析（Semantic Synthesis Stage）**
    *   **核心思想**：利用注意力分数（Attention Scores）将视觉 Patch 划分为不同的语义集合（背景、机器人手臂、目标物体）。

*   **第三阶段：动作迭代分析（Action Iteration Stage）**

#### 6. 主要结论与发现
*   **模态显著性差异**：在 MVLA 模型中，2D 模态通常占据主导地位，但 3D 模态在涉及空间交互（如避障、精准对齐）的语义区域具有不可替代的显著性。

*   **动态变化**：模态的显著性并非固定，而是随着机器人动作的执行（时间维度）和所处语义区域（空间维度）动态波动的。

#### 7. 优点
*   **多阶段深度耦合**：将剪枝策略与 VLA 模型的推理生命周期（预处理、推理、迭代）紧密结合。
*   **模态感知能力**：首次深入探讨了 2D 和 3D 模态在具身任务中的“权力分配”，避免了盲目剪枝导致的精度损失。
*   **时间稳定性**：通过 EMA 机制解决了机器人控制中常见的推理抖动问题，提高了系统的鲁棒性。

#### 8. 不足与局限
*   **架构依赖性**：实验主要基于 MLA 模型（LLaMA 架构），对于其他非 Transformer 架构或不同融合方式的 VLA 模型的泛化能力有待进一步验证。

*   **3D 模态形式限制**：目前主要针对点云（Point Cloud）形式的 3D 输入，对于神经辐射场（NeRF）或 3D 高斯泼溅（3DGS）等新型表征的适用性未知。
