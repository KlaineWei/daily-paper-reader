## 摘要
大语言模型 (LLM) 智能体正越来越多地被部署为可扩展的用户模拟器，用于推荐系统的评估。然而，现有的模拟器通常通过文本或结构化元数据来感知推荐内容，而非真实用户所浏览的视觉界面——这是一个关键差距，因为对推荐布局的注意力既是视觉驱动的，又是高度个性化的。通过对在轮播式推荐场景下收集的真实世界眼动追踪数据集进行分析，我们发现用户表现出稳定的个体注视模式，且这些模式对点击行为具有很强的预测性。基于这一发现，我们提出了面向用户仿真的注视对齐微调 (FixATE)。该方法首先通过可解释性算子探测视觉语言模型 (VLM) 的内部视觉注意力，以获得与人类注视具有可比性的槽位级相关性分布，随后学习个性化软提示 (soft prompts)，引导模型的注意力转向每个用户的特征注视模式。在三种基于可解释性的探测算子和两种架构不同的 VLM 主干网络上进行的实验表明，该方法在注意力对齐和点击预测准确率方面均有一致的提升。这些结果表明，让模型“像用户一样看”是开发能够更忠实地再现用户在推荐界面中感知和行动方式的模拟器的可行路径。

## Abstract
Large language model (LLM) agents are increasingly deployed as scalable user simulators for recommender system evaluation. Yet existing simulators perceive recommendations through text or structured metadata rather than the visual interfaces real users browse-a critical gap, since attention over recommendation layouts is both visually driven and highly personalized. We investigate whether aligning a vision-language model's (VLM's) visual attention with user-specific gaze patterns can improve simulation fidelity. Analysis of a real-world eye-tracking dataset collected in a carousel-based recommendation setting reveals that users exhibit stable individual gaze patterns strongly predictive of click behavior. Building on this finding, we propose Fixation-Aligned Tuning for user Emulation (FixATE). Our approach first probes the VLM's internal visual attention via interpretability operators to obtain a slot-level relevance distribution comparable with human fixation, and then learns personalized soft prompts to steer the model's attention toward each user's characteristic fixation pattern. Experiments across three interpretability-based probing operators and two architecturally distinct VLM backbones demonstrate consistent improvements in both attention alignment and click prediction accuracy. These results suggest that making the model "see like the user" is a viable path toward simulators that more faithfully reproduce how users perceive and act in recommendation interfaces.

### 2. 方法论：FixATE 框架
论文提出了 **FixATE (Fixation-Aligned Tuning for user Emulation)**，其核心思想是让模型“像用户一样看，从而像用户一样行动”。

*   **视觉注意力探测（Probing）：** 利用 VLM 的可解释性算子（如 AttnLRP, GLIMPSE, Attention Rollout）提取模型内部的视觉注意力分布。将图像块（Patch）级别的注意力聚合为界面槽位（Slot）级别的相关性向量 $a_{u,t}$。
*   **个性化软提示分解（Personalized Prompt Basis Decomposition）：**
    *   定义一组共享的**提示基（Prompt Basis）** $B$，捕捉通用的视觉关注模式（如中心偏置）。
    *   为每个用户学习一个**个性化系数** $z_u$，通过 Softmax 得到混合权重 $\alpha_u$。
    *   生成用户专属的软提示 $P_u = \sum \alpha_{u,m} B_m$，并将其拼接到 VLM 输入中，引导模型关注特定区域。
*   **对齐目标函数：**
    *   **注意力对齐损失（$L_{Attn}$）：** 使用加权的 KL 散度，将模型的槽位注意力分布与人类真实的注视时长分布进行对齐。
    *   **行为预测损失（$L_{NTP}$）：** 标准的下一 Token 预测损失，确保模型输出正确的点击决策。
    *   **联合优化：** 冻结 VLM 主干参数，仅微调提示基和个性化系数。

### 6. 主要结论与发现
*   **视觉输入优于文本：** 实验证明，直接输入视觉界面比将界面转译为带坐标的文本更能捕捉人类的 F 型阅读模式和位置偏置。
*   **注意力对齐提升行为仿真：** 成功对齐用户注视模式的模型，其点击预测的准确率显著提升（部分配置下 Accuracy 提升达 100%）。
*   **个性化是关键：** 简单的全局注意力对齐效果有限，必须通过个性化系数捕捉不同用户的浏览习惯。
*   **模型无关性：** FixATE 在不同架构的 VLM 上均表现出一致的改进，证明了框架的通用性。

### 7. 优点与亮点
*   **视角新颖：** 首次将“个性化注视对齐”引入推荐系统模拟器，从感知层面（Perception）而非单纯的记忆/逻辑层面改进仿真。
*   **即插即用：** 采用软提示微调（Soft Prompt Tuning），无需修改 VLM 内部架构或进行全参数微调，部署成本低。
*   **跨领域验证：** 从电影推荐扩展到搜索广告界面，验证了方法在不同视觉布局下的鲁棒性。

### 8. 不足与局限
*   **数据稀缺性：** 高质量的个性化眼动数据集（如 RecGaze）规模仍然较小（仅几十名用户），限制了在大规模场景下的验证。

*   **时序建模缺失：** 目前的框架主要针对单次会话，未考虑用户注意力随时间或长期历史演变的动态过程。
*   **先验冲突：** 当 VLM 自身的视觉偏见（如对某些海报内容的固有偏好）过强时，仅靠软提示可能难以完全扭转注意力。
