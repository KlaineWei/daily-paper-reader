## 摘要
强化学习（RL）已被广泛用于训练大语言模型（LLM）智能体以执行多轮交互任务，但其样本效率受到稀疏奖励和长时程（long horizons）的严重限制。同策略自蒸馏（OPSD）通过提供来自拥有地面真值（ground-truth）答案的特权教师的密集词元级（token-level）监督来缓解这一问题。然而，这种固定的特权信息无法捕捉智能体任务中多样化的有效策略，且将 OPSD 与 RL 简单结合往往会导致训练崩溃。为了解决这些局限性，我们提出了 Skill-SD，这是一个将智能体自身的轨迹转化为动态的、仅限训练的监督信息的框架。完成的轨迹被总结为简洁的自然语言技能，描述了成功的行为、错误和工作流。这些技能作为动态特权信息仅对教师进行条件化，而学生始终在普通任务提示下行动，并通过蒸馏学习内化这些指导。为了稳定训练，我们推导了一种重要性加权的反向 KL 损失，以提供梯度正确的词元级蒸馏，并动态地将教师与不断进步的学生同步。在智能体基准测试上的实验结果表明，Skill-SD 显著优于标准的 RL 基线，在 AppWorld 和 Sokoban 任务上分别提升了原生 GRPO（+14.0%/+10.9%）和原生 OPD（+42.1%/+40.6%）。项目主页：https://k1xe.github.io/skill-sd/

## Abstract
Reinforcement learning (RL) has been widely used to train LLM agents for multi-turn interactive tasks, but its sample efficiency is severely limited by sparse rewards and long horizons. On-policy self-distillation (OPSD) alleviates this by providing dense token-level supervision from a privileged teacher that has access to ground-truth answers. However, such fixed privileged information cannot capture the diverse valid strategies in agent tasks, and naively combining OPSD with RL often leads to training collapse. To address these limitations, we introduce Skill-SD, a framework that turns the agent's own trajectories into dynamic training-only supervision. Completed trajectories are summarized into compact natural language skills that describe successful behaviors, mistakes, and workflows. These skills serve as dynamic privileged information conditioning only the teacher, while the student always acts under the plain task prompt and learns to internalize the guidance through distillation. To stabilize the training, we derive an importance-weighted reverse-KL loss to provide gradient-correct token-level distillation, and dynamically synchronize the teacher with the improving student. Experimental results on agentic benchmarks demonstrate that Skill-SD substantially outperforms the standard RL baseline, improving both vanilla GRPO (+14.0%/+10.9% on AppWorld/Sokoban) and vanilla OPD (+42.1%/+40.6%). *   **研究背景**：强化学习（RL）是提升大语言模型（LLM）智能体多轮交互能力的主流方法，但面临**奖励稀疏**（任务完成才给分）和**长路径**（步骤多导致信用分配难）的挑战。
*   **核心问题**：
    1.  **特权信息定义难**：传统的自蒸馏（Self-Distillation）依赖固定答案（如数学题），但智能体任务（如操作 API）通常有多种有效路径，固定参考答案会限制探索。
    2.  **训练不稳定**：将自蒸馏与 RL 结合时，如果教师模型与学生模型的分布漂移过大，容易导致训练崩溃。
*   **研究目标**：提出一种动态的、基于技能引导的自蒸馏框架，让智能体通过内化自身成功与失败的经验来加速学习。

### 2. 方法论：Skill-SD 框架
*   **核心思想**：将智能体过去的轨迹总结为自然语言形式的“技能”（包含成功分析、错误分析、黄金工作流），这些技能仅作为“特权信息”提供给教师模型，学生模型依然在普通提示词下运行，通过蒸馏损失函数学习教师的输出分布。
*   **关键技术细节**：
    *   **技能生成与检索**：使用辅助 LLM 将完成的轨迹总结为结构化 JSON 技能，存入技能库。采用 **UCB（置信上限）算法** 动态检索对当前任务最有效的技能。
    *   **重要性加权反向 KL 损失（SDL Loss）**：由于教师和学生使用不同的 Prompt（跨 Prompt 设定），直接计算 KL 散度会导致梯度偏差。论文推导了带有重要性采样权重（$\rho$）的损失函数，确保在词元（Token）级别提供无偏的梯度更新。
    *   **动态教师同步**：教师模型不再是固定的，而是定期从最新的学生模型中同步参数，确保特权信号随学生能力的提升而共同演进。
    *   **联合优化**：总损失 = GRPO 损失（任务级奖励）+ $\lambda \times$ SDL 损失（词元级引导）。

### 6. 主要结论与发现
*   **性能飞跃**：Skill-SD 在 AppWorld 上准确率达到 64.9%（比 GRPO 提升 14.0%），在 Sokoban 上达到 62.5%（提升 10.9%）。
*   **技能应引导教师而非学生**：直接给学生喂技能（Skill-Augmented）会导致严重的过拟合和推理干扰，性能反而不如普通 GRPO。
*   **稳定性关键**：**同策略采样**和**动态教师同步**是防止训练崩溃的核心。异策略（教师采样）在训练中期会发生灾难性崩溃。
*   **蒸馏的价值**：纯蒸馏（OPD）效果极差，证明了环境奖励（RL）在长程任务中不可或缺，蒸馏仅作为密集的辅助信号。

### 7. 优点与亮点
*   **创新的特权信息**：将“技能”作为动态特权信息，解决了 Agent 任务中缺乏单一标准答案的蒸馏难题。
*   **理论严谨**：针对跨 Prompt 蒸馏推导了重要性加权的梯度修正公式，具有较强的数学支撑。
*   **系统效率**：通过异步总结和 UCB 检索，在不显著增加算力负担的情况下实现了自进化。

### 8. 不足与局限
*   **依赖外部模型**：技能总结依赖于一个更强的辅助 LLM（如 Seed1.8），这在完全闭环的自进化中可能引入外部偏差。
*   **任务池规模**：实验主要在百量级的任务池上进行，在大规模、更通用的 Agent 场景下的泛化能力仍需进一步验证。
*   **检索机制简单**：目前的 UCB 检索是基于任务 ID 的，缺乏基于语义的跨任务技能迁移能力。
