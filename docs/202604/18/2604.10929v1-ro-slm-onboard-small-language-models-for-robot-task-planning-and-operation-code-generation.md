## 摘要
大语言模型（LLM）的最新进展赋予了机器人理解人类指令的上下文推理能力。然而，目前支持 LLM 的机器人通常依赖云端模型或高性能计算基础设施，这限制了它们在网络环境不稳定或计算资源受限的机器人（如无人机和小型地面车辆）上的部署。因此，部署支持机载部署的微调小语言模型（SLM）提供了一个极具前景的替代方案。本文介绍了 Ro-SLM，这是一个通过蒸馏 LLM 的知识和推理能力来实现可靠的 SLM 驱动机器人操作的框架。Ro-SLM 从数据集合成开始，利用 LLM 生成多样化的任务指令，在极少人工辅助的情况下产生相应的基准代码，并将指令增强到现实世界的应用场景中。随后，Ro-SLM 使用该数据集进行微调，其中 LLM 作为奖励函数来指导训练。在无人机操作任务上的广泛实验表明，Ro-SLM 将 SLM 的性能从无法支持机器人任务规划和代码生成，提升到了接近 LLM 的水平。

## Abstract
Recent advances in large language models (LLMs) provide robots with contextual reasoning abilities to comprehend human instructions. Yet, current LLM-enabled robots typically depend on cloud-based models or high-performance computing infrastructure, which limit their deployment on robots under unreliable internet environments or with constrained computational resources, such as UAVs and small ground vehicles. Thus, deploying fine-tuned small language models (SLMs) that support onboard deployment offers a promising alternative. This paper introduces Ro-SLM, a framework that enables reliable SLM-driven robot operation by distilling LLMs' knowledge and reasoning. Ro-SLM starts from dataset synthesis by leveraging LLMs to generate diverse task instructions, produce corresponding ground truth code with minimal human assistance, and augment instructions into real-world application scenarios. Ro-SLM is then fine-tuned with the dataset, in which LLM serves as a reward function to guide the training. Extensive experiments on UAV operation tasks demonstrate that Ro-SLM improves the performance of SLM from being incapable of supporting robotic task planning and code generation to achieving performance that approaches LLM.

### 1. 论文的核心问题与整体含义
**研究动机与背景：**
尽管大语言模型（LLM）在机器人任务规划和代码生成方面表现卓越，但其巨大的参数量导致了严重的部署障碍：
*   **环境限制：** 云端模型依赖稳定的网络连接，无法在偏远地区或灾难现场等断网环境下工作。
*   **硬件限制：** 资源受限的平台（如小型无人机 UAV、地面车辆 UGV）载荷和电池容量有限，难以承载运行数百亿参数模型的计算设备。
*   **SLM 的局限：** 现有的小语言模型（SLM）虽然可以机载部署，但由于参数规模小，其逻辑推理和从提示词中提取任务信息的能力较弱。

**核心问题：** 如何通过知识蒸馏和微调，使 SLM 在保持轻量化的同时，具备接近 LLM 的机器人任务规划与代码生成能力？

### 2. 论文提出的方法论：Ro-SLM 框架
Ro-SLM 采用两阶段流程，核心思想是将 LLM 的推理能力“蒸馏”到 SLM 中：

**第一阶段：数据集合成（Dataset Synthesis）**
1.  **任务指令生成：** 利用 LLM 代理根据预设的机器人操作策略和演示，自动生成不同复杂度的任务指令（从简单空间移动到复杂多步规划）。
2.  **基准代码生成：** 采用纠错式代码生成方法。对于简单任务由 LLM 自动生成；对于高复杂度任务（5步以上操作），引入**极少量人工辅助**进行校验，确保 Ground Truth 的绝对准确。
3.  **场景增强：** 利用 LLM 的世界知识，将简洁的指令（如“向上飞5米”）改写为自然语言描述的现实场景（如“检查仓库通风口”），提高模型的泛化性。
4.  **数据预处理：** 移除代码中的所有注释，防止 SLM 过度拟合语法模式而非逻辑。

**第二阶段：SLM 微调（Fine-tune）**
1.  **监督微调（SFT）：** 使用合成数据集对 SLM（如 Llama-3.1-8B）进行初步训练，并应用 LoRA 技术提高效率。
2.  **基于 LLM 反馈的优化：** 引入 **GRPO（组相对策略优化）** 算法。此时 LLM 充当**奖励函数**，它不比较文本相似度，而是解释代码隐含的机器人行为，判断 SLM 生成的代码在逻辑上是否与基准代码等效。

### 3. 实验设计
*   **实验场景：** 主要基于 AirSim 模拟器中的无人机（UAV）操作任务，后期扩展到了地面车辆（ROSMASTER X3）。
*   **数据集：**
    *   **Basic Dataset：** 44 个直观任务（1-2 个动作）。
    *   **Advanced Dataset：** 20 个长程任务，分为低、中、高、极高四个难度等级。
    *   **Real-world Mapping：** 将上述任务映射为现实应用场景描述的扩展集。
*   **Benchmark 与对比方法：**
    *   **Llama-3.1-8B (Original)：** 未经微调的原始小模型。
    *   **GSCE (o4-mini)：** 基于结构化提示词的 LLM 方案。
    *   **Corrective GSCE (o4-mini)：** 目前最先进的（SOTA）LLM 纠错生成方案。

*   **硬件设备：** 实验在配备了 **2 张 Nvidia A100 GPU** 的服务器上进行。
*   **模型规模：** 选用了 **Llama-3.1-8B** 作为基础 SLM，该模型在推理时约需 16GB 显存，适合部署在 Jetson AGX Orin 等机载计算单元上。

### 6. 主要结论与发现
*   **性能飞跃：** 原始 8B 模型几乎无法完成任务，而 Ro-SLM 使其在基础任务上达到 **97.7% 的成功率**，在复杂任务上达到 **70% 的成功率**。
*   **接近 LLM：** 在极高难度任务下，Ro-SLM 甚至在某些指标上超过了 o4-mini，这归功于高质量的人工辅助基准数据。
*   **增强的必要性：** 数据增强显著提升了模型处理自然语言描述（而非机械指令）的鲁棒性。
*   **去注释的效果：** 移除代码注释能有效减少 SLM 的语法干扰，使其更专注于逻辑生成。

### 7. 优点与亮点
*   **行为级奖励函数：** 创新性地让 LLM 评估代码执行的“意图”而非“文本”，解决了代码生成中“同义异构”的评价难题。
*   **机载可行性：** 填补了高性能机器人推理与低功耗硬件部署之间的鸿沟。
*   **高质量合成数据：** 结合了 LLM 的效率与人工对复杂逻辑的把关，构建了一个高质量的垂直领域数据集。

### 8. 不足与局限
*   **内存门槛：** 尽管是 SLM，8B 模型仍需约 16GB 显存，对于更小型的嵌入式设备（如仅有 4GB/8GB 内存的设备）依然偏大。
*   **人工依赖：** 复杂任务的 Ground Truth 仍需专家干预，限制了数据集向超大规模扩展的自动化程度。
*   **单次推理限制：** 与 LLM 的多轮迭代纠错不同，Ro-SLM 在推理时是单次生成的，缺乏运行时的自我修正能力。
*   **实机验证不足：** 实验主要在模拟器（AirSim）中完成，现实世界中的传感器噪声和动态环境干扰尚未充分验证。
