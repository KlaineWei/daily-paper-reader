## 摘要
大语言模型（LLM）的最新进展赋予了机器人理解人类指令的上下文推理能力。然而，目前支持 LLM 的机器人通常依赖于云端模型或高性能计算基础设施，这限制了它们在网络环境不可靠或计算资源受限的机器人（如无人机和小型地面车辆）上的部署。因此，部署支持机载部署的微调小语言模型（SLM）提供了一个极具前景的替代方案。本文介绍了 Ro-SLM，这是一个通过蒸馏 LLM 的知识和推理能力，实现可靠的 SLM 驱动机器人操作的框架。Ro-SLM 从数据集合成开始，利用 LLM 生成多样化的任务指令，在极少人工辅助的情况下产生相应的基准代码，并将指令增强到现实世界的应用场景中。随后，Ro-SLM 使用该数据集进行微调，其中 LLM 作为奖励函数来指导训练。在无人机操作任务上的广泛实验表明，Ro-SLM 将 SLM 的性能从无法支持机器人任务规划和代码生成，提升到了接近 LLM 的水平。

## Abstract
Recent advances in large language models (LLMs) provide robots with contextual reasoning abilities to comprehend human instructions. Yet, current LLM-enabled robots typically depend on cloud-based models or high-performance computing infrastructure, which limit their deployment on robots under unreliable internet environments or with constrained computational resources, such as UAVs and small ground vehicles. Thus, deploying fine-tuned small language models (SLMs) that support onboard deployment offers a promising alternative. This paper introduces Ro-SLM, a framework that enables reliable SLM-driven robot operation by distilling LLMs' knowledge and reasoning. Ro-SLM starts from dataset synthesis by leveraging LLMs to generate diverse task instructions, produce corresponding ground truth code with minimal human assistance, and augment instructions into real-world application scenarios. Ro-SLM is then fine-tuned with the dataset, in which LLM serves as a reward function to guide the training. Extensive experiments on UAV operation tasks demonstrate that Ro-SLM improves the performance of SLM from being incapable of supporting robotic task planning and code generation to achieving performance that approaches LLM.

以下是对该论文的结构化总结：

### 1. 核心问题与研究动机
*   **背景**：大语言模型（LLM）在机器人任务规划和代码生成方面表现卓越，但其巨大的参数量导致了高昂的计算开销。
*   **痛点**：现有的机器人 LLM 方案通常依赖云端 API（需要稳定网络）或高性能计算集群（高功耗、高载荷），这使得它们难以部署在无人机（UAV）或小型地面车辆等资源受限、环境多变的机载平台上。
*   **核心问题**：如何在保持机载部署可行性的同时，让小语言模型（SLM）具备接近 LLM 的复杂逻辑推理和任务规划能力？

### 2. 方法论：Ro-SLM 框架
Ro-SLM 的核心思想是**“通过 LLM 蒸馏知识来增强 SLM”**，主要分为两个阶段：

*   **阶段一：数据集合成（Dataset Synthesis）**
    1.  **任务指令生成**：利用 LLM 代理根据预设的机器人操作策略和演示，自动生成涵盖不同复杂度的任务指令集。
    2.  **基准代码生成（Ground Truth）**：采用纠错式代码生成框架，将指令映射为可执行代码。对于极高难度的任务，引入少量人工辅助以确保代码的绝对正确性。
    3.  **场景增强（Augmentation）**：利用 LLM 的世界知识，将简洁的指令（如“向上飞5米”）改写为更符合人类自然语言习惯的现实场景描述（如“检查仓库通风口，请上升5米”），并去除代码注释以防止模型过拟合于语言模式而非逻辑。
*   **阶段二：SLM 微调与优化**
    1.  **监督微调（SFT）**：在合成数据集上对 SLM（如 Llama-3.1-8B）进行初步训练，使其掌握机器人 API 和基本指令映射。
    2.  **基于 LLM 反馈的强化学习（GRPO）**：使用组相对策略优化（GRPO）算法，并配置一个 LLM 作为奖励函数。LLM 负责判断 SLM 生成的代码在逻辑行为上是否与基准代码等效，从而指导模型进行深层推理优化。

### 3. 实验设计
*   **实验场景**：主要针对无人机（UAV）操作任务，并在地面车辆（ROSMASTER X3）上验证了泛化性。
*   **数据集**：
    *   **Basic Dataset**：44个简单任务（1-2个动作）。
    *   **Advanced Dataset**：20个长程复杂任务（涉及几何推理和多步规划）。
    *   **Real-world Mapping**：上述数据集的自然语言增强版本。
*   **对比方法（Baselines）**：
    *   **GSCE / Corrective GSCE**：基于 GPT-4o-mini 的 SOTA 提示词工程方法。
    *   **原始 Llama-3.1-8B**：未经过 Ro-SLM 微调的原始小模型。

### 4. 资源与算力
*   **硬件环境**：实验在一台配备了 **2 张 Nvidia A100 GPU** 的服务器上进行。
*   **模型规模**：选用了 **Llama-3.1-8B** 作为 SLM 基础模型，该模型在量化后可运行在 Jetson AGX Orin 等机载计算单元上（约需 16GB 显存）。
*   **训练细节**：使用了 LoRA 技术提高微调效率。论文未明确给出具体的总训练时长，但提到了所有结果均取三次运行的平均值以减少随机性。

### 5. 实验数量与充分性
*   **实验规模**：合成了 598 个指令-代码对用于训练，并在 106 个测试对上进行评估。
*   **消融实验**：非常充分。作者分别测试了“保留注释”、“无增强”、“仅简单任务训练”、“仅复杂任务训练”以及“无 GRPO 优化”等多种变体，验证了每个模块的必要性。
*   **客观性**：通过在不同机器人平台（无人机 vs 地面车辆）和不同复杂度等级（Low 到 Very High）下进行对比，证明了方法的鲁棒性和泛化能力。

### 6. 主要结论与发现
*   **性能飞跃**：原始 SLM 几乎无法完成机器人任务（成功率极低），而经过 Ro-SLM 微调后，在简单任务上达到了 **97.7%** 的成功率，在复杂任务上达到了 **70%**，接近 LLM 水平。
*   **超越 LLM 的潜力**：在“极高难度”任务中，Ro-SLM 的成功率甚至超过了某些 LLM 方案，这归功于高质量人工辅助标注的基准数据。
*   **数据质量至关重要**：实验发现 SLM 对训练数据的分布非常敏感，多样化的复杂度分布和去除代码注释能显著提升模型性能。

### 7. 优点与亮点
*   **机载可行性**：成功将复杂的推理能力压缩进 8B 规模的模型，解决了机器人脱离云端运行的难题。
*   **创新的奖励机制**：不使用传统的文本相似度（如 BLEU），而是利用 LLM 理解代码背后的“机器人行为意图”来提供奖励，更符合具身智能的需求。
*   **自动化程度高**：通过 LLM 代理大幅降低了构建高质量机器人指令数据集的人工成本。

### 8. 不足与局限
*   **内存限制**：虽然 8B 模型比 405B 小得多，但 16GB 的显存需求对于极小型的嵌入式设备（如单片机或低端边缘模块）依然过高。
*   **人工依赖**：对于极复杂的长程任务，仍需专家介入纠正基准代码，无法做到 100% 自动化数据生成。
*   **闭环反馈缺失**：Ro-SLM 目前主要采用单次生成（Single-pass），缺乏像某些 LLM 框架那样的实时感知纠错能力（即在执行过程中根据传感器反馈修正代码）。
*   **环境泛化**：实验主要在仿真环境（AirSim）中完成，真实世界中的物理噪声和动态障碍物可能对模型表现产生额外挑战。
