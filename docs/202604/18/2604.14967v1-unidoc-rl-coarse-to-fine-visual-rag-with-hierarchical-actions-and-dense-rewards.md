## 摘要
检索增强生成 (RAG) 通过外部视觉知识扩展了大视觉语言模型 (LVLMs)。然而，现有的视觉 RAG 系统通常依赖于通用的检索信号，忽略了复杂推理所必需的细粒度视觉语义。为了解决这一局限性，我们提出了 UniDoc-RL，这是一个统一的强化学习框架，其中 LVLM 智能体共同执行检索、重排序、主动视觉感知和推理。UniDoc-RL 将视觉信息获取建模为具有分层动作空间的序列决策问题。具体而言，它将视觉证据从粗粒度的文档检索逐步细化为细粒度的图像选择和主动区域裁剪，使模型能够抑制无关内容并关注信息密集区域。为了实现有效的端到端训练，我们引入了一种稠密多奖励方案，为每个动作提供任务感知的监督。基于群体相对策略优化 (GRPO)，UniDoc-RL 在不依赖独立价值网络的情况下，使智能体行为与多个目标保持一致。为了支持这种训练范式，我们构建了一个包含高质量推理轨迹和细粒度动作标注的综合数据集。在三个基准测试上的实验表明，UniDoc-RL 持续超越了最先进的基准模型，相比之前的基于强化学习的方法提升高达 17.7%。

## Abstract
Retrieval-Augmented Generation (RAG) extends Large Vision-Language Models (LVLMs) with external visual knowledge. However, existing visual RAG systems typically rely on generic retrieval signals that overlook the fine-grained visual semantics essential for complex reasoning. To address this limitation, we propose UniDoc-RL, a unified reinforcement learning framework in which an LVLM agent jointly performs retrieval, reranking, active visual perception, and reasoning. UniDoc-RL formulates visual information acquisition as a sequential decision-making problem with a hierarchical action space. Specifically, it progressively refines visual evidence from coarse-grained document retrieval to fine-grained image selection and active region cropping, allowing the model to suppress irrelevant content and attend to information-dense regions. For effective end-to-end training, we introduce a dense multi-reward scheme that provides task-aware supervision for each action. Based on Group Relative Policy Optimization (GRPO), UniDoc-RL aligns agent behavior with multiple objectives without relying on a separate value network. To support this training paradigm, we curate a comprehensive dataset of high-quality reasoning trajectories with fine-grained action annotations. Experiments on three benchmarks demonstrate that UniDoc-RL consistently surpasses state-of-the-art baselines, yielding up to 17.7% gains over prior RL-based methods.

### UniDoc-RL 论文深度总结

#### 1. 核心问题与整体含义（研究动机和背景）
现有的视觉检索增强生成（Visual RAG）系统在处理复杂视觉文档（如带有图表、表格的扫描件）时面临三大挑战：
*   **检索精度不足**：通用检索器往往基于浅层匹配，难以捕捉复杂推理所需的细粒度语义，导致引入无关背景噪声。
*   **视觉利用率低**：现有模型多为被动接收全图，无法像人类一样主动关注信息密集区域，造成上下文窗口浪费和细节丢失。
*   **优化困难（信用分配问题）**：传统的强化学习（RL）方法通常只使用稀疏的最终结果奖励，难以对检索、筛选、裁剪等中间决策步骤进行有效监督。

**UniDoc-RL** 的提出旨在通过一个统一的强化学习框架，将视觉 RAG 建模为“由粗到精”的序列决策过程，使智能体能够自主进行检索、重排序、主动感知和推理。

#### 2. 方法论：核心思想与关键技术
UniDoc-RL 将视觉信息获取定义为 **Thought-Action-Observation (T, A, O)** 框架，核心技术包括：

*   **分层动作空间（Hierarchical Action Space）**：
    1.  **Image Search（搜索）**：调用外部工具进行粗粒度候选文档检索。
    2.  **Precise Selection（选择）**：由 LVLM 智能体对候选图进行语义筛选，过滤掉检索器引入的噪声。
    3.  **Visual Perception（感知）**：通过 `<bbox>` 动作主动定位关键区域，执行裁剪（Crop）和缩放（Zoom），提取高分辨率细节。
*   **密集多奖励机制（Dense Multi-Reward Scheme）**：
    *   **检索奖励 ($r_{ir}$)**：基于 NDCG 评估搜索结果的排序质量。
    *   **选择奖励 ($r_{sel}$)**：评估 LVLM 筛选出的图像是否包含真实证据（包含伪监督策略）。
    *   **感知奖励 ($r_{crop}$)**：基于预测框与真实区域的 IoU（交并比）进行评分。
    *   **模式奖励 ($r_{pat}$)**：确保模型遵循预定义的 XML 格式规范。
    *   **结果奖励 ($r_{ans}$)**：由奖励模型（RM）评估最终答案的正确性。
*   **优化算法**：采用 **GRPO（Group Relative Policy Optimization）**，通过组内相对评分进行策略更新，无需独立的价值网络（Value Network），降低了训练开销。

#### 6. 主要结论与发现
*   **性能飞跃**：UniDoc-RL 在所有基准测试中均达到 SOTA，相比之前的 RL 方法（如 VRAG-RL），在 3B 和 7B 模型上分别实现了 **17.5% 和 17.7%** 的性能提升。
*   **选择动作的价值**：LVLM 驱动的选择动作显著提高了检索召回率（Recall），有效弥补了粗粒度检索器的不足。
*   **RL 的进化作用**：SFT 模型倾向于保守的“全图阅读”，而经过 RL 训练后，模型学会了更积极、更精准地调用“裁剪”工具来获取细节。
*   **任务适应性**：选择动作对推理密集型任务（SlideVQA）提升更大，而感知动作对细节密集型任务（MMLongBench）贡献更多。

#### 7. 优点
*   **由粗到精的逻辑**：分层动作空间（搜索-选择-感知）非常符合人类处理复杂文档的认知过程。
*   **密集奖励设计**：成功解决了长链条决策中的信用分配问题，使中间步骤（如裁剪位置）得到显式优化。
*   **高质量数据贡献**：开源了包含细粒度动作标注的推理轨迹数据集，对社区具有重要价值。
*   **算法高效性**：利用 GRPO 避免了复杂的价值网络训练，提升了 RL 阶段的稳定性。

#### 8. 不足与局限
*   **推理延迟**：多轮迭代（搜索、选择、裁剪、推理）虽然提高了准确率，但显著增加了端到端的推理耗时。
*   **数据依赖**：训练依赖于高性能教师模型（如 Qwen3-VL-235B）生成的合成轨迹，若教师模型存在偏见，可能影响学生模型。
*   **应用限制**：目前主要针对静态文档图像，对于动态视频或极大规模实时网页 RAG 的适用性尚待验证。
*   **算力门槛**：尽管使用了 GRPO，但 8 张 A100 的配置对于个人开发者或小型研究团队仍有一定门槛。
