## 摘要
大语言模型（LLM）的最新进展赋予了机器人理解人类指令的上下文推理能力。然而，目前支持 LLM 的机器人通常依赖于云端模型或高性能计算基础设施，这限制了它们在网络环境不可靠或计算资源受限（如无人机和小型地面车辆）的机器人上的部署。因此，部署支持机载部署的微调小语言模型（SLM）提供了一个极具前景的替代方案。本文介绍了 Ro-SLM，这是一个通过蒸馏 LLM 的知识和推理能力来实现可靠的 SLM 驱动机器人操作的框架。Ro-SLM 从数据集合成开始，利用 LLM 生成多样化的任务指令，在极少人工协助的情况下生成相应的真值代码，并将指令增强到现实应用场景中。随后，Ro-SLM 使用该数据集进行微调，其中 LLM 作为奖励函数来指导训练。在无人机操作任务上的广泛实验表明，Ro-SLM 显著提升了 SLM 的性能，使其从无法支持机器人任务规划和代码生成提升到接近 LLM 的水平。

## Abstract
Recent advances in large language models (LLMs) provide robots with contextual reasoning abilities to comprehend human instructions. Yet, current LLM-enabled robots typically depend on cloud-based models or high-performance computing infrastructure, which limit their deployment on robots under unreliable internet environments or with constrained computational resources, such as UAVs and small ground vehicles. Thus, deploying fine-tuned small language models (SLMs) that support onboard deployment offers a promising alternative. This paper introduces Ro-SLM, a framework that enables reliable SLM-driven robot operation by distilling LLMs' knowledge and reasoning. Ro-SLM starts from dataset synthesis by leveraging LLMs to generate diverse task instructions, produce corresponding ground truth code with minimal human assistance, and augment instructions into real-world application scenarios. Ro-SLM is then fine-tuned with the dataset, in which LLM serves as a reward function to guide the training. Extensive experiments on UAV operation tasks demonstrate that Ro-SLM improves the performance of SLM from being incapable of supporting robotic task planning and code generation to achieving performance that approaches LLM.

*   **核心问题**：如何在不依赖云端和高性能硬件的前提下，让机载的小语言模型（SLM）具备与 LLM 相当的逻辑推理、任务规划和机器人操作代码生成能力。

### 2. 方法论：核心思想与关键技术
Ro-SLM 的核心思想是**“通过 LLM 蒸馏知识来增强 SLM”**，分为两个主要阶段：
*   **阶段一：数据集合成（Dataset Synthesis）**
    *   **任务指令生成**：利用 LLM 代理根据定义的机器人操作策略和演示，自动生成不同复杂度的任务指令。
    *   **真值代码生成**：采用纠错式代码生成框架，将指令映射为可执行代码。对于高复杂度任务（5步以上动作），引入少量人工审核以确保数据质量。
    *   **场景增强**：利用 LLM 的世界知识，将简洁的指令（如“向上飞5米”）改写为更符合人类习惯的现实应用场景描述（如“检查仓库墙壁的垂直状况”），提高模型的鲁棒性。
    *   **数据去噪**：移除代码中的所有注释，防止 SLM 过度拟合语言模式而非逻辑结构。
*   **阶段二：SLM 微调与优化**
    *   **监督微调（SFT）**：使用合成数据集对 SLM（如 Llama-3.1-8B）进行初步训练，并结合 LoRA 技术提高效率。
    *   **基于 LLM 反馈的优化（GRPO）**：引入组相对策略优化（GRPO），利用 LLM 作为奖励函数。LLM 不仅对比文本相似度，更通过解释代码隐含的机器人行为来判断其与真值的一致性，从而提供更精准的奖励信号。

### 3. 实验设计
*   **实验场景**：主要针对无人机（UAV）操作任务，并在地面车辆（ROSMASTER X3）上验证了泛化性。
*   **数据集**：
    *   **Basic Dataset**：44个简单任务（1-2个动作）。
    *   **Advanced Dataset**：20个长程复杂任务（分为低、中、高、极高四个难度）。
    *   **Real-world Mapping**：上述数据集的现实场景增强版本。
*   **Benchmark 与对比方法**：
    *   **GSCE**：基于 GPT-4o-mini 的提示词工程方法。
    *   **Corrective GSCE**：目前最先进的（SOTA）基于 LLM 的纠错生成方法。
    *   **原始 Llama-3.1-8B**：未经过 Ro-SLM 微调的基座模型。

### 4. 资源与算力
*   **硬件环境**：实验在一台配备了 **2 张 Nvidia A100 GPU** 的服务器上进行。
*   **模型规模**：选用了 **Llama-3.1-8B** 作为 SLM 目标模型，认为其 16GB 的显存占用适合部署在 Jetson AGX Orin 等机载计算单元上。
*   **训练时长**：文中未明确给出具体的训练总时长，但提到了使用了 LoRA 和 GRPO 来优化内存使用并加速训练。

### 5. 实验数量与充分性
*   **实验规模**：合成了 598 个指令-代码对（492个用于训练，106个用于评估）。
*   **实验维度**：涵盖了基础任务、高级任务、现实场景映射任务、跨平台（地面车）任务。
*   **消融实验**：非常充分。作者分别验证了“保留注释”、“无数据增强”、“单一复杂度数据训练”以及“无 GRPO 优化”对结果的影响。
*   **客观性**：所有实验结果均取三次运行的平均值，以减少 LLM 生成随机性的影响，评估指标（成功率 SR 和完成度 Completeness）定义明确且客观。

### 6. 主要结论与发现
*   **性能飞跃**：原始 SLM 在机器人任务上几乎不可用，而 Ro-SLM 使其在基础任务上达到了 **97.7% 的成功率**，在高级任务上达到了 **70% 的成功率**。
*   **接近 LLM**：Ro-SLM 微调后的 8B 模型在复杂任务上的表现已接近甚至在某些极高难度任务上超过了 GPT-4o-mini。
*   **泛化能力**：模型不仅能处理结构化指令，也能理解自然语言描述的现实场景，并能成功迁移到地面机器人平台。
*   **关键因素**：数据多样性和去除代码注释对 SLM 的性能提升至关重要。

### 7. 优点（亮点）
*   **闭环蒸馏**：不仅利用 LLM 生成数据，还利用 LLM 作为行为级的奖励函数进行强化学习优化。
*   **机载友好**：针对资源受限环境设计，摆脱了对云端和高性能计算的依赖。
*   **高质量数据管线**：通过“自动生成+纠错框架+高难任务人工介入”的模式，构建了一个高质量的机器人指令数据集。

### 8. 不足与局限
*   **内存占用仍有挑战**：虽然 8B 模型比 405B 小得多，但 16GB 显存对于更小型的嵌入式设备（如更低端的边缘计算模块）依然偏大。
*   **人工依赖**：在构建真值数据集时，极高难度的任务仍需人工干预，限制了其向全新领域快速迁移的自动化程度。
*   **单次推理限制**：Ro-SLM 在推理时采用单次生成（Single-pass），不像某些 LLM 方案可以进行多轮迭代纠错，这在处理极其复杂的逻辑时可能存在瓶颈。
*   **环境动态性**：实验主要在仿真环境（AirSim）中完成，在具有不可预测变量的真实物理环境中的鲁棒性仍需进一步验证。
