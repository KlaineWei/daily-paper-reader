## 摘要
大语言模型（LLMs）的最新进展赋予了机器人理解人类指令的上下文推理能力。然而，目前支持 LLM 的机器人通常依赖于云端模型或高性能计算基础设施，这限制了它们在网络环境不可靠或计算资源受限（如无人机和小型地面车辆）的机器人上的部署。因此，部署支持机载运行的微调小语言模型（SLMs）提供了一个极具前景的替代方案。本文介绍了 Ro-SLM，这是一个通过蒸馏 LLMs 的知识与推理能力来实现可靠的 SLM 驱动机器人操作的框架。Ro-SLM 从数据集合成入手，利用 LLMs 生成多样化的任务指令，在极少人工辅助的情况下产生相应的基准代码，并将指令增强至现实应用场景中。随后，Ro-SLM 使用该数据集进行微调，其中 LLM 作为奖励函数来指导训练。在无人机操作任务上的广泛实验表明，Ro-SLM 显著提升了 SLM 的性能，使其从无法支持机器人任务规划和代码生成，提升至接近 LLM 的水平。

## Abstract
Recent advances in large language models (LLMs) provide robots with contextual reasoning abilities to comprehend human instructions. Yet, current LLM-enabled robots typically depend on cloud-based models or high-performance computing infrastructure, which limit their deployment on robots under unreliable internet environments or with constrained computational resources, such as UAVs and small ground vehicles. Thus, deploying fine-tuned small language models (SLMs) that support onboard deployment offers a promising alternative. This paper introduces Ro-SLM, a framework that enables reliable SLM-driven robot operation by distilling LLMs' knowledge and reasoning. Ro-SLM starts from dataset synthesis by leveraging LLMs to generate diverse task instructions, produce corresponding ground truth code with minimal human assistance, and augment instructions into real-world application scenarios. Ro-SLM is then fine-tuned with the dataset, in which LLM serves as a reward function to guide the training. Extensive experiments on UAV operation tasks demonstrate that Ro-SLM improves the performance of SLM from being incapable of supporting robotic task planning and code generation to achieving performance that approaches LLM.

*   **研究背景**：大语言模型（LLM）在机器人任务规划和代码生成方面表现出色，但其巨大的参数量和计算需求使其难以在无人机（UAV）或小型地面车辆等资源受限的平台上进行“机载（Onboard）”部署。
*   **核心问题**：现有的 LLM 方案通常依赖云端 API（需要稳定网络）或高性能计算集群，而现成的小语言模型（SLM）由于推理能力较弱，难以直接理解复杂的机器人指令并生成准确的操作代码。
*   **研究目标**：开发一种框架，将 LLM 的推理能力蒸馏到 SLM 中，使其在离线、低算力环境下也能达到接近 LLM 的任务执行水平。

### 2. 方法论
Ro-SLM 框架分为两个主要阶段：

*   **阶段一：数据集合成（Dataset Synthesis）**
    1.  **任务指令生成**：利用 LLM 代理根据预设的机器人操作策略和演示，自动生成不同复杂度的任务指令（从简单空间移动到复杂多步规划）。
    2.  **基准代码生成**：采用纠错式代码生成方法，将指令映射为机器人 API 代码。对于高复杂度任务，引入少量人工辅助以确保 Ground Truth 的绝对准确。
    3.  **场景增强**：利用 LLM 的世界知识，将简洁的指令（如“向上飞5米”）改写为更符合人类自然语言习惯的现实应用场景描述（如“检查仓库通风口”）。
    4.  **数据预处理**：移除代码中的所有注释，防止 SLM 过度拟合语法模式而非逻辑逻辑。

*   **阶段二：SLM 微调与优化**
    1.  **监督微调（SFT）**：使用合成数据集对 SLM（如 Llama-3.1-8B）进行微调，并采用 LoRA 技术提高效率。
    2.  **基于 LLM 反馈的优化（GRPO）**：引入群体相对策略优化（GRPO），将 LLM 配置为“奖励函数”。LLM 不比较文本相似度，而是解释代码背后的机器人行为意图，判断 SLM 生成的代码是否与基准代码在行为上等效，从而指导模型优化。

### 5. 实验数量与充分性
*   **实验规模**：合成了 598 个指令-代码对，其中 492 个用于训练，106 个用于评估。

*   **客观性**：所有结果均取三次运行的平均值以减少随机性影响。实验覆盖了从简单到极高难度的任务，并跨越了无人机和地面车辆两个平台，实验设计较为充分且客观。

### 6. 主要结论与发现
*   **性能飞跃**：Ro-SLM 使 Llama-3.1-8B 从几乎无法执行任务（SR 仅 9.1%）提升到了接近 LLM 的水平（简单任务 SR 97.7%，复杂任务 SR 70%）。
*   **超越 LLM 的潜力**：在“极高难度”任务中，Ro-SLM 的成功率甚至超过了 o4-mini，这归功于高质量人工辅助标注的微调数据。
*   **鲁棒性**：通过场景增强，模型对人类自然语言描述的理解能力显著增强。
*   **泛化性**：模型能够学习任务规划的逻辑，而非仅仅死记硬背 API，因此能较好地迁移到不同类型的机器人（如地面车辆）。

### 7. 优点与亮点
*   **行为等效奖励函数**：不依赖传统的 ROUGE/BLEU 分数，而是利用 LLM 理解代码行为意图作为奖励，这更符合机器人任务的本质。
*   **机载可行性**：证明了 8B 规模的模型经过针对性蒸馏后，可以在 Jetson AGX Orin 等嵌入式计算单元上独立运行。
*   **数据合成流水线**：提出了一套从指令生成到纠错接地再到场景增强的完整自动化/半自动化数据生产流程。

### 8. 不足与局限
*   **内存需求仍较高**：虽然 8B 模型比 405B 小得多，但仍需约 16GB 显存，对于极小型的边缘设备（如 1B/3B 级别需求）仍有挑战。
*   **人工依赖**：复杂任务的 Ground Truth 仍需领域专家介入校对，限制了其向全新领域快速扩张的规模化能力。
*   **单次推理限制**：Ro-SLM 在推理时采用单次生成（Single-pass），不像 Corrective GSCE 那样可以进行多轮迭代纠错，这在处理极复杂任务时可能存在容错率上限。
*   **现实环境变数**：实验主要在模拟器中完成，真实物理环境中的传感器噪声、动力学不确定性等因素尚未充分验证。
