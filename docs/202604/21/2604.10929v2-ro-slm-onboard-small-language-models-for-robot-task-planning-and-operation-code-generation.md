## 摘要
大语言模型（LLM）的最新进展赋予了机器人理解人类指令的上下文推理能力。然而，目前支持 LLM 的机器人通常依赖于云端模型或高性能计算基础设施，这限制了它们在网络环境不可靠或计算资源受限的机器人（如无人机和小型地面车辆）上的部署。因此，部署支持机载部署的微调小语言模型（SLM）提供了一个极具前景的替代方案。本文介绍了 Ro-SLM，这是一个通过蒸馏 LLM 的知识和推理能力，实现可靠的 SLM 驱动机器人操作的框架。Ro-SLM 从数据集合成开始，利用 LLM 生成多样化的任务指令，在极少人工辅助的情况下产生相应的基准代码，并将指令增强到现实世界的应用场景中。随后，Ro-SLM 使用该数据集进行微调，其中 LLM 作为奖励函数来指导训练。在无人机操作任务上的广泛实验表明，Ro-SLM 将 SLM 的性能从无法支持机器人任务规划和代码生成，提升到了接近 LLM 的水平。

## Abstract
Recent advances in large language models (LLMs) provide robots with contextual reasoning abilities to comprehend human instructions. Yet, current LLM-enabled robots typically depend on cloud-based models or high-performance computing infrastructure, which limit their deployment on robots under unreliable internet environments or with constrained computational resources, such as UAVs and small ground vehicles. Thus, deploying fine-tuned small language models (SLMs) that support onboard deployment offers a promising alternative. This paper introduces Ro-SLM, a framework that enables reliable SLM-driven robot operation by distilling LLMs' knowledge and reasoning. Ro-SLM starts from dataset synthesis by leveraging LLMs to generate diverse task instructions, produce corresponding ground truth code with minimal human assistance, and augment instructions into real-world application scenarios. Ro-SLM is then fine-tuned with the dataset, in which LLM serves as a reward function to guide the training. Extensive experiments on UAV operation tasks demonstrate that Ro-SLM improves the performance of SLM from being incapable of supporting robotic task planning and code generation to achieving performance that approaches LLM.

*   **研究动机**：
    *   **LLM 的局限性**：虽然 GPT-4 等大语言模型推理能力强，但依赖云端 API（需稳定网络）或极高的本地算力，不适合机载（Onboard）实时部署。
    *   **SLM 的局限性**：小语言模型（SLM）虽易于部署，但由于参数量小，在理解复杂指令、空间推理和长程规划方面表现较弱。
    *   **目标**：通过知识蒸馏和针对性微调，将 LLM 的推理能力迁移到 SLM 中，使其在端侧也能达到接近大模型的表现。

### 2. 方法论
Ro-SLM 框架分为两个主要阶段：

#### 阶段一：数据集合成（Dataset Synthesis）
1.  **任务指令生成 ($F_1$)**：利用 LLM 代理根据预设的机器人操作策略和演示，自动生成不同复杂度的任务指令（从简单空间移动到复杂多步规划）。
2.  **基准代码生成 ($F_2$)**：采用纠错式代码生成框架。对于简单任务由 LLM 自动生成；对于高复杂度任务（5步以上动作），引入**极少量人工辅助**进行校验，确保 Ground Truth 的绝对准确。
3.  **场景增强 ($F_3$)**：利用 LLM 的世界知识，将简洁的指令（如“向上飞5米”）改写为自然语言化的现实场景描述（如“检查仓库上方的通风口”），提高模型的鲁棒性。
4.  **数据预处理**：移除代码中的所有注释，防止 SLM 过度拟合语言模式而非逻辑结构。

#### 阶段二：SLM 微调（SLM Fine-tune）
1.  **监督微调 (SFT)**：使用合成数据集对 SLM（如 Llama-3.1-8B）进行初步训练，并采用 **LoRA** 技术提高效率。
2.  **基于 LLM 反馈的优化 (GRPO)**：引入组相对策略优化（GRPO）。关键创新在于**将 LLM 作为奖励函数**：LLM 不直接对比文本相似度，而是解释 SLM 生成代码的“意图”是否与基准代码的机器人行为一致，从而提供更准确的强化学习信号。

### 6. 主要结论与发现

### 7. 优点与亮点
*   **端侧友好**：成功将复杂的机器人规划能力压缩进 8B 规模的模型，支持 Jetson AGX Orin 等嵌入式设备部署。
*   **LLM 奖励函数设计**：避开了传统的文本相似度指标，通过 LLM 理解代码行为来提供奖励，解决了机器人代码生成中“语义相同但表达不同”的评价难题。
*   **高质量数据闭环**：结合了自动生成与极少量人工校验，平衡了数据规模与数据质量。

### 8. 不足与局限
*   **内存占用**：虽然 8B 模型比 405B 小得多，但仍需约 16GB 显存，对于更小型的边缘设备（如 1B/3B 需求场景）仍有压力。
