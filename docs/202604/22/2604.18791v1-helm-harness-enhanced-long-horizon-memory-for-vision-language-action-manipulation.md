## 摘要
尽管视觉-语言-动作（VLA）模型在短程任务中表现强劲，但在长程操纵任务中却存在系统性失败。我们表明，在当前的反应式执行设置中，仅靠延长上下文长度无法解决这一失败；相反，它源于执行循环中反复出现的三个缺陷：记忆间隙、验证间隙和恢复间隙。我们提出了 HELM，这是一个与模型无关的框架，通过三个组件解决这些缺陷：一个通过 CLIP 索引关键帧检索关键任务历史的情景记忆模块（EMM）；一个学习得到的状态验证器（SV），它根据观测、动作、子目标和受记忆约束的上下文在执行前预测动作失败；以及一个执行回滚和重新规划的 Harness 控制器（HC）。SV 是核心的学习贡献：它始终优于基于规则的可行性检查和集成不确定性基准，且其有效性关键取决于对情景记忆的访问。在 LIBERO-LONG 上，HELM 将任务成功率比 OpenVLA 提高了 23.1 个百分点（从 58.4% 提升至 81.5%），而将上下文窗口扩展到 H=32 仅带来 5.4 个百分点的提升，且相同预算下的 LoRA 适配仍比 HELM 低 12.2 个百分点。HELM 还提高了在 CALVIN 上的长程表现，并显著提升了受控扰动下的恢复成功率。消融实验和机制分析分离了各组件的贡献，我们发布了 LIBERO-Recovery，作为一种用于评估长程操纵中故障恢复的扰动注入协议。

## Abstract
Vision-Language-Action (VLA) models fail systematically on long-horizon manipulation tasks despite strong short-horizon performance. We show that this failure is not resolved by extending context length alone in the current reactive execution setting; instead, it stems from three recurring execution-loop deficiencies: the memory gap, the verification gap, and the recovery gap. We present HELM, a model-agnostic framework that addresses these deficiencies with three components: an Episodic Memory Module (EMM) that retrieves key task history via CLIP-indexed keyframes, a learned State Verifier (SV) that predicts action failure before execution from observation, action, subgoal, and memory-conditioned context, and a Harness Controller (HC) that performs rollback and replanning. The SV is the core learning contribution: it consistently outperforms rule-based feasibility checks and ensemble uncertainty baselines, and its effectiveness depends critically on access to episodic memory. On LIBERO-LONG, HELM improves task success rate by 23.1 percentage points over OpenVLA (58.4% to 81.5%), while extending the context window to H=32 yields only a 5.4-point gain and same-budget LoRA adaptation remains 12.2 points below HELM. HELM also improves long-horizon performance on CALVIN and substantially boosts recovery success under controlled perturbations. Ablations and mechanism analyses isolate the contribution of each component, and we release LIBERO-Recovery as a perturbation-injection protocol for evaluating failure recovery in long-horizon manipulation.

### 1. 核心问题与整体含义（研究动机和背景）
*   **核心问题**：现有的视觉-语言-动作（VLA）模型（如 OpenVLA, Octo）在短程任务中表现优异，但在长程操纵任务中性能大幅下降。
*   **研究动机**：作者发现单纯增加上下文窗口长度（Context Length）并不能解决长程任务的失败。这种失败源于三个系统性缺陷：
    1.  **记忆间隙（Memory Gap）**：固定窗口会丢弃已完成子目标的证据，导致模型重复执行已完成的动作。
    2.  **验证间隙（Verification Gap）**：模型反应式地提出动作，缺乏执行前的可行性检查。
    3.  **恢复间隙（Recovery Gap）**：一旦动作失败，模型会在损坏的状态下继续执行，导致连锁反应。
*   **整体含义**：HELM 旨在通过一个模型无关的框架，引入显式记忆、预执行验证和自动恢复机制，增强 VLA 模型在复杂长程任务中的鲁棒性。

### 2. 方法论：核心思想与关键技术
HELM 框架由三个核心组件组成，形成一个“检索-提议-验证-执行/恢复”的闭环：
*   **情景记忆模块 (EMM)**：
    *   维护一个基于 CLIP 索引的关键帧存储库。
    *   **写入策略**：在子目标完成、检测到失败或每隔 20 步（检查点）时记录状态。
    *   **检索**：通过余弦相似度检索最相关的历史关键帧，并将其序列化为文本注入 VLA 的语言输入中。
*   **状态验证器 (SV) —— 核心贡献**：
    *   这是一个轻量级的 MLP 模型，输入当前观测、拟执行动作、当前子目标和检索到的记忆上下文。
    *   **核心逻辑**：在动作执行前预测失败概率 $p_{fail}$。它不仅检查物理可行性，还结合记忆判断动作在逻辑上是否合理（例如：是否在重复已完成的步骤）。
*   **Harness 控制器 (HC)**：
    *   管理子目标堆栈。如果 SV 预测失败，HC 会触发恢复机制。
    *   **回滚（Rollback）**：利用 EMM 中的检查点引导机器人回到之前的成功状态。
    *   **前向恢复（Forward Recovery）**：在无法回滚的环境中，生成新的规划尝试从当前错误状态恢复。

### 3. 实验设计
*   **数据集/场景**：

    2.  **CALVIN (ABC → D)**：评估在未见环境中的长程链式任务完成情况。
    3.  **LIBERO-Recovery (本文提出)**：专门用于评估故障恢复能力的协议，在子目标边界随机注入物体位移或夹具状态翻转等扰动。

### 4. 资源与算力
*   **硬件**：实验主要在 **NVIDIA A100 (80GB)** GPU 上运行。
*   **训练时长**：状态验证器（SV）的训练需要约 5 万步的 rollout 数据，在单张 A100 上训练约 **2 小时**。
*   **推理开销**：HELM 引入的额外延迟约为 **12ms/步**，比单纯运行 VLA 骨干模型增加了约 15% 的计算开销。

*   **实验规模**：

*   **充分性与公平性**：
    *   **消融实验**：详细拆解了 EMM、SV、HC 以及记忆上下文对 SV 的影响，证明了各组件的必要性。
    *   **公平对比**：特别设置了“相同预算 LoRA”基准，证明了将数据用于训练验证器比直接微调骨干模型更有效。

### 6. 主要结论与发现
*   **长上下文并非万能**：将上下文从 8 增加到 64，成功率提升有限（仅约 6.7%），无法弥补结构性的记忆缺陷。
*   **HELM 性能卓越**：在 LIBERO-LONG 上，HELM 将 OpenVLA 的成功率从 **58.4% 提升至 81.5%**（+23.1 pp）。
*   **验证器的关键性**：学习得到的 SV 优于基于规则的检查和不确定性估计，且 SV 的准确率高度依赖于记忆模块提供的上下文。
*   **恢复能力**：在注入扰动的情况下，HELM 的恢复成功率（RSR）达到 54.2%，远高于原始模型的 12.3%。

### 7. 优点（亮点）
*   **模块化与通用性**：不改变 VLA 骨干模型权重，易于集成到任何现有的反应式策略中。
*   **预执行干预**：不同于事后反思（Reflexion），HELM 在错误发生前进行拦截，节省了执行时间和物理损耗。
*   **新评估协议**：提出的 LIBERO-Recovery 为机器人社区研究“鲁棒性”和“故障恢复”提供了标准化的工具。

### 8. 不足与局限
*   **数据依赖性**：SV 的训练需要针对特定环境收集约 5 万步的 rollout 数据，这限制了其在完全陌生环境下的零样本（Zero-shot）部署能力。
*   **回滚假设**：回滚机制假设动作是可逆的或环境可以重置，虽然提出了“前向恢复”变体，但在极端不可逆任务中的表现仍有待提升。
*   **仿真与现实差距**：实验全部在仿真环境（LIBERO, CALVIN）中完成，尚未在真实机器人上验证 CLIP 编码在真实光照/噪声下的判别力。
*   **子目标分解瓶颈**：依赖 VLA 自身的分解能力，若初始任务分解错误，HELM 的提升空间会受限。
