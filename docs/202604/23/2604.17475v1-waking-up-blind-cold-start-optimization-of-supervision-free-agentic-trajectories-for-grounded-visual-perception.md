## 摘要
小型视觉语言模型（SVLMs）是高效的任务控制器，但通常面临视觉脆弱性和工具编排能力差的问题。为了缓解这些缺陷，通常需要昂贵的监督轨迹微调。在这项工作中，我们提出了通过级联工具展开对齐实现的自监督感知（SPECTRA），这是一个无需监督的框架，通过冷启动强化学习引导 SVLMs 的智能体能力。SPECTRA 强制执行软结构化多轮展开（Soft Structured Multi-turn Rollouts），这是一种拓扑约束，引导智能体在综合之前显式地对工具获取的证据进行排序，从而有效地将推理建立在视觉观察的基础上。我们采用了一种多目标奖励信号，同时最大化任务正确性、展开结构和工具效用，使智能体能够在没有人类偏好标签的情况下自我发现鲁棒行为。我们还引入了工具工具性效用（TIU），这是一种在缺乏地面真值的情况下量化工具效能的新指标。在复合和分布外（MMMU-Pro）基准测试上的广泛评估表明，SPECTRA 提升了智能体轨迹，将任务准确率提高了多达 5%，工具效率提高了 9%，从而实现了仅通过环境交互即可有效学习的更高效的多模态智能体。

## Abstract
Small Vision-Language Models (SVLMs) are efficient task controllers but often suffer from visual brittleness and poor tool orchestration. They typically require expensive supervised trajectory tuning to mitigate these deficits. In this work, we propose Self-supervised Perception Enabled by Cascaded Tool Rollout Alignment (SPECTRA), a supervision-free framework that bootstraps agentic capabilities via Coldstart Reinforcement Learning for SVLMs. SPECTRA enforces Soft Structured Multi-turn Rollouts, a topological constraint that directs agents to explicitly sequence tool derived evidence before synthesis, effectively grounding reasoning in visual observations. We employ a multi-objective reward signal that simultaneously maximizes task correctness, rollout structure, and tool utility, enabling agent to self-discover robust behaviors without human preference labels. We further introduce Tool Instrumental Utility (TIU), a novel metric to quantify tool efficacy in the absence of ground truth. Extensive evaluations across composite and out-of-distribution (MMMU-Pro) benchmarks demonstrate that SPECTRA boosts agentic trajectories, improving task accuracy by up to 5% and tool efficiency by 9%, enabling more efficient multimodal agents that learn effectively from environmental interaction alone.

### 2. 方法论：SPECTRA 框架
SPECTRA（Self-supervised Perception Enabled by Cascaded Tool Rollout Alignment）的核心思想是通过强化学习优化智能体的决策轨迹。

*   **核心思想**：利用**冷启动强化学习（Cold-Start RL）**，在没有人类演示数据的情况下，通过多目标奖励函数引导模型发现最优的工具调用和推理路径。
*   **关键技术细节**：
    *   **软结构化多轮展开（Soft Structured Multi-turn Rollouts）**：强制执行一种特定的推理拓扑结构：`推理 -> 工具调用 -> 观察集成 -> 感知再对齐 -> 重新推理 -> 最终回答`。这种结构迫使模型在给出答案前，必须先通过工具获取证据并进行视觉合成。
    *   **多目标奖励信号 ($R_{total}$)**：
        1.  **任务正确性 ($R_{corr}$)**：最终答案是否正确。
        2.  **结构完整性 ($R_{struct}$)**：轨迹是否符合预设的推理拓扑结构。
        3.  **工具效用 ($R_{tool}$)**：包括语法正确性、执行成功率及工具多样性奖励。
        4.  **终止符奖励 ($R_{term}$)**：确保模型能正常收敛到答案标签。
    *   **优化算法**：采用 **GRPO（Group Relative Policy Optimization）**。通过对同一问题采样一组（$G$个）不同的推理轨迹，计算组内的相对优势（Advantage），从而在无需价值模型（Value Model）的情况下稳定策略梯度更新。
    *   **新指标 TIU（Tool Instrumental Utility）**：综合衡量工具执行的可靠性（TER）、工具与任务成功的相关性（TTAC）以及工具选择的策略性（TSS）。

*   **性能提升**：SPECTRA 在 7B 模型上相比最强基线，任务准确率平均提升了 **3% - 5%**，在 ScienceQA 和 OK-VQA 上表现尤为突出。

*   **冷启动可行性**：证明了即使没有高质量的人类轨迹数据，通过合理的结构约束和环境反馈，SVLM 也能进化出强大的智能体能力。

### 7. 优点与亮点
*   **无需监督**：摆脱了对昂贵轨迹标注的依赖，降低了智能体训练的门槛。
*   **结构化感知**：通过“软结构化”约束解决了 SVLM 容易跳过视觉细节直接猜测答案的“盲目”问题。
*   **评估创新**：提出的 TIU 指标为无监督环境下的工具效能评估提供了科学的量化手段。
*   **鲁棒性强**：在 OOD 数据集 MMMU-Pro 上依然保持了领先优势，证明了方法的泛化性。

### 8. 不足与局限
*   **工具集局限性**：目前仅集成了视觉相关工具（OCR、检测、描述），缺乏代码执行、搜索引擎等通用工具。
*   **中间步骤幻觉**：虽然最终答案正确率提高，但中间推理步骤（如 `<think_reasoning>` 内部）有时仍会出现幻觉或重复生成。
*   **空间推理瓶颈**：在处理极度复杂的解剖图或细微空间关系时（如区分左肺与右肺），模型仍可能受限于初始视觉编码器的能力。
