## 摘要
视觉-语言-动作（VLA）模型尽管在短时程任务中表现强劲，但在长时程操控任务中却存在系统性失效。我们表明，在当前的反应式执行设置下，仅通过延长上下文长度无法解决这一失效问题；相反，它源于执行循环中反复出现的三个缺陷：记忆鸿沟（memory gap）、验证鸿沟（verification gap）和恢复鸿沟（recovery gap）。我们提出了 HELM，这是一个与模型无关的框架，通过三个组件解决这些缺陷：情景记忆模块（EMM），通过 CLIP 索引的关键帧检索关键任务历史；学习型状态验证器（SV），根据观测、动作、子目标和基于记忆的上下文在执行前预测动作失败；以及引导控制器（HC），执行回滚和重新规划。SV 是核心的学习贡献：它始终优于基于规则的可行性检查和集成不确定性基准，且其有效性关键取决于对情景记忆的访问。在 LIBERO-LONG 数据集上，HELM 将任务成功率比 OpenVLA 提高了 23.1 个百分点（从 58.4% 提升至 81.5%），而将上下文窗口延长至 H=32 仅带来 5.4 个百分点的提升，且在相同预算下的 LoRA 适配仍比 HELM 低 12.2 个百分点。HELM 还提高了在 CALVIN 上的长时程表现，并显著增强了受控扰动下的恢复成功率。消融实验和机制分析分离了各组件的贡献，我们发布了 LIBERO-Recovery，这是一个用于评估长时程操控中故障恢复的扰动注入协议。

## Abstract
Vision-Language-Action (VLA) models fail systematically on long-horizon manipulation tasks despite strong short-horizon performance. We show that this failure is not resolved by extending context length alone in the current reactive execution setting; instead, it stems from three recurring execution-loop deficiencies: the memory gap, the verification gap, and the recovery gap. We present HELM, a model-agnostic framework that addresses these deficiencies with three components: an Episodic Memory Module (EMM) that retrieves key task history via CLIP-indexed keyframes, a learned State Verifier (SV) that predicts action failure before execution from observation, action, subgoal, and memory-conditioned context, and a Harness Controller (HC) that performs rollback and replanning. The SV is the core learning contribution: it consistently outperforms rule-based feasibility checks and ensemble uncertainty baselines, and its effectiveness depends critically on access to episodic memory. On LIBERO-LONG, HELM improves task success rate by 23.1 percentage points over OpenVLA (58.4% to 81.5%), while extending the context window to H=32 yields only a 5.4-point gain and same-budget LoRA adaptation remains 12.2 points below HELM. HELM also improves long-horizon performance on CALVIN and substantially boosts recovery success under controlled perturbations. Ablations and mechanism analyses isolate the contribution of each component, and we release LIBERO-Recovery as a perturbation-injection protocol for evaluating failure recovery in long-horizon manipulation.

### 1. 核心问题与整体含义（研究动机和背景）
论文关注的核心问题是：**视觉-语言-动作（VLA）模型在长程（Long-horizon）操控任务中表现极差**。尽管 OpenVLA 等模型在短程任务中成功率极高，但在步骤较多的长程任务中，性能会断崖式下跌。
作者指出，这种失败并非单纯因为上下文窗口不够长，而是源于当前“反应式执行”模式下的三个结构性缺陷：
*   **记忆鸿沟 (Memory Gap)**：固定窗口会丢弃已完成子目标的证据，导致模型重复执行已完成的动作。
*   **验证鸿沟 (Verification Gap)**：模型直接执行生成的动作，缺乏预执行的可行性检查。
*   **恢复鸿沟 (Recovery Gap)**：一旦发生错误，模型会在损坏的状态下继续尝试后续步骤，导致连锁失败。

### 2. 方法论：HELM 框架
HELM 是一个模型无关的增强框架，通过三个核心组件闭合上述“鸿沟”：
*   **情景记忆模块 (EMM)**：建立一个基于 CLIP 索引的关键帧存储库。它在子目标完成、检测到失败或每隔 20 步时写入关键帧。执行时，通过余弦相似度检索最相关的历史状态，并将其序列化为文本注入 VLA 的语言输入中。
*   **状态验证器 (SV) —— 核心贡献**：这是一个轻量级的 MLP 模型，在动作执行前预测失败概率 $P(fail | o_t, a_t, g_t, M_t)$。它不仅看当前的观测和动作，还结合了 EMM 提供的记忆上下文。
*   **引导控制器 (HC)**：负责协调循环。如果 SV 预测动作会失败，HC 会触发“回滚（Rollback）”机制，利用记忆中的检查点让机器人返回之前的安全状态并重新规划；对于不可逆环境，则提供“前向恢复（Forward Recovery）”变体。

### 3. 实验设计
*   **数据集/场景**：
    *   **LIBERO-LONG**：包含 10 个任务，平均 5.8 个子目标。
    *   **CALVIN (ABC → D)**：评估在未见环境中的长程链式操作能力。
    *   **LIBERO-Recovery (本文提出)**：在随机子目标边界注入扰动（如物体位移、夹爪状态翻转），专门测试恢复能力。
*   **对比方法 (Baselines)**：包括 OpenVLA (H=8/32/64)、Oracle Memory (真值注入)、规则验证器、集成不确定性方法 (Ensemble)、同等数据预算下的 LoRA 微调、以及 Reflexion (自我反思) 等 9 种基准。

### 4. 资源与算力
*   **硬件**：实验主要在 **NVIDIA A100 (80GB)** GPU 上运行。
*   **训练时长**：状态验证器 (SV) 的训练需要从 VLA 滚出数据中收集 5 万个样本，训练时间约为 **2 小时**。
*   **推理开销**：HELM 引入的额外延迟约为 **12ms/步**，仅比原始 VLA 骨干网络增加约 15% 的计算开销。

### 5. 实验数量与充分性
*   **实验规模**：涵盖了 3 个主要基准测试，每个实验运行 3 个随机种子并报告标准差。
*   **消融实验**：非常充分。作者分别验证了 EMM、SV、回滚机制的独立贡献，并对比了不同的检索策略（随机、最近、CLIP、学习型）和记忆大小 $k$。
*   **客观性**：通过引入“同等预算 LoRA”基准，证明了 HELM 的提升并非单纯来自额外的训练数据，而是来自架构设计的优越性。同时，通过在 OpenVLA 和 Octo 两个不同架构上测试，验证了框架的通用性。

### 6. 主要结论与发现
*   **长上下文并非万能**：将上下文窗口从 8 增加到 64，成功率仅提升不到 7%，远低于 HELM 的提升（23.1%）。
*   **记忆与验证的耦合**：SV 的有效性高度依赖于记忆上下文，移除记忆后 SV 的性能显著下降。
*   **回滚的价值**：在可逆任务中，回滚机制比单纯的前向重规划能更有效地解决连锁失败问题。
*   **性能飞跃**：在 LIBERO-LONG 上，HELM 将成功率从 58.4% 提升至 81.5%。

### 7. 优点与亮点
*   **即插即用**：作为一个包装器，HELM 不需要对庞大的 VLA 骨干网络进行昂贵的重新训练或微调。
*   **预执行验证**：不同于事后反思（Post-hoc），SV 在错误发生前拦截，极大地保护了物理设备和任务状态。
*   **新评估协议**：提出的 LIBERO-Recovery 为机器人领域研究“鲁棒性”和“故障恢复”提供了标准化的工具。

### 8. 不足与局限
*   **数据依赖性**：SV 的训练虽然快，但仍需要针对特定环境收集约 5 万步的滚出数据，限制了完全的零样本迁移。
*   **回滚假设**：回滚机制假设动作是可逆的，虽然提出了前向恢复变体，但在极端不可逆（如物体破碎、液体倾倒）的情况下效果受限。
*   **仿真与现实差距**：所有实验均在仿真环境（LIBERO, CALVIN）中完成，现实世界中的传感器噪声和视觉偏移可能会影响 CLIP 检索和 SV 的准确性。
