## 摘要
系统生成的日志支撑着安全监控，然而其基于模板的僵化格式阻碍了自动化分析和人类理解。我们提出NLLog（自然语言日志），一种轻量级流水线，它确定性地将解析后的模板重写为“谁-做了什么-严重程度”的句子，通过词频-逆文档频率加权进行池化，使用树集成对会话进行分类，并利用TreeSHAP回溯证据供分析人员审查。在Hadoop分布式文件系统（HDFS）和Blue Gene/L（BGL）语料库上，NLLog超越了两种复现的匹配协议基线；在HDFS、BGL和AIT警报数据集上，它保持了较低的误报率，且延迟适合安全运营中心的分类处理。覆盖度、稀疏与密集、忠实性和对抗性消融实验表明，回退充分性依赖于语料库，注册时的覆盖度检查可以在部署前揭示优化需求，且可审计的确定性重写结合轻量级密集编码为日志异常检测和分类提供了一个可衡量的表示层。

## Abstract
System-generated logs underpin security monitoring, yet their rigid template-based format hinders both automated analysis and human comprehension. We present NLLog (Natural-Language Log), a lightweight pipeline that deterministically rewrites parsed templates into WHO-WHAT-SEVERITY sentences, pools them with term-frequency-inverse-document-frequency weighting, classifies sessions with tree ensembles, and back-projects evidence with TreeSHAP for analyst review. On Hadoop Distributed File System (HDFS) and Blue Gene/L (BGL) corpora, NLLog exceeds two reproduced matched-protocol baselines; across HDFS, BGL, and the AIT Alert Data Set, it sustains low false-positive rates with commodity-hardware latency suitable for security operations center triage. Coverage, sparse-versus-dense, faithfulness, and adversarial ablations show that fallback sufficiency is corpus-dependent, that an enrollment-time coverage check can surface refinement requirements before deployment, and that an auditable deterministic rewrite combined with lightweight dense encoding provides a measurable representation layer for log-anomaly detection and triage.

#### 1. 核心问题与整体含义
- **问题**：安全运营中心（SOC）每天处理数百万条系统日志，日志采用僵化的模板格式（如“E23”），缺乏语义信息，既不利于自动化分析，也加重了分析师的告警疲劳。
- **目标**：设计一种**轻量级、可解释**的日志异常检测方法，通过**确定性重写**将模板日志转化为自然语言句子，在不引入大模型微调或GPU依赖的前提下提升检测性能并输出可归因的证据。

#### 2. 方法论
- **核心思想**：将日志解析后**确定性地重写**为“谁-做了什么-严重程度”（WHO–WHAT–SEVERITY, WWS）句子，使用冻结的句子编码器嵌入，通过TF-IDF加权池化生成会话向量，最后用树集成分类器检测异常，并以TreeSHAP将决策归因回句子级。
- **关键技术细节**：
  - **日志规范化**：用正则替换敏感/高基数标记（IP、端口、块ID等）。
  - **WWS生成**：基于Drain3模板，提取组件（WHO）、动词-宾语（WHAT）和日志级别（SEV），拼接成自然语句；未知模板回退为“WHO + raw + SEV”。
  - **嵌入与池化**：冻结的MiniLM-L6（22M参数）编码每个句子，mean pooling得384维向量；然后对同一会话内的所有句子按TF-IDF权重加权平均（公式2-3），抑制重复状态日志、突出稀有事件。

  - **可解释性**：TreeSHAP计算每个特征维度的Shapley值（公式4），再通过责任矩阵（公式5）投影回句子，得到每个句子的贡献度ψji（公式6），供分析师查看Top-k证据。

#### 7. 优点
- **设计亮点**：
  - **确定性重写**：无需微调或prompt，可审计、可重复。
  - **可解释管线**：从分类到句子级归因保持透明，适合SOC分析师。
  - **轻量级**：纯CPU、低延迟、低内存，适合资源受限环境。
  - **诊断性实验丰富**：覆盖度、稀疏vs密集、忠实性、对抗性等多维度分析，科学严谨。

#### 8. 不足与局限
- **实验覆盖**：
  - 时序漂移至评估仅AIT-ADS（HDFS/BGL未做）；忠实性测试未覆盖AIT-ADS。
  - 会话化参数仅对AIT-ADS做敏感性扫描。
- **威胁模型限制**：
  - 不防御日志篡改、模板注入、日志静默；假设日志基础设施可信。

  - 依赖于Drain3模板解析，新模板可能被降级为回退表示。
- **缺少用户实证**：分析人员对解释效用的感知未通过控制实验验证。
