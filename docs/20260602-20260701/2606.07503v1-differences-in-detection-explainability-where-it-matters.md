## 摘要
我们提出了“检测中的差异”（Differences in Detection, DnD）方法，这是一种直观比较两个目标检测模型的方法。基于相同的匹配算法，它通过直接比较两个模型的能力，补充了均值平均精度（$mAP$）和TIDE误差分析等标准指标。具体来说，我们计算两个模型都识别出的真实标注标签的交集，以及对应的差集和两个模型都漏检的真实标注标签的补集。这种比较比独立汇总统计量的比较更加直接和直观。它揭示了个体和共同错误，当与错误类型结合时尤其有趣。在这种情况下，可以在标准混淆矩阵中自然地分析检测错误的差异。虽然DnD本身很有价值，但我们认为其最佳应用之一是引导诸如ODAM等可解释性方法，使其关注基于结构化子集的与指标相关的示例。我们方法的代码可在此处获取：https://github.com/JohannesTheo/differences-in-detection

## Abstract
We propose Differences in Detection (DnD), an intuitive method to compare two object detection models. Based on the same matching algorithm, it complements the standard metrics of mean Average Precision ($mAP$) and TIDE error analysis with the ability to compare two models directly. More specifically, we calculate the intersection of ground truth labels that are recognized by both models, followed by the corresponding difference sets and the complement set of ground truth labels that are missed by both models. The resulting comparison is more direct and intuitive than a comparison of independent summary statistics. It reveals individual and shared mistakes and becomes particularly interesting when combined with error types. In this case, the differences in detection errors can be analyzed naturally in a standard confusion matrix. While valuable in itself, we believe that one of the best applications of DnD is to guide explainability methods such as ODAM towards metric-relevant examples, grounded in structured subsets. The code for our method is available here: https://github.com/JohannesTheo/differences-in-detection

## 1. 核心问题与整体含义（研究动机和背景）

目标检测模型的性能对比通常依赖 **mAP**（均值平均精度）和 **TIDE** 误差分析等汇总统计指标。然而，这些指标只能独立评估每个模型的表现，无法回答如下问题：  
- 两个模型是否识别了**相同**的物体实例？  
- 它们的错误模式是**相似**还是**不同**？  
- 能否直观地看到模型间**共享错误**和**独有错误**？  

论文指出，这种“黑盒”比较方式既不直观，也缺乏实例级别的深入洞察。因此，作者提出 **DnD（检测中的差异）** 方法，旨在**直接比较两个目标检测模型的预测结果**，揭示它们之间的共性差异，并以此为可解释性方法（如 ODAM）提供结构化、指标相关的子集，从而提升模型分析的针对性。

## 2. 方法论：核心思想与关键技术细节

### 核心思想
基于与 mAP 相同的**匹配算法**，将两个模型（M1、M2）对同一数据集（真值标签集 GT）的预测结果进行对齐，然后计算它们共同匹配的、各自独有的以及共同遗漏的真值标签子集。

### 关键技术细节

1. **匹配过程**：对每个模型分别计算预测框与真值框的 IoU，并按照 mAP 标准匹配为正/负样本。  
2. **定义四个主要子集**（图 1 所示）：  
   - **B = D1 ∩ D2**：两个模型都检测到的真值标签（交集）。  
   - **M1 = D1 − B**：仅 M1 检测到的真值标签。  
   - **M2 = D2 − B**：仅 M2 检测到的真值标签。  
   - **N = GT − (D1 ∪ D2)**：两个模型都未检测到的真值标签（补集）。  

3. **错误类型编码**：对未匹配的真值标签，利用 **TIDE 错误分析**（表 1）为其分配错误类别（如 Cls、Loc、Both、Miss）。  
   - 仅考虑属于假阴性（FN）的错误类型；对假阳性（FP）错误暂不处理。  
4. **直接比较的混淆矩阵**：将 M1 和 M2 的独有错误集 **Ex1** 和 **Ex2** 分别统计错误类型，同时将共享未检测集 N 中的错误类型按两模型组合构建 **3×3 的混淆矩阵**（图 3 下方表格）。  

### 算法流程（文字说明）
1. 输入两个模型在测试集上的预测结果（边界框、置信度、类别）。  
2. 对每个模型分别执行 mAP 匹配，得到预测-真值匹配对。  
3. 基于相同的真值索引，计算 B、M1、M2、N。  
4. 对 N 中的每个未匹配真值及其它未匹配实例，查询其 TIDE 错误类型（表 1 中的 Oracle 操作）。  
5. 统计 Ex1 = M2（M1 的个体错误）、Ex2 = M1（M2 的个体错误）以及 N 中的错误分布，形成混淆矩阵。  
6. 利用这些子集（尤其是个体错误集）引导可解释性方法（如 ODAM）生成热力图进行实例分析。

- DnD 能够**直观展示**两个模型之间共享和独有检测结果（图 3、图 6），并发现即使一个模型整体性能更强（如 ConvNext-v2 的 mAP 更高），另一个模型也能检测到其遗漏的实例（ViTDet 的 M2 集非空）。

## 7. 优点

- **直观性**：从真值标签的匹配角度进行直接比较，比独立统计量更符合人类直觉。  
- **兼容性**：基于与 mAP 相同的匹配逻辑，易于集成到现有评估流程。  
- **结构化子集**：产生的子集（个体错误、共享错误）有明确的数学定义，便于后续分析。  
- **深度分析**：结合 TIDE 错误类型，将错误模式映射到混淆矩阵，实现细粒度的模型比较。  
- **引导可解释性**：能够自动筛选出对指标最有影响的实例，避免人工在海量预测中盲目搜索，提升可解释性分析的效率。

## 8. 不足与局限

- **仅支持两两比较**：当前方法只适用于两个模型，扩展至多模型需要链式对比，不够高效。  
- **仅考虑真值视角**：DnD 基于真值标签定义，未纳入假正预测（FP）的直接比较（如两个模型各自产生的多余检测），导致无法全面反映 mAP 中的假正影响。  
- **假正处理不完善**：虽然通过 TIDE 的 Dupe、Bkg 等错误类型涉及假正，但 DnD 未直接定义正预测间的差异。  
- **实验覆盖面有限**：仅在 MS-COCO 上验证，缺乏多种域迁移、不同架构、不同训练策略的广泛比较。  
- **未讨论计算开销**：文中未提及 DnD 的计算时间与复杂度，但匹配和错误分类通常可高效实现。  
- **潜在偏差**：匹配阈值（IoU=0.5）的选择影响子集定义，但论文仅在单一阈值下展示结果；对不同阈值敏感性的分析缺失。
