## 摘要
基于点云的3D目标检测器的结构脆弱性仍鲜为人知。以往工作主要在孤立的3D目标模型上研究对抗鲁棒性，而最近的LiDAR欺骗攻击针对更丰富真实驾驶场景，但主要关注物理可实现性而非理解检测器行为或攻击效率。在这项工作中，我们研究基于LiDAR的检测器如何在复杂场景中依赖空间证据，以及这些依赖模式是否可以被利用以更高效地诱发失败。为此，我们提出了一种可解释性引导的对抗分析方法。我们引入Saliency-LiDAR (SALL)方法，它跨场景聚合集成梯度属性，为基于LiDAR的3D目标检测器生成通用显著性图。在这些图的指导下，我们设计了可解释性感知的视锥攻击 (EFA)，该攻击选择性地仅扰动最具影响力的视锥，而非均匀攻击整个目标区域。在KITTI和nuScenes上，针对PointPillars和SECOND等检测器的实验表明，EFA将检测召回率降低超过15个百分点，同时比最先进的非显著性感知基线所需的扰动视锥减少25%-50%。这些发现揭示了现代3D检测器将判别性证据集中在空间区域的小子集上，暴露了当前LiDAR感知系统中的结构性鲁棒性漏洞。我们的代码发布在https://github.com/SecMindLab/Saliency_LiDAR。

## Abstract
The structural vulnerabilities of point cloud-based 3D object detectors remain poorly understood. Prior work has studied adversarial robustness primarily on isolated 3D object models, while recent LiDAR spoofing attacks target richer and more realistic driving scenes but focus mainly on physical realizability rather than understanding detector behavior or attack efficiency. In this work, we investigate how LiDAR-based detectors rely on spatial evidence in complex scenes and whether these reliance patterns can be exploited to induce failures more efficiently. To this end, we propose an explainability-guided adversarial analysis methodology. We introduce the Saliency-LiDAR (SALL) method, which aggregates Integrated Gradient attributions across scenes to produce universal saliency maps for LiDAR-based 3D object detectors. Guided by these maps, we design the Explainability-aware Frustum Attack (EFA), which selectively perturbs only the most influential frustums rather than uniformly attacking entire object regions. Experiments on KITTI and nuScenes, across detectors such as PointPillars and SECOND, show that EFA reduces detection recall by more than 15 percentage points while requiring 25-50% fewer perturbed frustums than the state-of-the-art non-saliency-aware baseline. These findings reveal that modern 3D detectors concentrate discriminative evidence in a small subset of spatial regions, exposing a structural robustness vulnerability in current LiDAR perception systems. Our code is released at https://github.com/SecMindLab/Saliency_LiDAR.

- **含义**：本文首次将可解释性（显著性分析）引入 LiDAR 3D 目标检测的对抗攻击，旨在揭示检测器在复杂驾驶场景中是否将判别证据集中在少数关键空间区域，并利用这一结构特点设计更高效的攻击。

## 2. 方法论
### 核心思想
提出 **SALL（Saliency-LiDAR）** 框架，通过聚合多个场景中实例级别的集成梯度（Integrated Gradient, IG）属性，生成类别级别的通用显著性图。然后基于该显著性图，设计 **EFA（Explainability-aware Frustum Attack）** 攻击，**仅扰动显著性最高（最关键）的视锥**，而非均匀攻击整个目标包围盒区域。

### 关键技术细节
- **SALL 生成显著性图**：
  1. **预处理**：从原始 LiDAR 场景中提取目标物体点云和背景点。
  2. **集成梯度计算**：对每个目标点云，沿射线方向逐步移动点到指定基点（如 LiDAR 原点或包围盒最近角点），在 M 步（本文设为 25）后，将扰动点云与背景合并，输入检测器得到梯度，经 IoU 过滤保留目标预测的梯度，积分得到点级贡献图。
  3. **自适应索引**：将点级贡献图通过自适应体素化（2D 索引，尺寸 64×32）转为像素级别的矩阵。
  4. **聚合**：对同一物体类别，跨场景（数千个场景）简单相加所有矩阵，得到通用显著性图。

- **EFA 攻击流程**：
  1. **提取**：从场景中分离背景和目标点云。
  2. **2D 索引**：将目标点云转换为柱状（pillar）格式的 2D 索引。
  3. **视锥模拟**：根据 LiDAR 原点计算每个点的水平角度，按度数 D_step=1° 划分视锥。
  4. **视锥选择**：使用 **Critical Frustum First** 策略，根据 SALL 显著性图选择最关键的那些视锥。
  5. **视锥扰动**：支持 **移除（Remove）** 或 **移位（Shift）** 扰动，沿 LiDAR 射线方向调整点位置或直接删除。
  6. **合并**：扰动后的目标点云与背景合并，形成对抗场景。

## 3. 实验设计
- **数据集**：KITTI（7481 个训练验证场景）、nuScenes（34149 个样本）。
- **目标物体**：主要聚焦 Car（距离 5 m–8 m），也包含 Pedestrian（距离 0 m–20 m）。
- **检测器**：PointPillars、SECOND（两个主流且代表性的 LiDAR 3D 检测器）。
- **对比方法**：
  - **PRA**（Cao et al., USENIX Security 2023）：视锥移除攻击。
  - **HFR**（Sato et al., NDSS 2024）：视锥移位攻击。
  - **A-HFR**（Sato et al., NDSS 2025）：视锥移除攻击，附带被移除点比例。
  - 点级攻击对比 ORA（Hau et al., AutoSec 2021）。
- **评估指标**：检测召回率（Recall）和攻击成功率（ASR，隐藏物体的比例）。

## 4. 资源与算力
- **文中说明**：离线显著性图生成在单张 **12 GB NVIDIA TITAN Xp GPU** 上运行。具体耗时：预处理 3.8 ms、IG 计算 51.79 s、自适应索引 14 ms、聚合 3.5 ms。在线视锥选择开销极低（显著性图仅 5.8 KB（Car）或 0.3 KB（Pedestrian））。
- **未明确说明**：训练检测器本身需要的 GPU 数量、总训练时长等未提及。

## 5. 实验数量与充分性
- **实验类别**：
  - 鲁棒性分析：不同攻击策略（Critical vs. Random 选择、Remove vs. Shift 扰动）、不同距离（5 m–26 m）、不同 IoU 阈值、检测器内部参数（置信度、IoU）。
  - 主实验：在 KITTI 和 nuScenes 上对比 EFA（Critical Frustum First）与基线（HFR、PRA、A-HFR）的 ASR 随扰动视锥数变化。
  - 小目标：Pedestrian 在 KITTI 上的攻击成功率和视锥效率。
  - 迁移性：跨模型（PointPillars → SECOND）、跨数据集（KITTI → nuScenes）。
  - 点级攻击延伸：与 ORA 对比。
  - 物理可行性：加入 LiDAR 欺骗误差（角度偏移）和速度相关的点移除约束。
  - 消融实验：物体提取偏置（航向偏移、位置偏移）、2D 索引偏移、正/负贡献对比、IG 步数、基点选择。
- **充分性评价**：实验覆盖全面，设计合理，对比公平（均采用相同视锥角度 30° 和扰动约束），定量结果清晰。但缺乏多种更先进的检测器（如 CenterPoint、PV-RCNN）以及多模态融合系统的验证，也未进行统计显著性检验。

## 6. 主要结论与发现
- **核心发现**：现代 LiDAR 3D 检测器（PointPillars、SECOND）将判别性证据高度集中在少数空间区域（如物体边缘、角点），形成结构鲁棒性漏洞。
- **攻击效果**：在 KITTI/nuScenes 上，EFA 使用 **10–15 个视锥** 即可达到 95% 以上的 ASR，比基线（HFR、PRA）**扰动视锥数减少 25%–50%**，同时 ASR 提升 20%–30%（大物体）或约 23%（小物体 Pedestrian）。
- **迁移性**：SALL 显著性图可在不同检测器之间（PointPillars → SECOND）以及不同数据集之间（KITTI → nuScenes）有效迁移，联合显著性图进一步强化攻击。
- **物理可行性**：在 5° 的视锥选择误差下仍保持 >94% ASR；在速度高导致点可操作数少的约束下，SALL 引导的 A-HFR 比原始 A-HFR 提升约 25% 成功率。

## 7. 优点
- **方法创新**：首次将可解释性（集成梯度）系统性地引入 LiDAR 3D 检测对抗攻击，从单分类器扩展到复杂驾驶场景检测；提出通用显著性图聚合机制，显著降低攻击成本。
- **效率与效果平衡**：通过只扰动极少关键视锥，在物理层面降低硬件过热风险，同时保持甚至超越全视锥攻击的效果。
- **实验严谨**：包含跨模型、跨数据集迁移性验证、物理误差仿真、速度约束测试，以及对不同攻击组件（选择策略、扰动类型、正负贡献）的消融，结论可信度高。
- **开源**：提供代码，可复现。

## 8. 不足与局限
- **检测器覆盖有限**：仅测试 PointPillars 和 SECOND，未涉及更现代的 CenterPoint、PV-RCNN 或 Transformer 类检测器，也未评估多传感器融合（如 Camera-LiDAR）系统。
- **场景限制**：主要分析前向近距离（5–8 m）的 Car 和小范围 Pedestrian，未充分考察远距离、侧面、遮挡严重或多物体密集交互场景下的攻击效果。
- **防御分析薄弱**：仅测试了随机丢弃视锥的简单基线，且效果有限（需丢弃 1/3 视锥才能降低 ASR 约 40%），未提出具体可部署的防御措施。
- **物理攻击假设**：前提是攻击者能精确控制点在射线上移位/删除，这依赖于先进 LiDAR 欺骗硬件（如 HFR 实现）；实际中可能会受环境噪声、多机干扰等影响，文中虽加了误差测试，但未做真实物理部署实验。
- **统计稳健性缺失**：未报告多次运行的标准差或置信区间，也难以排除数据集特定偏差。
