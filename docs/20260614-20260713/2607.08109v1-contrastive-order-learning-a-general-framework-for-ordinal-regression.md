## 摘要
我们提出了对比顺序学习（ConOrd），一种用于序数回归的对比学习框架，它整合了对比学习和顺序学习的优势。对比学习有效地利用了批次中的所有样本，但通常忽略排序标签之间的内在顺序。相反，顺序学习显式地建模标签的序数性，但通常依赖于基于边界的局部比较，限制了其捕捉全局序数结构的能力。ConOrd通过引入基于排序差异的软亲和力和差异权重的对比顺序损失来解决这些限制，从而能够在批次内的所有样本对之间实现细粒度的序数关系建模。在包括人脸年龄估计、盲图像质量评估和盲视频质量评估等一系列序数回归任务上的广泛实验表明，ConOrd始终达到最先进的性能，并在各种序数回归场景中具有良好的泛化能力。源代码可在 https://github.com/cwlee00/ConOrd 获取。

## Abstract
We propose contrastive order learning (ConOrd), a contrastive learning framework for ordinal regression that integrates the strengths of contrastive learning and order learning. While contrastive learning effectively leverages all samples in a batch, it typically ignores the inherent ordering among rank labels. Conversely, order learning explicitly models label ordinality but often relies on local, margin-based comparisons, limiting its ability to capture global ordinal structure. ConOrd addresses these limitations by introducing a contrastive order loss with soft affinity and disparity weights based on rank differences, enabling fine-grained modeling of ordinal relationships across all sample pairs within a batch. Extensive experiments on a range of ordinal regression tasks, including facial age estimation, blind image quality assessment, and blind video quality assessment, demonstrate that ConOrd consistently achieves state-of-the-art performance and generalizes well across diverse ordinal regression scenarios. The source code is available at https://github.com/cwlee00/ConOrd.

## 1. 论文的核心问题与整体含义（研究动机和背景）

序数回归（Ordinal Regression）旨在预测具有内在顺序但相邻等级界限模糊的标签（如年龄、图像质量分数）。现有方法存在以下局限：
- **对比学习**（如SupCon）能有效利用批次内所有样本，但完全忽略标签的顺序属性，将序数任务当作分类来处理。
- **顺序学习**（如GOL）显式建模标签的序数性，但通常依赖局部、基于边界的成对比较，无法捕获全局的序数结构，且一旦满足margin就停止梯度，信息利用不充分。
- **Rank-N-Contrast (RnC)** 虽引入了序数感知，但采用硬阈值将序数距离二值化（正/负），忽略了距离的细粒度差异。

为此，论文提出**对比顺序学习（ConOrd）**框架，统一对比学习和顺序学习的优势，在批次级别的表示学习中融入软序数权重，实现全局一致的序数嵌入空间。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
ConOrd通过设计**对比顺序损失（Contrastive Order Loss）**，对批次内所有样本对赋予基于秩差异的软亲和权重（affinity weight）和软差异权重（disparity weight），实现**软序数对比**，使相似秩的样本相互吸引、差异大的样本相互排斥，且权重随秩差距平滑变化。

### 关键技术细节

1. **问题定义**  
   给定实例\(x\)，编码器\(h\)输出\(\ell_2\)归一化的特征向量\(z = h(x)\)。训练集有\(M\)个不同秩，引入\(M\)个可学习参考点\(\{\mu_m\}\)作为每个秩的原型。

2. **对比顺序损失**  
   \[
   L_{\text{ConOrd}} = -\frac{1}{2N} \sum_{i=1}^{2N} \frac{1}{|A(i)|} \log \frac{\sum_{j \in A(i)} a_{ij} e^{\kappa_{ij}/\tau}}{\sum_{j \in A(i)} b_{ij} e^{\kappa_{ij}/\tau}}
   \]
   其中：
   - \(\kappa_{ij} = -\|z_i - z_j\|_2^2\)（负平方欧氏距离）
   - \(a_{ij} = 1/((r_i - r_j)^2 + \epsilon)\)：亲和权重，随秩差增大而减小
   - \(b_{ij} = (r_i - r_j)^2\)：差异权重，随秩差增大而增大
   - \(\tau\)：温度参数
   - \(A(i) = I \setminus \{i\}\)：批次中除锚点外的所有样本

3. **梯度特性**  
   梯度分析（附录A）显示，每个成对贡献由因子\(\left(\frac{a_{ij}}{\alpha_i} - \frac{b_{ij}}{\beta_i}\right)\)控制，其中\(\alpha_i, \beta_i\)为归一化项。由于\(a_{ij}\)小秩差时大、\(b_{ij}\)大秩差时大，该因子导致相似秩样本吸引、差异大样本排斥。同时，指数核\(e^{\kappa_{ij}/\tau}\)使得只有嵌入空间中已经接近的样本对获得较大权重，实现细粒度局部调整。

4. **总体训练损失**  
   \[
   L_{\text{total}} = L_{\text{ConOrd}} + L_{\text{center}}, \quad L_{\text{center}} = \sum_i \|z_i - \mu_{r_i}\|_2
   \]
   中心损失使同一秩的实例在嵌入空间中聚集在对应参考点周围。

5. **推理**  
   使用k-NN规则：将测试实例嵌入与所有训练实例比较，取最近的\(k\)个邻居的秩的均值作为预测结果。

6. **与RnC的关系**  
   RnC使用硬阈值划分正负样本，而ConOrd通过软权重实现全样本对比，是RnC的软松弛版本，能捕获更精细的序数结构。
