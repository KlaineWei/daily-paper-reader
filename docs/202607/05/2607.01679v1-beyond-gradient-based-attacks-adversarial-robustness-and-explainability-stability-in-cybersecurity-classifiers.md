## 摘要
针对网络安全分类器的对抗攻击构成双重威胁：既降低预测性能，又破坏安全分析师赖以理解和分流告警的基于SHAP的解释的稳定性。我们将先前的MLP会议研究扩展至随机森林和XGBoost，涵盖四个表格安全数据集（钓鱼URL、UNSW-NB15、NF-ToN-IoT、HIKARI-2021），评估五种攻击方法，其中包括三种适用于不可微树模型的黑盒方法。我们引入了可解释性稳定性指数（ESI），该标量指标基于对抗扰动下的TreeSHAP归因漂移计算，并与鲁棒性指数（RI）采用相同的[0,1]尺度报告。关键发现是，由于分段常数预测面，基于梯度的黑盒攻击（ZOO）对XGBoost产生退化结果（表观RI约0.98），而基于分数的Square攻击则揭示了真实脆弱性（RI约0.36）。这些退化扰动仍会驱动显著的归因漂移：尽管ZOO攻击下鲁棒性近乎完美，XGBoost的ESI约为0.06-0.16，而随机森林的ESI为0.14-0.29，表明预测鲁棒性与解释稳定性是不同的维度，需联合测量。一个双轴框架（梯度依赖性、查询效率）解释了观察到的攻击排名，并为树集成评估提供了实用指导。此外，步长消融实验解释了在z分数归一化表格数据上出现的反直觉PGD异常。

## Abstract
Adversarial attacks on cybersecurity classifiers pose a dual threat: degrading predictions and destabilising the SHAP-based explanations that security analysts rely on to understand and triage alerts. We extend our prior MLP conference study to Random Forest and XGBoost across four tabular security datasets (phishing URLs, UNSW-NB15, NF-ToN-IoT, HIKARI-2021), evaluating five attacks including three black-box methods applicable to non-differentiable tree models. We introduce the Explainability Stability Index (ESI), a scalar metric computed from TreeSHAP attribution drift under adversarial perturbation, reported on the same [0,1] scale as the Robustness Index (RI). A key finding is that gradient-based black-box attacks (ZOO) produce degenerate results against XGBoost (apparent RI ~0.98) due to piecewise-constant prediction surfaces, while score-based Square Attack reveals genuine vulnerability (RI ~0.36). These degenerate perturbations still drive substantial attribution drift: XGBoost ESI ~0.06-0.16 despite near-perfect ZOO robustness, versus 0.14-0.29 for RF, showing that prediction robustness and explanation stability are distinct axes requiring joint measurement. A two-axis framework (gradient dependence, query efficiency) explains the observed attack ranking and yields practical guidance for tree ensemble evaluation. A step-size ablation explains a counterintuitive PGD anomaly on z-score normalised tabular data.

## 2. 论文提出的方法论

### 核心思想
- 将对抗鲁棒性（RI）与解释稳定性（ESI）视为两个需要独立测量的维度，提出联合评估框架。
- 通过**双轴框架（梯度依赖性、查询效率）** 解释不同攻击在树模型上的效果差异，为评估提供指导。

### 关键技术细节
- **鲁棒性指数（RI）**：  
  \[
  RI = \frac{1}{\varepsilon_{\max}} \int_0^{\varepsilon_{\max}} \text{Acc}(\varepsilon) d\varepsilon
  \]  
  其中 \(\text{Acc}(\varepsilon)\) 是给定扰动预算 \(\varepsilon\) 下的分类准确率，积分用梯形法近似，值域[0,1]，越高越鲁棒。

- **可解释性稳定性指数（ESI）**：  
  \[
  \Delta \Phi_i(\varepsilon) = E[|\phi_i(x_{\text{adv}}) - \phi_i(x)|]
  \]  
  \[
  \bar{D}(\varepsilon) = \frac{1}{d} \sum_i \Delta \Phi_i(\varepsilon)
  \]  
  \[
  ESI = 1 - \frac{1}{\varepsilon_{\max}} \int_0^{\varepsilon_{\max}} \frac{\bar{D}(\varepsilon)}{\bar{D}(\varepsilon_{\max})} d\varepsilon
  \]  
  对树模型使用TreeSHAP（干预期望变体），MLP使用KernelSHAP。ESI在[0,1]，越高表示解释越稳定。

### 攻击方法
- **白盒攻击**：FGSM、PGD（针对MLP）
- **黑盒攻击**（针对树模型）：
  - ZOO：基于有限差分的梯度估计 → 对XGBoost的分段常数预测面产生退化。
  - Square Attack：基于分数的随机搜索，无需梯度。
  - HopSkipJump：仅需硬标签，通过二分搜索和蒙特卡洛梯度估计。

### 双轴框架
- **梯度依赖性**：决定攻击是否受模型平滑性影响（ZOO对XGBoost失效，Square和HSJ不受影响）。
- **查询效率**：在高维空间中，随机搜索（Square）优于边界搜索（HSJ）。

## 6. 论文的主要结论与发现

1. **ZOO对XGBoost产生退化伪鲁棒性**：由于分段常数预测面，有限差分梯度估计近零，导致RI虚假地高（~0.98），而Square攻击揭示真实脆弱性（RI~0.36）。此现象在所有4个数据集上一致（平均间隙0.54-0.58，种子间标准差≤0.035）。
2. **预测鲁棒性与解释稳定性解耦**：即使ZOO扰动无法改变XGBoost预测（RI≈0.98），仍引起大量归因漂移（ESI≈0.06-0.16），而随机森林的ESI更高（0.14-0.29）。说明“抗攻击预测”不等于“抗攻击解释”。
3. **PGD步长敏感异常**：默认步长α=0.01时PGD弱于FGSM，增大步长至α≥0.05后PGD超越FGSM。原因是小步长被L∞投影截断，无法累积有效梯度。
4. **双轴框架实用指导**：
   - 树集成模型应以Square Attack为主要基准；
   - MLP使用自适应步长PGD或FGSM；
   - 报告RI时应同时给出最强攻击和ZOO（量化退化间隙）。
5. **Square对抗训练有效**：对XGBoost（Phishing数据集）Square RI从0.372提升至0.755，干净准确率几乎不变。但对已有中等鲁棒性的RF可能过度增强导致退化。

1. **提出新的度量ESI**：填补了对抗攻击下解释稳定性量化空白，且与RI同尺度便于联合评估。
2. **覆盖多种模型与攻击**：MLP、RF、XGBoost；白盒+黑盒共5种攻击，为表格安全数据提供全面基准。

4. **异常现象消融实验**：清晰解释了PGD < FGSM的成因，为后续研究提供实践建议（自适应步长）。
5. **攻击选择双轴框架**：简洁实用，有助于研究人员理解不同攻击在树模型上的适用性。

## 8. 不足与局限

### 实验覆盖与偏差风险
- **特征有效性约束**：所有攻击采用无约束的ℓ∞扰动，未考虑安全领域特征间的依赖关系（如NetFlow中字节数与包数的物理约束），导致鲁棒性估计偏乐观。
- **数据集局限性**：未覆盖静态恶意软件分类、主机入侵检测等任务，且NF-ToN-IoT、HIKARI-2021干净准确率过高（~0.998），可能高估了对抗难度。
- **计算资源限制**：仅CPU运行，攻击查询预算受限（HSJ仅120样本），可能低估了HSJ的真实强度。
- **方差与统计显著性**：尽管做了5种子评估，ESI的方差较大（如NF-ToN-IoT上RF-XGB差距不显著），部分结论（如RF > XGB的ESI排序）仅由数据集间定性模式支撑，而非严格的统计检验。

### 方法局限
- **ESI归一化问题**：当不同模型SHAP值尺度差异大时（如HIKARI-2021上XGBoost绝对漂移大但增长平缓），归一化后ESI可能高于绝对漂移小的模型，误导排序。作者已指出需结合绝对幅度解读。
- **未对比其他解释方法**：仅使用SHAP（TreeSHAP/KernelSHAP），未扩展至LIME、Grad-CAM等。
- **对抗训练局限性**：Square对抗训练中εmax固定为0.3，对于已有中等鲁棒性的模型（RF on Phishing）导致性能下降，提示需交叉验证ε。
- **无防御机制探讨**：仅初步尝试了数据增强，未涉及特征有效性投影、集成多样性、对抗净化等更复杂防御。

### 应用限制
- 本文的威胁模型是逃避攻击（evasion），不包括投毒或模型提取。
- 结果适用于z-score归一化的表格数据，对其他特征标准化方法可能不直接适用。
