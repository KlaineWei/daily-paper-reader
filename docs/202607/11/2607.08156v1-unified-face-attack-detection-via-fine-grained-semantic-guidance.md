## 摘要
人脸识别系统的广泛应用伴随着日益多样化的安全威胁。现有数据集缺乏伪造线索的详细文本描述，导致大多数先前方法主要将人脸攻击检测视为视觉识别任务。在本文中，基于包含超过800万张攻击图像的大规模MS-UFAD数据集，我们为每张图像丰富了伪造线索的细粒度文本描述。此外，我们提出了一种双对齐伪造网络（DAF-Net）以更好地利用这些文本信息。大量实验表明，我们的方法从攻击图像中提取了更具泛化性和语义意义的伪造表示，优于纯视觉方法和基于粗粒度描述的方法。

## Abstract
The growing applications of facial recognition systems are accompanied by increasingly diverse security threats. Existing datasets lack detailed textual descriptions of forgery cues, leading most prior methods to treat face attack detection primarily as a visual recognition task. In this paper, building upon the large-scale MS-UFAD dataset which contains over 8 million attack images, we enrich each image with a fine-grained textual description of forgery cues. Furthermore, we propose a Dual Alignment Forgery Network(DAF-Net) to better leverage these textual information. Extensive experiments demonstrate that our approach extracts more generalizable and semantically meaningful forgery representations from attack images, outperforming both vision-only methods and approaches based on coarse-grained descriptions.

## 2. 论文提出的方法论

- **核心思想**：在现有大规模人脸攻击数据集MS-UFAD（含800万+攻击图像）的基础上，为每张图像补充细粒度的文本描述，描述图像中具体的伪造痕迹（如嘴部异常平滑、眼部轮廓不自然等）。然后设计双模态对齐网络（DAF-Net），利用文本信息引导视觉特征学习，训练时使用图像-文本对，推理时仅需视觉分支。
- **关键技术细节**：
  - **文本描述生成流程**：使用预训练的人脸攻击检测模型 + ScoreCAM定位篡改区域；计算量化差异（颜色、模糊度）；构建不同攻击类型的 artifact corpus；利用 MLLM（InternVL3）生成连贯的自然语言描述，克服 MLLM 的幻觉问题。
  - **DAF-Net 架构**：基于 BLIP 的视觉/文本编码器，分别输出 patch/token 特征。每个分支后插入语义伪造聚合模块（SFAM），通过 N 个可学习查询向量与视觉 patch 或文本 token 进行交叉注意力，将离散视觉区域/文本片段聚合为 N 个语义意义的伪造区域/短语。最后使用 LSE 池化得到全局特征，送入分类器。
  - **双对齐损失**：
    - 全局对齐：采用对比损失，对齐全局视觉和文本表示。
    - 细粒度对齐：对 SFAM 输出的区域/短语特征计算 token-wise 相似度，再用 triplet loss 进行正负样本对齐（hard negative mining）。
  - **总损失**：分类损失 + λ(全局对齐损失 + 细粒度对齐损失)。
- **公式/算法流程**（文字说明）：
  1. 输入：攻击图像 I，对应文本描述 T。
  2. 视觉编码器 Ev(I) → 视觉 patch 特征；文本编码器 Et(T) → 文本 token 特征。
  3. 视觉 SFAM：用 N 个可学习查询与 patch 特征交叉注意力 → 视觉区域特征 V。
  4. 文本 SFAM：同样处理 → 文本短语特征 Z。
  5. LSE 池化得到全局视觉 v 和文本 z。
  6. 分类损失 Lce(v,y) + Lce(z,y)。
  7. 全局对齐损失 Lglobal（对比损失）与细粒度对齐损失 Lfine（triplet loss）。
  8. 总损失 L = Lcls + λ(Lglobal + Lfine)。

## 6. 论文的主要结论与发现

- 细粒度文本描述显著提升人脸攻击检测的性能，优于纯视觉方法和粗粒度文本方法。
- DAF-Net 通过双模态对齐和 SFAM 模块，能够有效利用细粒度语义，学习到更具泛化性和语义可解释性的伪造表示。

- 视觉和文本 SFAM 需同时使用（去除任一导致粒度不匹配，性能更差）。
