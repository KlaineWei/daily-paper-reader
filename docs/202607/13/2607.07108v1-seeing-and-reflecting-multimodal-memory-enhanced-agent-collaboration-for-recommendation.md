## 摘要
基于大语言模型的智能体推荐系统通过自然语言推理在用户偏好建模方面展现出潜力，但其仍受限于以文本为中心的输入和粗粒度的记忆更新，导致智能体容易遗漏视觉证据、受语义噪声干扰且难以捕捉偏好漂移。为克服这些局限，我们提出MMEACR——一种面向推荐的多模态记忆增强智能体协作框架。MMEACR引入双轨道记忆架构，将可解释的智能体推理与细粒度多模态匹配分离。在推理轨道中，协作式用户与项目记忆智能体维护持久的多模态记忆，并通过属性引导的强化与反思机制进行更新。在匹配轨道中，从原始交互叙事和项目图像构建解耦的多模态嵌入记忆，以保留结构化记忆更新之外的详细跨模态信号。双轨道通过加权倒数秩融合进行整合，生成鲁棒且可解释的排序结果。在三个真实世界领域的实验表明，MMEACR在基于LLM和基于智能体的强基线方法中取得了优异的整体性能，尤其在视觉引导推荐场景中表现显著提升。

## Abstract
Large language model (LLM)-based agentic recommender systems show promise in modeling user preferences through natural-language reasoning, yet they remain limited by text-centric inputs and coarse-grained memory updates, making agents prone to missing visual evidence, semantic noise, and preference drift. To address these limitations, we propose MMEACR, a Multimodal Memory-Enhanced Agent Collaboration framework for recommendation. MMEACR introduces a dual-track memory architecture that separates interpretable agent reasoning from fine-grained multimodal matching. In the reasoning track, collaborative User and Item Memory Agents maintain persistent multimodal memories and update them through an attribute-guided reinforcement-and-reflection mechanism. In the matching track, a decoupled multi-modal embedding memory is built from raw interaction narratives and item images to preserve detailed cross-modal signals beyond structured memory updates. The two tracks are integrated through weighted Reciprocal Rank Fusion to produce robust and interpretable rankings. Experiments on three real-world domains show that MMEACR achieves strong overall performance against competitive LLM-based and agent-based baselines, with notable gains in visually grounded recommendation scenarios.

## 2. 论文提出的方法论

### 核心思想：Seeing and Reflecting（看见与反思）
- **Seeing**：利用多模态大模型（MLLM）从项目图像和文本元数据生成图像描述，从而初始化项目的多模态记忆，使智能体“看见”视觉证据。
- **Reflecting**：通过属性引导的强化与反思机制，在用户-项目交互后，根据选择的正确性对记忆进行结构化更新，减少噪声并纠正偏好漂移。

### 关键技术细节
- **双轨架构**：
  - **推理轨道（Reasoning Track）**：
    - 用户记忆智能体（UA）和项目记忆智能体（IA）分别维护持续演化的语言记忆（描述性文本）。
    - 每个交互步骤构造三元组 \((u, i^+, i^-)\)，LLM 根据记忆选择更匹配的项目并生成推理理由 \(r^{(t)}\)。
    - 引入**属性引导的偏好提取**：利用预定义的语义属性空间 \(A\)（如风格、功能、外观），LLM 提取属性级信号 \(z^{(t)}\)，解释偏好差异。
    - 记忆更新采用条件分支：
      - 若选择正确 → 强化（reinforce）：确认偏好；
      - 若选择错误 → 反思（reflect）：修正错误记忆。
    - 同时，同步更新正/负项目的记忆，并维护原始交互叙事（raw narratives）供匹配轨道使用。
  - **匹配轨道（Matching Track）**：
    - 建立**多模态嵌入记忆**：使用预训练多模态嵌入模型（如GME）编码项目标题与图像，生成项目嵌入；对用户，聚合历史偏好项目的嵌入与原始叙事。
    - 通过余弦相似度计算用户-项目语义匹配得分，产生嵌入排名 \(\pi_{emb}\)。
  - **融合机制**：
    - 采用**加权倒数秩融合**（Weighted Reciprocal Rank Fusion, RRF）将推理排名 \(\pi_{des}\) 和嵌入排名 \(\pi_{emb}\) 融合：
      \[
      S_{RRF}(i) = w_{des} \frac{1}{k_{des} + \text{rank}_{\pi_{des}}(i)} + w_{emb} \frac{1}{k_{emb} + \text{rank}_{\pi_{emb}}(i)}
      \]
    - 最终按融合分数降序排列得到推荐列表。

### 算法流程（文字说明）
1. 初始化：为每个项目生成多模态记忆（文本+图像描述），为用户写入初始偏好模板。
2. 迭代训练：进行 T 轮交互，每轮从用户历史中构造一个正项和负项；LLM 选择后输出正确性标签，属性提取器获取属性信号；根据正确性调用强化或反思函数更新用户/项目记忆；同时追加原始叙事。
3. 测试：使用最新记忆对候选集分别进行推理排序和嵌入排序，通过 RRF 融合得到最终排名。
