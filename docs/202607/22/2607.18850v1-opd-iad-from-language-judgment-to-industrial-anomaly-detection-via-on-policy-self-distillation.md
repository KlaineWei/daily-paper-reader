## 摘要
大型视觉语言模型（LVLMs）近期通过提供图像级异常判断和可解释的缺陷推理，展现出在工业异常检测（IAD）中的强大潜力。然而，当前基于LVLM的IAD方法仍难以从生成的语言判断中产生精确的像素级异常图。我们的目标是实现精确的像素级定位，同时使用语言作为引导而非让其主导视觉响应。具体而言，我们提出了OPD-IAD，一种用于基于LVLM的IAD的基于证据特权的密集同策略自蒸馏框架。OPD-IAD将特权缺陷证据蒸馏到模型自身的同策略判断轨迹上，使得最终生成的判断能够在密集监督下学习，而不仅仅是作为文本答案处理。得到的判断作为密集异常感知的语义条件。为了将该条件转化为密集的视觉证据，我们引入了语言引导的视觉锚定，该方法使用判断前馈，在最终判断条件下将图像和问题重新编码为语义锚点，并通过对比热图头将它们与密集视觉特征进行对比，生成异常图。因此，语言判断提供了紧凑的语义引导，而密集视觉特征仍然是像素级评分的基础，使得语言能够引导异常定位，同时避免语言质量直接决定像素级响应。大量实验表明，OPD-IAD在基于LVLM的IAD方法中取得了最佳整体性能，在大多数图像级、像素级和QA指标上领先。

## Abstract
Large vision-language models (LVLMs) have recently shown strong potential for industrial anomaly detection (IAD) by providing image-level anomaly judgments and interpretable defect reasoning. However, current LVLM-based IAD methods still struggle to produce precise pixel-level anomaly maps from generated language judgments. We aim to achieve precise pixel-level localization while using language as guidance rather than letting it dominate the visual response. Specifically, we propose \textbf{OPD-IAD}, an evidence-privileged dense on-policy self-distillation framework for LVLM-based IAD. OPD-IAD distills privileged defect evidence onto the model's own on-policy judgment trajectory, enabling the final generated judgment to be learned under dense supervision rather than treated only as a textual answer. The resulting judgment serves as a semantic condition for dense anomaly perception. To turn this condition into dense visual evidence, we introduce \textbf{Language-guided Visual Anchoring}, which uses a judgment reforward to re-encode the image and question under the final-judgment condition into semantic anchors and contrasts them with dense visual features through a contrastive heatmap head to generate anomaly maps. The language judgment therefore provides compact semantic guidance, while dense visual features remain the basis for pixel-level scoring, allowing language to guide anomaly localization without letting language quality directly dictate the pixel-level response. Extensive experiments show that OPD-IAD achieves the best overall performance among LVLM-based IAD methods, leading on most image-level, pixel-level, and QA metrics.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：大型视觉语言模型（LVLMs）在工业异常检测（IAD）中虽然能提供图像级异常判断和可解释的缺陷推理，但难以从生成的语言判断中产生**精确的像素级异常图**。现有两类方法存在缺陷：
  - **解耦型**：语言判断不参与热图生成，语言能力未被充分利用。
  - **语言耦合型**：定位紧密依赖语言侧接口（如分割token、掩码文本、推理token注意力），导致定位对语言判断的准确性和稳定性敏感，不准确判断会抑制或破坏热图质量。
- **设计原则**：语言应提供**语义指导**，而像素级异常响应应根植于**密集视觉证据**，而非直接由生成文本决定。
- **训练挑战**：生成的判断由模型自身产生并用作定位的语义条件，其训练需满足两个要求：
  1. 监督必须施加于模型自身的生成轨迹（同策略，on-policy）。
  2. 监督应足够细粒度（dense token-level），而非仅最终答案奖励。
  现有SFT是离策略但密集，RLVR是同策略但稀疏，两者均不能同时满足。
- **整体含义**：提出OPD-IAD框架，通过证据特权密集同策略自蒸馏（evidence-privileged dense on-policy self-distillation）和语言引导视觉锚定（Language-guided Visual Anchoring），使语言判断成为定位的有效桥梁，且定位仍基于视觉特征。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：
  - 训练时，模型在仅有图像和问题的部署上下文（student context）中采样判断轨迹；同时在包含缺陷证据的特权上下文（teacher context）中对同一轨迹进行逐token重评分，提供密集自蒸馏目标，使模型在自身轨迹上学习。
  - 定位时，只保留最终判断（而不使用完整思维链），通过“判断前馈”（judgment reforward）将图像、问题和最终判断重新编码为异常/正常语义锚点，然后用对比热图头（contrastive heatmap head）将密集视觉特征与锚点对比，生成异常图。
- **关键技术细节**：
  - **证据特权同策略自蒸馏（Evidence-Privileged On-Policy Self-Distillation, OPSD）**：
    - 学生采样：\(\hat{y}_i \sim \pi_\theta(\cdot | c_i^S)\)，其中\(c_i^S\)为部署上下文。
    - 教师重评分：使用特权上下文\(c_i^T\)（含缺陷证据\(r_i\)）计算学生每个前缀的next-token分布\(P_{T,t}\)。
    - 教师参数通过EMA更新：\(\bar{\theta}^{(k)} = \mu \bar{\theta}^{(k-1)} + (1-\mu)\theta^{(k)}\)。
    - 逐token损失：\( \ell_{\text{OPSD}}^{(i)} = \sum_{t=1}^{|\hat{y}_i|} D(P_{S,t} \parallel \text{stopgrad}(P_{T,t})) \)，其中\(D\)取广义Jensen-Shannon散度。
  - **语言引导视觉锚定（Language-guided Visual Anchoring）**：
    - 提取最终判断\(\hat{a}_i\)（<answer></answer>内的文本）。
    - 判断前馈：\((\tilde{z}_a, \tilde{z}_n) = f_\theta^{\text{ref}}(x_i^{\text{img}}, x_i^{\text{text}}, \hat{a}_i; z_a, z_n)\)，得到上下文化的异常/正常锚点。
    - 对比热图头：对每个patch特征\(\bar{v}_{ij}\)，计算\(s_{ij} = \tau(\langle \bar{v}_{ij}, \bar{z}_a \rangle - \langle \bar{v}_{ij}, \bar{z}_n \rangle)\)，得到异常得分图\(S\)，上采样得像素级异常图\(\hat{M}_i\)。
  - **总损失**：\(L = L_{\text{OPSD}} + \lambda_{\text{RL}} L_{\text{reward}} + \lambda_{\text{H}} L_{\text{map}}\)，其中\(L_{\text{map}}\)包含图像级、像素级、focal、Dice及锚点对比损失。

- OPD-IAD在所有五个基准上，在图像级、像素级和QA指标上整体达到LVLM-based IAD方法的**最优**性能。
- 证据特权密集同策略自蒸馏（OPSD）优于SFT和稀疏奖励（GRPO），说明在模型自身轨迹上提供密集token级监督更有效（表2）。
