## 摘要
深度伪造检测正从二元分类决策转向能够解释支持这些决策的视觉证据的系统。这一转变对于现实世界的验证场景至关重要，因为不同用户不仅需要了解图像是否被篡改，还需要理解为何被认为可疑。ACM Multimedia 2026的可解释深度伪造检测挑战赛旨在评估这种联合能力。该挑战基于XPlainVerse（一个百万规模的可解释深度伪造检测基准），评估方法在图像分类和基于自然语言的可解释生成方面的表现。参与者为每张图像提交一个真实/伪造标签以及两种解释：面向技术用户的详细复杂解释和面向普通用户的简洁简单解释。评估结合了分类指标与语义相似性、简洁性以及意图感知的接地指标，这些指标评估解释是否能识别相关的被篡改实体和支持性视觉证据。通过该挑战开发的方法将有助于下一代可解释深度伪造检测器的发展。评估脚本、基线模型及配套代码可在https://github.com/Abhijeet8901/XPlainVerse-ACMChallenge获取。

## Abstract
Deepfake detection is moving beyond binary classification decisions toward systems that can also explain the visual evidence supporting those decisions. This transition is important for real-world verification settings, where diverse users need to understand not only whether an image is manipulated, but also why it is considered suspicious. The Explainable Deepfake Detection Challenge at ACM Multimedia 2026 is designed to benchmark this joint capability. Built on XPlainVerse, a million-scale benchmark for explainable deepfake detection, the challenge evaluates methods on image classification and grounded natural-language explanation generation. Participants submit a real/fake label together with two explanations for each image: a detailed complex explanation for technical users and a concise simple explanation for general users. The evaluation combines classification metrics with semantic similarity, simplicity, and intent-aware grounding metrics that assess whether explanations identify the relevant manipulated entities and supporting visual evidence. The methodologies developed through the challenge will contribute to the development of next-generation explainable deepfake detectors. Evaluation script, baseline models, and accompanying code are available on https://github.com/Abhijeet8901/XPlainVerse-ACMChallenge.

- **核心问题**：当前深度伪造检测主要聚焦于二元分类（真实/伪造），但实际验证场景中，用户不仅需要知道结果，更需理解“为什么”被判定为伪造。不同类型的用户（如法医分析师、普通用户）对解释的详细程度和语言风格需求不同，因此需要系统不仅能检测，还能生成**针对不同受众的有依据的自然语言解释**。

## 2. 论文提出的方法论

### 核心思想
- 构建一个同时评估图像级真实性分类和**双层次自然语言解释生成**的基准挑战赛。
- 解释需**基于视觉证据**，且根据用户角色分为**复杂解释**（面向技术用户，详细描述具体伪造痕迹）和**简单解释**（面向普通用户，简洁易懂）。

### 关键技术细节
- **数据集**：基于 XPlainVerse，包含数百万张真实/伪造图像，覆盖多样化编辑类型（人物、物体、场景布局、文本、局部几何等），并包含真实世界扰动和对抗扰动。
- **任务**：
  - **Task 1**：图像级真实性检测（二分类）。
  - **Task 2**：为每张图像生成两种解释（复杂+简单）。
- **评估指标**（综合得分 M_final 由检测得分和解释得分等权平均）：
  - **检测得分 D_F1**：macro-F1（伪造类和真实类的F1平均）。
  - **解释得分 E_exp**：由参考基础解释得分 E_ref (40%) 和 LLM 接地得分 E_LLM (60%) 加权。
    - **E_ref**：复杂解释语义相似度 BERTScore-F1（B_c） + 简单解释语义相似度 B_s 与可读性 SLE 归一化后组合（E_s = 0.7*B_s + 0.3*L_s），取平均。
    - **E_LLM**：基于 LLM 评估的**实体接地得分 G_ent**（解释是否识别正确被篡改实体）和**证据接地得分 G_evid**（解释是否提供正确视觉证据）的平均。
  - **最终得分 M_final = (D_F1 + E_exp)/2**。

### 算法流程（文字说明）
1. 模型接收图像 \( x_i \)，输出：
   - 预测标签 \( \hat{y}_i \)；
   - 复杂解释 \( \hat{e}_i^c \)；
   - 简单解释 \( \hat{e}_i^s \)。
2. 计算检测指标 D_F1。
3. 计算解释指标：
   - 对比参考复杂解释 \( e_i^{c,*} \) 得 BERTScore F1 (B_c)；
   - 对比参考简单解释 \( e_i^{s,*} \) 得 BERTScore F1 (B_s)；
   - 对简单解释计算 SLE 并归一化得 L_s；
   - 使用 LLM 提取复杂解释中的实体和证据集，与参考进行双向覆盖评估，得 G_ent 和 G_evid。
4. 加权组合得到 E_exp 和 M_final。
