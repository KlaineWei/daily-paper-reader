## 摘要
我们提出MiSS，一个黑盒、基于查询的框架，通过扰动相对充分性推理来解释3D点云分类器。MiSS将超点分区视为可解释的抽象层，并询问在指定的扰动分布下，是否可以从几何区域的最小联盟中证明原始预测。与需要布尔特征空间或预测器的白盒逻辑编码的溯因解释器不同，MiSS将候选提议与验证分离：加权MaxSAT过程使用启发式自适应基数下限、经过认证的精确大小回退、安全收紧的上限、阻塞子句以及从先前预言评估中学到的替代获取启发式来提出联盟，而黑盒统计预言则根据预测查询决定充分性。该系统返回一个统计验证的充分联盟作为二元属性，当认证搜索完成时保证最小基数。在ModelNet40和ShapeNet上使用PointNet和PointMLP分类器的实验显示，在大多数设置中，比基于规则的基线具有更高的精确度和覆盖率，并且比穷举搜索更低的解释时间。

## Abstract
We present MiSS, a black-box, query-based framework for explaining 3D point cloud classifiers through perturbation-relative sufficiency reasoning. MiSS treats a superpoint partition as an interpretable abstraction layer and asks whether the original prediction can be certified from a minimal coalition of geometric regions under a specified perturbation distribution. Unlike abductive explainers that require Boolean feature spaces or white-box logical encodings of the predictor, MiSS separates candidate proposal from verification: a weighted MaxSAT procedure proposes coalitions using a heuristic adaptive cardinality floor, certified exact-size fallback, a safely tightened upper bound, blocking clauses, and a surrogate acquisition heuristic learned from previous oracle evaluations, while a blackbox statistical oracle decides sufficiency from prediction queries. The system returns a statistically verified sufficient coalition as a binary attribution, with minimum cardinality guaranteed when certified search completes. Experiments on ModelNet40 and ShapeNet with PointNet and PointMLP classifiers show higher precision and coverage than rule-based baselines in most settings, with lower explanation time than exhaustive search.

## 1. 核心问题与研究动机
- **问题背景**：点云分类器（如 PointNet、PointMLP）在自动驾驶、机器人等领域至关重要，但其决策过程难以解释。现有可解释性方法主要分为两类：
  - **信号级归因**（如 Grad-CAM、SHAP、LIME）：只能回答“哪个特征贡献大”，但无法提供预测的**充分性保证**（即保留这些特征后，预测是否必然不变）。
  - **溯因解释**（Abductive Explanation / Prime Implicant）：要求特征为布尔值或模型为白盒逻辑编码，不适用于连续、黑盒的深度点云模型。
- **核心挑战**：连续高维输入空间 + 非线性神经网络 + 黑盒访问 ⇒ 无法用传统逻辑推理验证充分性。同时，逐点解释规模大、不直观，用户更倾向区域级（超点）解释。
- **本文目标**：提出一个黑盒、查询驱动的框架 **MiSS**，在超点分区上寻找**最小充分联盟**，保证统计意义上预测保留概率 ≥ 阈值 τ，并在搜索完成时证明最小基数。

## 2. 方法论：核心思想与关键技术
### 2.1 整体架构
- **输入**：点云 P，黑盒分类器 f（输出类 y），超点分区 S = {S1,…,SK}，扰动分布 M，精度阈值 τ。
- **输出**：最小充分联盟 C* ⊆ S（统计验证满足 Pr[f(P̃_C)=y] ≥ τ），呈现为二元超点掩码。
- **流程**：种子单向 → 代理权重初始化 → 加权 MaxSAT 候选提议 → 统计 Oracle 验证 → 结果反馈更新历史、阻塞子句、基数上下界 → 迭代直至预算耗尽或 UNSAT 认证完成。

### 2.2 核心定义
- **最小充分集 (MiSS)**：C 满足：
  1. Sufficiency: Pr[f(P̃_C) = y] ≥ τ
  2. Minimality: ∀C' ⊂ C, Pr[f(P̃_C') = y] < τ
- **单调性假设**：若 S ⊆ T 且 S 充分，则 T 充分。该假设下只需检查所有单特征移除即可保证最小性，否则仅保证一步最小。
- **存在性定理**：若存在任意充分超集，则至少存在一个 MiSS。

### 2.3 关键组件
#### a) 超点构建
- 使用**曲率增强 K-Means**：对每个点计算局部曲率 κ（PCA 特征值之比），形成 [x,y,z,κ] 特征，聚类得到 K 个超点，保证 disjoint & covering。

#### b) 扰动算子
- 保留联盟内超点原始几何，替换非联盟超点为**分布内补丁库**中的随机样本（中心化、缩放、小旋转平移），避免越界退化。

#### c) 候选提议：加权 MaxSAT + 代理引导
- 硬子句：基数约束 ℓ_cur ≤ Σxi ≤ L_cur、阻塞子句（已拒绝联盟及其子集、已接受联盟的 exact block）。
- 软子句：(¬xi, qi) 表示选择超点 i 的代价，qi ∝ α_soft(1-wi)。wi 来自代理模型预测的超点重要性（0~1）。
- 代理模型：**样本加权岭回归**，利用所有历史 Oracle 评估结果 (Cj, p̂j, nj)，回归目标为精确度 p̂j，样本权重为 nj（信任度）。预测单个超点 i 的权重 wi。
- 求解器：PySAT RC2 + MapleSat，返回满足所有硬子句、最大化软权重总和的候选联盟。

#### d) 统计验证：顺序 KL 界限测试
- 逐个批次采样扰动样本，计算成功率 p̂。
- 使用 KL 下界/上界判断是否超过阈值 τ（置信度 δ=0.05），若无法判定则回退至经验比率，最多 N_max 样本。
- 输出 (b, p̂, n)，b 表示是否充分。

#### e) 自适应基数窗口
- **上界 L_cur**：一旦发现充分联盟，立即收紧为 |C|-1。
- **下界 ℓ_cur**：启发式，根据初始单点集精度估计，并在连续 η 次拒绝同尺寸候选后递增。若 ℓ_cur ≥ L_cur 则重置为 2 并启用认证回退（精确大小枚举），保证覆盖被跳过的尺寸。
- **UNSAT 证书**：当窗口 Ψ_t 不可满足时，由单调性可推知不存在尺寸 ≤ L_cur 的充分联盟，从而认证当前解为全局最小基数。

#### f) 子句更新
- 拒绝时：添加失败子集剪枝子句 Ψ ← Ψ ∧ (∨_{Si∉C} xi)，排除 C 及其所有子集。
- 接受时：添加 exact block 子句，避免重复提议同一联盟。

### 2.4 算法流程（文字说明）
1. 初始化：评估所有单点集，存入历史 H；拟合代理，初始化权重；初始化窗口。
2. 循环迭代：
   a) 构建 WCNF Φ_t（硬子句+软子句）；
   b) 调用 MaxSAT 求解器获得候选 C；
   c) 若 UNSAT，则停止（窗口内无候选）；
   d) 调用 Oracle 验证 C；
   e) 更新历史 H、阻塞子句；
   f) 若充分则更新 L_cur = |C|-1，记录充分联盟；
   g) 若不充分则添加失败子集剪枝子句；
   h) 更新 ℓ_cur，重新拟合代理权重。
3. 返回最小尺寸的充分联盟（若搜索预算结束则返回第一个）。
4. 认证完成时保证全局最小基数。

## 6. 主要结论与发现
1. **性能优势**：在点云任务上，MiSS 的 Precision 显著高于所有规则基线（最高 95%+ vs 58-84%），覆盖率为中等水平但可接受。MiSS*（首充分联盟）在多数设置中达到近似质量且耗时减半。

5. **参数鲁棒性**：搜索预算从 30s 增至 240s 时精度/覆盖近乎不变，表明算法能在早期快速找到高质量解。求解器选择影响速度（MapleSat 最优）。

## 7. 优点
- **黑盒友好**：无需模型梯度或白盒逻辑，仅需查询接口。
- **统计保证**：通过 KL 界限提供概率充分性验证，用户可控制置信度 δ。
- **最小性可认证**：在 UNSAT 窗口下可证明全局最小基数（满足单调性假设时），远超现有启发式方法。
- **高效搜索**：代理加权、自适应窗口、阻塞子句等机制显著降低 Oracle 调用次数。
- **可解释性强**：输出为超点级二元掩码，直观且易于可视化。
- **跨领域适用**：同时验证于点云和表格数据，具有泛化潜力。

## 8. 不足与局限
- **认证条件受限**：最小基数保证仅在搜索完成且 UNSAT 窗口覆盖时成立，若因时间/查询预算中断则无法保证。且依赖单调性假设，违反时仅保证一步最小性。
- **分区依赖**：超点质量（K-Means 聚类）直接影响解释语义质量，无法保证与人类认知的区域完全一致。
- **扰动分布选择**：补丁替换假设分布内替换，但极端扰动可能导致 Oracle 评估失效（仍在线性附近）。对 out-of-distribution 情况未覆盖。
- **对比基线有限**：未与点云专用解释器（如 PointNet Grad-CAM、点云扰动方法）进行定量 Precision 对比，仅视觉列出了一个 GradCAM。规则基线在点云上的适配可能使其表现不佳。
- **计算开销**：虽然比穷举快，但在大分区（K=40）时仍可能需要数秒至数十秒（表 1），不满足实时交互需求（<1s）。
- **代码与可复现**：论文提供 artifact 链接（密码保护），但未明确开源许可证及长期维护计划。
- **安全应用限制**：作者明确声明解释应视为分区级充分性证据，非因果证据或安全证书，不适用于高风险系统直接审计。
