## 摘要
现有的音频伪造检测与定位（AFDL）方法往往过度拟合数据集特定的低级伪影，限制了其对细微、局部和未见过的篡改的泛化能力。近期基于音频大型语言模型（ALLM）的方法将AFDL视为问答任务，但仍隐式地建模法医学证据，未将篡改线索与预测联系起来。为弥合这一差距，我们提出ThinkOmni，一种推理驱动的全模态大语言模型，联合执行显式法医学推理、欺骗检测和时间定位。为实现显式推理监督，我们构建了法证感知思维链（FACoT），一个包含10万样本、带有结构化法医学证据和推理注释的数据集。利用FACoT，我们引入法证感知模态增量学习（FMIL），逐步将语义、声学和谱视觉表示与LLM骨干网络对齐，以捕获互补的法医学线索。我们进一步提出法证一致性多任务损失（FCML），结合加权交叉熵与自适应定位损失，以协调推理生成、欺骗检测和时间定位。大量实验表明，ThinkOmni在检测和定位方面均实现了强大的跨数据集泛化能力。代码、模型、数据和推理示例见https://beyond0814.github.io/ThinkOmni/。

## Abstract
Existing audio forgery detection and localization (AFDL) methods often overfit dataset-specific low-level artifacts, limiting their generalization to subtle, localized, and unseen manipulations. Recent audio large language model (ALLM)-based approaches cast AFDL as question answering but still model forensic evidence implicitly, without linking manipulation cues to predictions. To bridge this gap, we propose ThinkOmni, a reasoning-driven omni-modal large language model that jointly performs explicit forensic reasoning, spoofing detection, and temporal manipulation localization. To enable explicit reasoning supervision, we construct Forensic-Aware Chain-of-Thought (FACoT), a 100K-sample dataset with structured forensic evidence and reasoning annotations. Leveraging FACoT, we introduce Forensic-Aware Modality-Incremental Learning (FMIL), which progressively aligns semantic, acoustic, and spectral-visual representations with the LLM backbone to capture complementary forensic cues. We further propose Forensic-Consistent Multi-task Loss (FCML), which combines weighted cross-entropy with an adaptive localization loss to coordinate reasoning generation, spoofing detection, and temporal localization. Extensive experiments show that ThinkOmni achieves strong cross-dataset generalization in both detection and localization. Code, models, data, and inference examples are available at https://beyond0814.github.io/ThinkOmni/.

- **动机**：引入**显式推理（Chain-of-Thought）**，使模型能够逐步分析多模态法医证据（语义不一致性、声学伪影、时间操纵模式），从而提升跨数据集泛化能力和决策可解释性。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 总体框架
- 基于**Qwen2.5-Omni**构建，保留其语义编码器、视觉编码器和Thinker骨干，并新增**声学编码器**和**语义-声学法医增强模块（SAFE）**，以捕获互补的低级法医学线索。
- 输入包括音频波形、线性语谱图和文本指令。输出由结构化推理序列、检测结果（0/1/2：全真实/全伪造/部分伪造）和时间戳序列组成。

### 2.2 关键技术细节

#### (1) 法医感知思维链数据集（FACoT）
- **规模**：100K样本，来自8个公开数据集，覆盖全真实、全伪造和部分伪造三类。
- **构建三步走**：
  1. **源音频收集**：从PS、HAD、LAV-DF、SINE、LPS、ArEnAV、AV-1M++和ASVspoof 2019 LA共8个数据集中抽取100K条。
  2. **CoT标注**：
     - **种子集**：6.2K样本通过Gemini-3-Pro生成初始推理，经专家验证（8项检查清单）后得到高质量种子。
     - **大规模扩展**：基于种子集微调Qwen3-Omni，对剩余93.8K样本自动生成结构化解剖推理。
  3. **语义质量过滤**：利用CLAP计算音频-文本相似度，丢弃相似度低于0.2的推理维度，保留音频样本与其余合理维度。
- **标注维度**：9个法医维度，分为三个层级——低级声学异常（嗓音纹理、频谱伪影、生成痕迹）、中级时间不连续（边界分析、时间连贯性）、高级上下文不一致（韵律、说话人一致性、语言自然度、环境一致性）。

#### (2) 法医感知模态增量学习（FMIL）
- **动机**：跨数据集泛化受限于数据集特定伪影和不同模态间的异构法医线索。FMIL通过三个阶段渐进式融合语义、声学和谱-视觉证据。
- **三个阶段**：
  - **阶段1：语义法医适应（SFA）**：仅训练语义编码器（Whisper-large-v3）和Thinker（LoRA），建立可迁移的语义推理基础。
  - **阶段2：声学法医增强（AFA）**：冻结语义编码器，引入声学编码器（Wav2Vec2 XLSR-300M）和SAFE模块，捕捉细粒度声学伪影。SAFE包含：
    - **局部交叉注意力分支**：对齐语义和声学token，生成局部融合表示。
    - **全局伪造判别器**：通过长度感知池化提取全局特征，经MLP映射后与局部特征通过**门控融合**结合。
  - **阶段3：多模态法医精炼（MFR）**：冻结语义和声学编码器及SAFE，引入视觉编码器（ViT）处理语谱图，进行跨模态验证。

#### (3) 法医一致性多任务损失（FCML）
- **加权交叉熵损失**：为不同角色token赋予不同权重：推理token 0.2，检测token 0.2×类别先验权重（0.36/0.24/0.40），定位token 0.6。
- **自适应定位损失**：根据样本类别动态调整：
  - 全真实样本：惩罚所有预测区间，鼓励输出零区间。
  - 全伪造样本：损失为零（整段均为伪造）。
  - 部分伪造样本：采用混合回归损失（1-IoU + Smooth L1）。
- **总损失**：L_total = L_wce + 0.5 × L_loc。
