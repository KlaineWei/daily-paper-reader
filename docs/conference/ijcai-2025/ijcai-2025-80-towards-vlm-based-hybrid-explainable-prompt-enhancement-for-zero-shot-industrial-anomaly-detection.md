# 中文总结

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究动机**：零样本工业异常检测（ZSIAD）旨在无需目标类别训练数据的情况下，识别和定位工业图像中的异常。现有基于视觉-语言模型（VLM）的方法（如WinCLIP、AdaCLIP）虽利用预训练模型的强大泛化能力，但存在两个关键局限：① 对未见异常的多样性和复杂性缺乏详细描述，难以准确分类和分割；② 获取高质量的异常细节提示成本高昂（需要大量人工标注），且现有方法依赖模拟异常导致泛化能力不足。
- **整体含义**：论文提出一种基于多模态大语言模型（MLLM）和视觉基础模型（VFM）的**多阶段提示生成智能体**，以低成本生成语义丰富的文本提示和注意力提示，并通过**混合可解释提示增强框架**（HEPE）充分利用这些提示，显著提升VLM在ZSIAD任务中的性能，同时提供可解释的异常识别依据。

## 2. 论文提出的方法论

### 核心思想
利用MLLM和VFM分别生成**文本提示**（描述异常细节）和**注意力提示**（聚焦异常区域），并将二者与CLIP框架中的静态/动态提示结合，通过混合语义融合模块（HSF）增强图像级和像素级异常检测。

### 关键技术细节

1. **多阶段提示生成智能体**：
   - **文本提示**：
     - **Step 1**：将正常图像和测试图像输入MLLM，让其详细描述二者差异，挖掘潜在异常细节。
     - **Step 2**：引入类别标签引导，并设置**抗误报约束**（anti-false alarm constraint），防止LLM将正常差异（如方向不同）误判为异常。
   - **注意力提示**：
     - 使用VFM（如DINOv2）提取测试图像的注意力特征，再通过**异常特征选择模块（AFS）** 筛选出最可能包含异常的区域。AFS包含**全维度动态卷积（OD Conv）** 和**深度可分离卷积（DS Conv）**，前者通过多维注意力机制动态增强对异常区域的关注，后者降低参数量。

2. **混合可解释提示增强框架（HEPE）**：
   - 基于CLIP架构，引入**静态提示（PS）** 和**动态提示（PD）**，动态提示由提示生成器G（CLIP图像编码器的类标记+可学习投影层）针对每张测试图像生成。
   - **混合语义融合模块（HSF）**：聚合最可能代表异常的patch嵌入，替代传统取最大值的方法，提高鲁棒性。HSF输出融合了注意力提示的语义嵌入。
   - **异常图生成**：计算融合注意力后的patch嵌入与文本嵌入（包含文本提示）的余弦相似度，通过softmax和插值得到像素级异常图。

3. **损失函数**：
   - 结合Dice损失（LD）和Focal损失（LF），最终损失 L = LD + LF。
